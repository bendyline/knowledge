# Contributing

This repository is open source, but we do not accept external contributions or
pull requests. Code and catalog updates are maintained by the project maintainers.

We welcome suggestions for new knowledge catalogs! Please
[open an issue](https://github.com/bendyline/knowledge/issues/new) with:

- A link to the source repository or content.
- A brief description of the knowledge it contains and why it would be useful.
- The suggested scope, such as a particular folder, topic, or language.
- Any licensing information you know about.
