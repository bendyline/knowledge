# How-to books

This catalog has two parts with different licenses.

## Source books (`books/`)

The books are English texts from Project Gutenberg's "How To ..." bookshelf.
Each selected book's generated HTML edition carries Project Gutenberg's rights
statement "Public domain in the USA." Books that Project Gutenberg marks as
copyrighted are excluded. `LICENSES/gutenberg-selection.json` lists every
included book with its rights statement, source URL, and SHA-256, along with
excluded and failed books and their reasons.

The book text is marked with the Creative Commons Public Domain Mark 1.0
(`LICENSES/CC-PDM-1.0.txt`). Copyright status was identified from Project
Gutenberg's metadata for the United States. Status in other countries can
differ. Project Gutenberg makes no representation about it, and neither does
this catalog. Check the law where you use or redistribute these texts.

Project Gutenberg volunteers transcribed these editions. Following the Project
Gutenberg license, its license text, trademark text, and every reference to
Project Gutenberg have been removed from the book text. Producer notes that
name Project Gutenberg are also removed. Crediting Project Gutenberg as a
source is permitted and done voluntarily in this notice and in each document's
provenance. This catalog is not affiliated with or endorsed by Project
Gutenberg.

Modifications: each book is converted from HTML to Markdown and split into
chapter or section documents. Page-number markers and links to the source
website are removed. Back-of-book indexes are omitted because they refer to
printed page numbers that no longer exist in this format. Internal links point
to the section that contains their target. Images are omitted, but their
alternative text and captions are kept.
Spelling, wording, and content are not otherwise changed. Per-document
provenance records the exact transformation.

These are historical works, reproduced as written. Some advice is obsolete or
unsafe by current standards. Examples include food preservation, medicine,
chemicals, poisons, electrical work, firearms, and the handling of animals.
None of it is current professional guidance.

## How-to guides (`guides/`)

The guides are original works by Bendyline, licensed under the Creative
Commons Attribution-ShareAlike 4.0 International license
(`LICENSES/CC-BY-SA-4.0.txt`). Each guide restates a practical task in
present-day language, cites the book sections it draws on, and adds modern
safety notes where historical practice differs from current guidance.
Adaptations of the guides must retain attribution and remain under
CC BY-SA 4.0.

The repository's MIT software license does not apply to either part of this
catalog's content.
