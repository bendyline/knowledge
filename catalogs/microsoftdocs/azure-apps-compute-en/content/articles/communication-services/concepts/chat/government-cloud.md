# Chat support for government clouds


> **Warning:**
> **Azure Communication Services is introducing breaking changes, and some services are being retired. Learn more in the [retirement and breaking changes guide](https://aka.ms/acs-retirement-and-breaking-changes-guide).**


Developers can build a chat application in government cloud for real-time text communications. 

> **Important:**
> This feature of Azure Communication Services is currently in preview. Features in preview are publicly available and can be used by all new and existing Microsoft customers.
>
> Preview APIs and SDKs are provided without a service-level agreement. We recommend that you don't use them for production workloads. Certain features might not be supported or capabilities might be constrained.
>
> For more information, see [Supplemental Terms of Use for Microsoft Azure Previews](https://azure.microsoft.com/support/legal/preview-supplemental-terms/).


| Microsoft 365 cloud | Azure cloud | Support |
| --- | --- | --- |
| Public | Public | ✔️ |
| GCC | Public | ❌ |
| GCC-High | [US Government](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/azure-government/documentation-government-welcome.md) | ✔️ |

## Supported use cases

The following table shows supported use cases for Government Community Cloud (GCC) user with Azure Communication Services:

| Scenario | Supported |
| --- | --- |
| 1:1 Chat | ✔️ |
| Group Chat | ✔️ |

Azure Communication Chat service also enables connecting to Microsoft 365 cloud that meets government security and compliance requirements for Teams Interoperability [scenarios](../interop/guest/government-cloud.md).
