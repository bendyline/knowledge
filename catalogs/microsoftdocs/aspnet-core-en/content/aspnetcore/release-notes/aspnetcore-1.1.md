# What's new in ASP.NET Core 1.1

ASP.NET Core 1.1 includes the following new features:

* [URL rewriting middleware](../fundamentals/url-rewriting.md)
* [Response caching middleware](../performance/caching/middleware.md)
* [View Components as Tag Helpers](https://learn.microsoft.com/search/?terms=mvc%2Fviews%2Fview-components%23invoking-a-view-component-as-a-tag-helper)
* [Middleware as MVC filters](https://learn.microsoft.com/search/?terms=mvc%2Fcontrollers%2Ffilters%23using-middleware-in-the-filter-pipeline)
* [Cookie-based TempData provider](https://learn.microsoft.com/search/?terms=fundamentals%2Fapp-state%23tempdata)
* [Azure App Service logging provider](https://learn.microsoft.com/search/?terms=fundamentals%2Flogging%2Findex%23azure-app-service)
* [Azure Key Vault configuration provider](../security/key-vault-configuration.md)
* [Azure and Redis Storage Data Protection Key Repositories](../security/data-protection/implementation/key-storage-providers.md)
* WebListener Server for Windows
* [WebSockets support](../fundamentals/websockets.md)

## Choosing between versions 1.0 and 1.1 of ASP.NET Core

ASP.NET Core 1.1 has more features than ASP.NET Core 1.0. In general, we recommend you use the latest version.

## Breaking changes

Use the articles in [Breaking changes in .NET](https://learn.microsoft.com/dotnet/core/compatibility/breaking-changes) to find breaking changes that might apply when upgrading an app to a newer version of .NET.
