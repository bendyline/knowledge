# RDG006: Invalid constructor parameters

|  | Value |
| --- | --- |
| **Rule ID** | RDG006 |
| **Fix is breaking or non-breaking** | Non-breaking |

## Cause

This diagnostic is emitted by the [Request Delegate Generator](https://learn.microsoft.com/aspnet/core/fundamentals/aot/request-delegate-generator/rdg) when an endpoint contains a route handler with a parameter annotated with the  [`[AsParameters]`](https://learn.microsoft.com/search/?terms=Microsoft.AspNetCore.Http.AsParametersAttribute) attribute that contains an invalid constructor.

### Rule description

Types that are used for surrogate binding via the  [`[AsParameters]`](https://learn.microsoft.com/search/?terms=Microsoft.AspNetCore.Http.AsParametersAttribute) attribute must contain a `public` parameterized constructor where all parameters to the constructor match the `public` properties declared on the type. The `TodoRequest` type produces this diagnostic because there is no matching constructor parameter for the `Todo` property.

[Code reference unavailable in this source snapshot: ~/../AspNetCore.Docs.Samples/fundamentals/aot/diagnostics/Rdg6/Program.cs](https://github.com/dotnet/AspNetCore.Docs/blob/970aa3fd243493b204e11c0f29472fd3f0399fee/aspnetcore/fundamentals/aot/request-delegate-generator/diagnostics/rdg006.md)

## How to fix violations

Ensure that all properties on the type have a matching parameter on the constructor.

[Code reference unavailable in this source snapshot: ~/../AspNetCore.Docs.Samples/fundamentals/aot/diagnostics/Rdg6/Program.cs](https://github.com/dotnet/AspNetCore.Docs/blob/970aa3fd243493b204e11c0f29472fd3f0399fee/aspnetcore/fundamentals/aot/request-delegate-generator/diagnostics/rdg006.md)

## When to suppress warnings

This warning should ***not*** be suppressed. Suppressing the warning leads to a runtime exception associated with the same warning.
