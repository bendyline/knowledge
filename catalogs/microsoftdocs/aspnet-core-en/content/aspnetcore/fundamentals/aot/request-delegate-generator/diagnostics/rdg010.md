# RDG010: InvalidAsParameters Nullable

<!-- UPDATE 9.0 Activate after release and INCLUDE is updated

[!INCLUDE[](~/includes/not-latest-version.md)]

-->

|  | Value |
| --- | --- |
| **Rule ID** | RDG010 |
| **Fix is breaking or non-breaking** | Non-breaking |

## Cause

This diagnostic is emitted by the [Request Delegate Generator](https://learn.microsoft.com/aspnet/core/fundamentals/aot/request-delegate-generator/rdg) when an endpoint contains a route handler with a parameter annotated with the [`[AsParameters]`](https://learn.microsoft.com/search/?terms=Microsoft.AspNetCore.Http.AsParametersAttribute) attribute that is marked as nullable.


### Rule description

The implementation of surrogate binding via the [`[AsParameters]`](https://learn.microsoft.com/search/?terms=Microsoft.AspNetCore.Http.AsParametersAttribute) attribute in Minimal APIs only supports types that are not nullable. 

[Code reference unavailable in this source snapshot: ~/../AspNetCore.Docs.Samples/fundamentals/aot/diagnostics/Rdg10/Program.cs](https://github.com/dotnet/AspNetCore.Docs/blob/970aa3fd243493b204e11c0f29472fd3f0399fee/aspnetcore/fundamentals/aot/request-delegate-generator/diagnostics/rdg010.md)

## How to fix violations

Declare the parameter as non-nullable.

[Code reference unavailable in this source snapshot: ~/../AspNetCore.Docs.Samples/fundamentals/aot/diagnostics/Rdg10/Program.cs](https://github.com/dotnet/AspNetCore.Docs/blob/970aa3fd243493b204e11c0f29472fd3f0399fee/aspnetcore/fundamentals/aot/request-delegate-generator/diagnostics/rdg010.md)

## When to suppress warnings

This warning should ***not*** be suppressed. Suppressing the warning leads to a runtime exception associated with the same warning.
