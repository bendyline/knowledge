## Cause

This diagnostic is emitted by the [Request Delegate Generator](https://learn.microsoft.com/aspnet/core/fundamentals/aot/request-delegate-generator/rdg) when an endpoint contains a route handler with a parameter that contains an invalid combination of service source attributes.

### Rule description

ASP.NET Core supports resolving keyed and non-keyed services via [dependency injection](../../../dependency-injection.md). It's ***not*** feasible to resolve a service as both keyed and non-keyed. The following code  produces the diagnostic and throws a run time error with the same message:

Resolve the target parameter as either a keyed or non-keyed service.

## When to suppress warnings

This warning should ***not*** be suppressed. Suppressing the warning leads to a [NotSupportedException](https://learn.microsoft.com/dotnet/api/system.notsupportedexception) runtime exception `The FromKeyedServicesAttribute is not supported on parameters that are also annotated with IFromServiceMetadata.`
