Microsoft and contributors license documentation under CC BY 4.0 and code under MIT. Full source license texts and original legal/trademark notices are retained in LICENSES/. Microsoft names identify the documented products; Bendyline is not affiliated with or endorsed by Microsoft.

Source: https://github.com/dotnet/EntityFramework.Docs/tree/fce62a889ce5d100d7961a638dd01dbe2d6c598c

This preservation snapshot imports Markdown from entity-framework and selected text code files from samples. Images, repository automation, binaries, and generated API YAML are outside this selection. It preserves the selected repository state, not Git history or an offline copy of every external dependency.

Bendyline normalizes Markdown and presentation directives, expands available licensed includes, converts local cross-references, omits images while retaining alt text, and stores complete selected code files as fenced Markdown with MIT attribution. Code snippet references link to complete source files rather than pretending a snippet selector was expanded. External UID references use Microsoft Learn search. Unsupported presentation markers remain visible as code. Missing external includes or code dependencies are explicitly marked in articles and listed in LICENSES/import-report.json; they are not silently discarded.

Source URLs, commit revisions, input hashes, and transformation details are recorded per file in provenance.jsonl. The manifest pins this source commit to preserve the corpus when the upstream repository retires. Refreshing to a newer source snapshot requires updating the manifest ref, reviewing notices, and syncing. A missing source never deletes the accepted copy.
