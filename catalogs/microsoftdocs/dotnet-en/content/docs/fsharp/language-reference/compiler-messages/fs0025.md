# FS0025: Incomplete pattern match

This message is given when pattern matching is incomplete.

Given the following definition:

[FS0025-DU-declaration (complete source file; reference: \~/samples/snippets/fsharp/compiler-messages/fs0025.fsx#L2-L6)](../../../../_code/samples/snippets/fsharp/compiler-messages/fs0025.fsx.md)

And match expression:

[FS0025-DU-incomplete-match (complete source file; reference: \~/samples/snippets/fsharp/compiler-messages/fs0025.fsx#L15-L17)](../../../../_code/samples/snippets/fsharp/compiler-messages/fs0025.fsx.md)

The compiler will yield the following message:

```text
FS0025: Incomplete pattern matches on this expression. For example, the value 'Cold' may indicate a case not covered by the pattern(s).
```

To resolve, you can either complete the pattern match:

[FS0025-DU-complete-match (complete source file; reference: \~/samples/snippets/fsharp/compiler-messages/fs0025.fsx#L9-L12)](../../../../_code/samples/snippets/fsharp/compiler-messages/fs0025.fsx.md)

Or, introduce a wildcard, `_` (use with caution)

[FS0025-DU-wildcard-match (complete source file; reference: \~/samples/snippets/fsharp/compiler-messages/fs0025.fsx#L20-L23)](../../../../_code/samples/snippets/fsharp/compiler-messages/fs0025.fsx.md)
