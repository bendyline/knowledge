# Use the IEmbeddingGenerator interface

The [Microsoft.Extensions.AI.IEmbeddingGenerator`2](https://learn.microsoft.com/search/?terms=Microsoft.Extensions.AI.IEmbeddingGenerator%602) interface represents a generic generator of embeddings. For the generic type parameters, `TInput` is the type of input values being embedded, and `TEmbedding` is the type of generated embedding, which inherits from the [Microsoft.Extensions.AI.Embedding](https://learn.microsoft.com/search/?terms=Microsoft.Extensions.AI.Embedding) class.

The `Embedding` class serves as a base class for embeddings generated by an `IEmbeddingGenerator`. It's designed to store and manage the metadata and data associated with embeddings. Derived types, like [Microsoft.Extensions.AI.Embedding`1](https://learn.microsoft.com/search/?terms=Microsoft.Extensions.AI.Embedding%601), provide the concrete embedding vector data. For example, an `Embedding<float>` exposes a `ReadOnlyMemory<float> Vector { get; }` property for access to its embedding data.

The `IEmbeddingGenerator` interface defines a method to asynchronously generate embeddings for a collection of input values, with optional configuration and cancellation support. It also provides metadata describing the generator and allows for the retrieval of strongly typed services that can be provided by the generator or its underlying services.

## Pipelines of functionality

As with `IChatClient`, `IEmbeddingGenerator` implementations can be layered. `Microsoft.Extensions.AI` provides a delegating implementation for `IEmbeddingGenerator` for caching and telemetry.

[language="csharp" source="snippets/microsoft-extensions-ai/ConsoleAI.CustomEmbeddingsMiddle/Program.cs"::: (complete source file; reference: snippets/microsoft-extensions-ai/ConsoleAI.CustomEmbeddingsMiddle/Program.cs)](../../_code/docs/ai/snippets/microsoft-extensions-ai/ConsoleAI.CustomEmbeddingsMiddle/Program.cs.md)

The `IEmbeddingGenerator` enables building custom middleware that extends the functionality of an `IEmbeddingGenerator`. The [Microsoft.Extensions.AI.DelegatingEmbeddingGenerator`2](https://learn.microsoft.com/search/?terms=Microsoft.Extensions.AI.DelegatingEmbeddingGenerator%602) class is an implementation of the `IEmbeddingGenerator<TInput, TEmbedding>` interface that serves as a base class for creating embedding generators that delegate their operations to another `IEmbeddingGenerator<TInput, TEmbedding>` instance. It allows for chaining multiple generators in any order, passing calls through to an underlying generator. The class provides default implementations for methods such as [Microsoft.Extensions.AI.DelegatingEmbeddingGenerator`2.GenerateAsync*](https://learn.microsoft.com/search/?terms=Microsoft.Extensions.AI.DelegatingEmbeddingGenerator%602.GenerateAsync*) and `Dispose`, which forward the calls to the inner generator instance, enabling flexible and modular embedding generation.
