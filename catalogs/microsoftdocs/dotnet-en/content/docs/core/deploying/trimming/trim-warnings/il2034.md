# IL2034: 'DynamicDependencyAttribute' could not be analyzed

## Cause

Application contains an invalid use of [System.Diagnostics.CodeAnalysis.DynamicDependencyAttribute](https://learn.microsoft.com/search/?terms=System.Diagnostics.CodeAnalysis.DynamicDependencyAttribute).
Ensure that you are using one of the officially supported constructors.
