# Build apps with .NET

.NET has support for building many kinds of apps, including client, cloud, and gaming.

## Cloud apps

* [Aspire](https://aspire.dev/)
* [Serverless functions](https://learn.microsoft.com/azure/azure-functions/functions-create-first-function-vs-code?pivots=programming-language-csharp)
* [Web and microservices](https://learn.microsoft.com/aspnet/core/introduction-to-aspnet-core#recommended-learning-path)

## Client apps

* [Mobile](https://learn.microsoft.com/dotnet/maui)
* [Games](https://dotnet.microsoft.com/apps/games)
* [Desktop apps](https://learn.microsoft.com/dotnet/desktop/)
