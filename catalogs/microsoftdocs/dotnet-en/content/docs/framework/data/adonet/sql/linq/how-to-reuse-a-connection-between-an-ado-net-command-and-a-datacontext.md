# How to: Reuse a Connection Between an ADO.NET Command and a DataContext

Because LINQ to SQL
 is a part of the ADO.NET family of technologies and is based on services provided by ADO.NET, you can reuse a connection between an ADO.NET command and a [System.Data.Linq.DataContext](https://learn.microsoft.com/search/?terms=System.Data.Linq.DataContext).
