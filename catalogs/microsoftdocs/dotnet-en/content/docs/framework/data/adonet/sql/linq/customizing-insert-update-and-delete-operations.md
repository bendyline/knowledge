# Customizing Insert, Update, and Delete Operations

By default, LINQ to SQL
 generates dynamic SQL to implement insert, read, update, and delete operations. In practice, however, you typically customize your application to suit your business needs.  
  
> **Note:**
> If you are using Visual Studio, you can use the Object Relational Designer to customize insert, update, and delete actions.  
  
 This section of topics describes the techniques that LINQ to SQL
 provides for customizing insert, read, update, and delete operations in your application.
