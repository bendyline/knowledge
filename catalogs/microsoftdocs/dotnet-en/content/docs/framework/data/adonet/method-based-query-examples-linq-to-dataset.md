# Method-Based Query Examples (LINQ to DataSet)

This section provides LINQ to DataSet programming examples in method-based query syntax that use the standard query operators. The [System.Data.DataSet](https://learn.microsoft.com/search/?terms=System.Data.DataSet) used in these examples is populated by using the `FillDataSet` method, which is specified in [Loading Data Into a DataSet](loading-data-into-a-dataset.md). For more information, see [Standard Query Operators Overview (C#)](../../../csharp/linq/standard-query-operators/index.md) or [Standard Query Operators Overview (Visual Basic)](../../../visual-basic/programming-guide/concepts/linq/standard-query-operators-overview.md).

## In This Section

 [Projection](method-based-query-syntax-examples-projection.md)
 The examples in this topic demonstrate how to use the [System.Linq.Enumerable.Select*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Select*) and [System.Linq.Enumerable.SelectMany*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.SelectMany*) methods to query a [System.Data.DataSet](https://learn.microsoft.com/search/?terms=System.Data.DataSet).

 [Partitioning](method-based-query-syntax-examples-partitioning-linq.md)
 The examples in this topic demonstrate how to use the [System.Linq.Enumerable.Skip*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Skip*) and [System.Linq.Enumerable.Take*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Take*) methods to query a [System.Data.DataSet](https://learn.microsoft.com/search/?terms=System.Data.DataSet) and partition the results.

 [Ordering](method-based-query-syntax-examples-ordering-linq-to-dataset.md)
 The examples in this topic demonstrate how to use the [System.Linq.Enumerable.OrderBy*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.OrderBy*), [System.Linq.Enumerable.OrderByDescending*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.OrderByDescending*), [System.Linq.Enumerable.Reverse*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Reverse*), and [System.Linq.Enumerable.ThenByDescending*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.ThenByDescending*) methods to query a [System.Data.DataSet](https://learn.microsoft.com/search/?terms=System.Data.DataSet) and order the results.

 [Set Operators](method-based-query-syntax-examples-set-operators.md)
 The examples in this topic demonstrate how to use the [System.Linq.Enumerable.Distinct*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Distinct*), [System.Linq.Enumerable.Except*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Except*), [System.Linq.Enumerable.Intersect*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Intersect*), and [System.Linq.Enumerable.Union*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Union*) operators to perform value-based comparison operations on sets of data rows.

 [Conversion Operators](method-based-query-syntax-examples-conversion-operators.md)
 The examples in this topic demonstrate how to use the [System.Linq.Enumerable.ToArray*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.ToArray*), [System.Linq.Enumerable.ToDictionary*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.ToDictionary*), and [System.Linq.Enumerable.ToList*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.ToList*) methods to immediately execute a query expression.

 [Element Operators](method-based-query-syntax-examples-element-operators.md)
 The examples in this topic demonstrate how to use the [System.Linq.Enumerable.First*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.First*) and [System.Linq.Enumerable.ElementAt*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.ElementAt*) methods to get [System.Data.DataRow](https://learn.microsoft.com/search/?terms=System.Data.DataRow) elements from a [System.Data.DataSet](https://learn.microsoft.com/search/?terms=System.Data.DataSet).

 [Aggregate Operators](method-based-query-syntax-examples-aggregate-operators.md)
 The examples in this topic demonstrate how to use the [System.Linq.Enumerable.Average*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Average*), [System.Linq.Enumerable.Count*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Count*), [System.Linq.Enumerable.Max*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Max*), [System.Linq.Enumerable.Min*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Min*), and [System.Linq.Enumerable.Sum*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Sum*) methods to query a [System.Data.DataSet](https://learn.microsoft.com/search/?terms=System.Data.DataSet) and aggregate data.

 [Join](method-based-query-syntax-examples-join-linq-to-dataset.md)
 The examples in this topic demonstrate how to use the [System.Linq.Enumerable.GroupJoin*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.GroupJoin*) and [System.Linq.Enumerable.Join*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Join*) methods to query a [System.Data.DataSet](https://learn.microsoft.com/search/?terms=System.Data.DataSet).
