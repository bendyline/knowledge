# Count the Number of Elements in a Sequence

Use the [System.Linq.Enumerable.Count*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Count*) operator to count the number of elements in a sequence.

 Running this query against the Northwind sample database produces an output of `91`.
