# How to: Represent Columns as Allowing Null Values

Use the LINQ to SQL
 [System.Data.Linq.Mapping.ColumnAttribute.CanBeNull](https://learn.microsoft.com/search/?terms=System.Data.Linq.Mapping.ColumnAttribute.CanBeNull) property on the [System.Data.Linq.Mapping.ColumnAttribute](https://learn.microsoft.com/search/?terms=System.Data.Linq.Mapping.ColumnAttribute) attribute to specify that the associated database column can hold null values.  
  
 For code examples, see [System.Data.Linq.Mapping.ColumnAttribute.CanBeNull](https://learn.microsoft.com/search/?terms=System.Data.Linq.Mapping.ColumnAttribute.CanBeNull).  
  
### To designate a column as allowing null values  
  
1. Add the [System.Data.Linq.Mapping.ColumnAttribute.CanBeNull](https://learn.microsoft.com/search/?terms=System.Data.Linq.Mapping.ColumnAttribute.CanBeNull) property to the [System.Data.Linq.Mapping.ColumnAttribute](https://learn.microsoft.com/search/?terms=System.Data.Linq.Mapping.ColumnAttribute) attribute.  
  
2. Set the [System.Data.Linq.Mapping.ColumnAttribute.CanBeNull](https://learn.microsoft.com/search/?terms=System.Data.Linq.Mapping.ColumnAttribute.CanBeNull) property value to `true`.
