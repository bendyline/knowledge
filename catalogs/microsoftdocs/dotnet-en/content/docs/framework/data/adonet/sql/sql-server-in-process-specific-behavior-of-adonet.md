# SQL Server In-Process-Specific Behavior of ADO.NET

There are four main functional extensions to ADO.NET, found in the [Microsoft.SqlServer.Server](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Server) namespace, that are specifically for in-process use: [Microsoft.SqlServer.Server.SqlContext](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Server.SqlContext), [Microsoft.SqlServer.Server.SqlPipe](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Server.SqlPipe), [Microsoft.SqlServer.Server.SqlTriggerContext](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Server.SqlTriggerContext), and [Microsoft.SqlServer.Server.SqlDataRecord](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Server.SqlDataRecord).  
  
For more detailed information, see [SQL Server In-Process Specific Extensions to ADO.NET](https://learn.microsoft.com/sql/relational-databases/clr-integration-data-access-in-process-ado-net/sql-server-in-process-specific-extensions-to-ado-net).
