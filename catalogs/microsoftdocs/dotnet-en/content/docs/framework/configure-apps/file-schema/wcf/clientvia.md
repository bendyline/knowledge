# `<clientVia>`

Specifies the URI for which the transport channel should be created. For more information, see [System.ServiceModel.Description.ClientViaBehavior](https://learn.microsoft.com/search/?terms=System.ServiceModel.Description.ClientViaBehavior).

## Syntax

```xml
<clientVia viaUri="String" />
```

## Attributes and Elements

 The following sections describe attributes, child elements, and parent elements.

### Attributes

| Attribute | Description |
| --- | --- |
| `viaUri` | A string that specifies a URI that indicates the route a message should take. |

### Child Elements

 None

### Parent Elements

| Element | Description |
| --- | --- |
| [\<behavior>](behavior-of-endpointbehaviors.md) | Specifies an endpoint behavior. |
