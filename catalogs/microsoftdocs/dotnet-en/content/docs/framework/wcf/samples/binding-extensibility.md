# Binding Extensibility

This section contains samples that demonstrate custom binding in Windows Communication Foundation (WCF).

## In This Section

 [System.ServiceModel.NetHttpBinding](https://learn.microsoft.com/search/?terms=System.ServiceModel.NetHttpBinding)
Demonstrates how to implement a binding that stacks [System.ServiceModel.Channels.HttpTransportBindingElement](https://learn.microsoft.com/search/?terms=System.ServiceModel.Channels.HttpTransportBindingElement) or the [System.ServiceModel.Channels.HttpsTransportBindingElement](https://learn.microsoft.com/search/?terms=System.ServiceModel.Channels.HttpsTransportBindingElement) on top of the [System.ServiceModel.Channels.BinaryMessageEncodingBindingElement](https://learn.microsoft.com/search/?terms=System.ServiceModel.Channels.BinaryMessageEncodingBindingElement).

 [WSStreamedHttpBinding](wsstreamedhttpbinding.md)
Demonstrates how to create a binding that is designed to support streaming scenarios when the HTTP transport is used.
