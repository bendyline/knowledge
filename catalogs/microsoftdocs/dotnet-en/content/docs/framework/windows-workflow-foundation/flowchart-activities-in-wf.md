# Flowchart Activities in WF

.NET Framework 4.6.1
 provides several system-provided activities for controlling execution and branching within a Flowchart.

| Activity type | Description |
| --- | --- |
| [System.Activities.Statements.Flowchart](https://learn.microsoft.com/search/?terms=System.Activities.Statements.Flowchart) | Executes contained activities using the familiar Flowchart paradigm. |
| [System.Activities.Statements.FlowDecision](https://learn.microsoft.com/search/?terms=System.Activities.Statements.FlowDecision) | A specialized [System.Activities.Statements.FlowNode](https://learn.microsoft.com/search/?terms=System.Activities.Statements.FlowNode) that provides the ability to model a conditional node with two outcomes. |
| [System.Activities.Statements.FlowSwitch`1](https://learn.microsoft.com/search/?terms=System.Activities.Statements.FlowSwitch%601) | A specialized [System.Activities.Statements.FlowNode](https://learn.microsoft.com/search/?terms=System.Activities.Statements.FlowNode) that allows modeling a switch construct, with one expression of a type defined in the activity’s type specifier and a single outcome for each match. |
