# Error Handling Activities in WF

.NET Framework 4.6.1
 provides several system-provided activities for implementing error handling and recovery. For more information, see [Exceptions](exceptions.md).  
  
## Error handling activities  
  
| Activity type | Description |
| --- | --- |
| [System.Activities.Statements.Rethrow](https://learn.microsoft.com/search/?terms=System.Activities.Statements.Rethrow) | Rethrows the last exception thrown from within a `TryCatch` activity. |
| [System.Activities.Statements.Throw](https://learn.microsoft.com/search/?terms=System.Activities.Statements.Throw) | Throws an exception. |
| [System.Activities.Statements.TryCatch](https://learn.microsoft.com/search/?terms=System.Activities.Statements.TryCatch) | Implements exception handling. |
