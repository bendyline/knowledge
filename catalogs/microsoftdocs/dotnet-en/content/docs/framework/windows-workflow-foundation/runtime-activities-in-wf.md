# Runtime Activities in WF

.NET Framework 4.6.1 provides several system-provided activities for accessing the features of the workflow runtime, such as persistence and termination.

| Activity | Description |
| --- | --- |
| [System.Activities.Statements.Persist](https://learn.microsoft.com/search/?terms=System.Activities.Statements.Persist) | Explicitly requests that the workflow persist its state. |
| [System.Activities.Statements.TerminateWorkflow](https://learn.microsoft.com/search/?terms=System.Activities.Statements.TerminateWorkflow) | Terminates the running workflow instance. |
| [System.Activities.Statements.NoPersistScope](https://learn.microsoft.com/search/?terms=System.Activities.Statements.NoPersistScope) | A container activity that prevents child activities from persisting. |
