# Navigate .NET docs

Use one of the following mechanisms to find other .NET documentation that you might be interested in:

- The drop-down menus on the header.

  .NET L2 header on learn.microsoft.com

- The breadcrumb trail. From any article, select an entry in the breadcrumb trail. The ".NET" breadcrumb navigates to the [.NET documentation](https://github.com/dotnet/docs/blob/77bc2511d224447ac13474e7757e3600ad30c3de/docs/index.yml) page where you can find another area that interests you. Or, select a different breadcrumb to see an overview for that topic.

  .NET docs breadcrumb
