# Usage guidelines

This section contains guidelines for using common types in publicly accessible APIs. It deals with direct usage of built-in Framework types (e.g., serialization attributes) and overloading common operators.

The [System.IDisposable](https://learn.microsoft.com/search/?terms=System.IDisposable) interface is not covered in this section, but is discussed in the [Dispose Pattern](dispose-pattern.md) section.

> **Note:**
> For guidelines and additional information about other common, built-in .NET Framework types, see the reference topics for the following: [System.DateTime](https://learn.microsoft.com/search/?terms=System.DateTime), [System.DateTimeOffset](https://learn.microsoft.com/search/?terms=System.DateTimeOffset), [System.ICloneable](https://learn.microsoft.com/search/?terms=System.ICloneable), [System.IComparable`1](https://learn.microsoft.com/search/?terms=System.IComparable%601), [System.IEquatable`1](https://learn.microsoft.com/search/?terms=System.IEquatable%601), [System.Nullable`1](https://learn.microsoft.com/search/?terms=System.Nullable%601), [System.Object](https://learn.microsoft.com/search/?terms=System.Object), [System.Uri](https://learn.microsoft.com/search/?terms=System.Uri).
