# Editing XML Data using XPathNavigator

The [System.Xml.XPath.XPathNavigator](https://learn.microsoft.com/search/?terms=System.Xml.XPath.XPathNavigator) class provides methods to insert, modify and remove nodes and values from an XML document contained in an [System.Xml.XmlDocument](https://learn.microsoft.com/search/?terms=System.Xml.XmlDocument) object. In order to use any of these methods to insert, modify, and remove nodes and values, the [System.Xml.XPath.XPathNavigator](https://learn.microsoft.com/search/?terms=System.Xml.XPath.XPathNavigator) object must be editable, that is, its [System.Xml.XPath.XPathNavigator.CanEdit](https://learn.microsoft.com/search/?terms=System.Xml.XPath.XPathNavigator.CanEdit) property must be true.

 [Modify XML Data using XPathNavigator](modify-xml-data-using-xpathnavigator.md)  
 Describes how to modify nodes and values in an [System.Xml.XmlDocument](https://learn.microsoft.com/search/?terms=System.Xml.XmlDocument) object using the [System.Xml.XPath.XPathNavigator](https://learn.microsoft.com/search/?terms=System.Xml.XPath.XPathNavigator) class.
