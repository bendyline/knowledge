# Reference (LINQ to XML)

This article contains links to the LINQ to XML reference articles.

For reference documentation for the LINQ to XML classes, see [System.Xml.Linq](https://learn.microsoft.com/search/?terms=System.Xml.Linq).

For reference documentation for the extension methods that help you validate XML trees against an XSD file, see [System.Xml.Schema.Extensions](https://learn.microsoft.com/search/?terms=System.Xml.Schema.Extensions).

For reference documentation for the extension methods that enable you to evaluate XPath queries on an XML tree, see [System.Xml.XPath.Extensions](https://learn.microsoft.com/search/?terms=System.Xml.XPath.Extensions).
