# CA2242: Test for NaN correctly

| Property | Value |
| --- | --- |
| **Rule ID** | CA2242 |
| **Title** | Test for NaN correctly |
| **Category** | [Usage](usage-warnings.md) |
| **Fix is breaking or non-breaking** | Non-breaking |
| **Enabled by default in .NET 10** | As suggestion |
| **Applicable languages** | C# and Visual Basic |

## Cause

An expression tests a value against [System.Single.NaN](https://learn.microsoft.com/search/?terms=System.Single.NaN) or [System.Double.NaN](https://learn.microsoft.com/search/?terms=System.Double.NaN).

## Rule description

[System.Double.NaN](https://learn.microsoft.com/search/?terms=System.Double.NaN), which represents a value that's not a number, results when an arithmetic operation is undefined. Any expression that tests for equality between a value and [System.Double.NaN](https://learn.microsoft.com/search/?terms=System.Double.NaN) always returns `false`. Any expression that tests for inequality (`!=` in C#) between a value and [System.Double.NaN](https://learn.microsoft.com/search/?terms=System.Double.NaN) always returns `true`.

## How to fix violations

To fix a violation of this rule and accurately determine whether a value represents [System.Double.NaN](https://learn.microsoft.com/search/?terms=System.Double.NaN), use [System.Single.IsNaN*](https://learn.microsoft.com/search/?terms=System.Single.IsNaN*) or [System.Double.IsNaN*](https://learn.microsoft.com/search/?terms=System.Double.IsNaN*) to test the value.

## When to suppress warnings

Do not suppress a warning from this rule.
