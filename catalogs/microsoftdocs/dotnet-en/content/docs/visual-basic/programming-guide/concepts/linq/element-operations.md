# Element Operations (Visual Basic)

Element operations return a single, specific element from a sequence.

 The standard query operator methods that perform element operations are listed in the following section.

## Methods

| Method Name | Description | Visual Basic Query Expression Syntax | More Information |
| --- | --- | --- | --- |
| ElementAt | Returns the element at a specified index in a collection. | Not applicable. | [System.Linq.Enumerable.ElementAt*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.ElementAt*)<br /><br /> [System.Linq.Queryable.ElementAt*](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.ElementAt*) |
| ElementAtOrDefault | Returns the element at a specified index in a collection or a default value if the index is out of range. | Not applicable. | [System.Linq.Enumerable.ElementAtOrDefault*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.ElementAtOrDefault*)<br /><br /> [System.Linq.Queryable.ElementAtOrDefault*](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.ElementAtOrDefault*) |
| First | Returns the first element of a collection, or the first element that satisfies a condition. | Not applicable. | [System.Linq.Enumerable.First*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.First*)<br /><br /> [System.Linq.Queryable.First*](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.First*) |
| FirstOrDefault | Returns the first element of a collection, or the first element that satisfies a condition. Returns a default value if no such element exists. | Not applicable. | [System.Linq.Enumerable.FirstOrDefault*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.FirstOrDefault*)<br /><br /> [System.Linq.Queryable.FirstOrDefault*](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.FirstOrDefault*)<br /><br /> [System.Linq.Queryable.FirstOrDefault``1%28System.Linq.IQueryable%7B``0%7D%29](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.FirstOrDefault%60%601%2528System.Linq.IQueryable%257B%60%600%257D%2529) |
| Last | Returns the last element of a collection, or the last element that satisfies a condition. | Not applicable. | [System.Linq.Enumerable.Last*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Last*)<br /><br /> [System.Linq.Queryable.Last*](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.Last*) |
| LastOrDefault | Returns the last element of a collection, or the last element that satisfies a condition. Returns a default value if no such element exists. | Not applicable. | [System.Linq.Enumerable.LastOrDefault*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.LastOrDefault*)<br /><br /> [System.Linq.Queryable.LastOrDefault*](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.LastOrDefault*) |
| Single | Returns the only element of a collection, or the only element that satisfies a condition. | Not applicable. | [System.Linq.Enumerable.Single*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.Single*)<br /><br /> [System.Linq.Queryable.Single*](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.Single*) |
| SingleOrDefault | Returns the only element of a collection, or the only element that satisfies a condition. Returns a default value if no such element exists or the collection does not contain exactly one element. | Not applicable. | [System.Linq.Enumerable.SingleOrDefault*](https://learn.microsoft.com/search/?terms=System.Linq.Enumerable.SingleOrDefault*)<br /><br /> [System.Linq.Queryable.SingleOrDefault*](https://learn.microsoft.com/search/?terms=System.Linq.Queryable.SingleOrDefault*) |
