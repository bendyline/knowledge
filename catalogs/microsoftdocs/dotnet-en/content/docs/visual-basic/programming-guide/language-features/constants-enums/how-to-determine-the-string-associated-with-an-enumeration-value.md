# How to: Determine the String Associated with an Enumeration Value (Visual Basic)

The [System.Enum.GetValues*](https://learn.microsoft.com/search/?terms=System.Enum.GetValues*) and [System.Enum.GetNames*](https://learn.microsoft.com/search/?terms=System.Enum.GetNames*) methods allow you to determine the strings and values associated with enumeration members.

### To determine the string associated with an enumeration

- Use the [System.Enum.GetNames*](https://learn.microsoft.com/search/?terms=System.Enum.GetNames*) method to retrieve the strings associated with the enumeration members. This example declares an enumeration, `flavorEnum`, then uses the [System.Enum.GetNames*](https://learn.microsoft.com/search/?terms=System.Enum.GetNames*) method to display the strings associated with each member.
