# 'WebMethod' attribute will not affect this member because its containing class is not exposed as a web service

The [System.Web.Services.WebMethodAttribute](https://learn.microsoft.com/search/?terms=System.Web.Services.WebMethodAttribute) attribute makes a method callable from remote Web clients, but only when the method's class derives from [System.Web.Services.WebService](https://learn.microsoft.com/search/?terms=System.Web.Services.WebService).  
  
 **Error ID:** BC30771  
  
## To correct this error  
  
- Change the class to derive from [System.Web.Services.WebService](https://learn.microsoft.com/search/?terms=System.Web.Services.WebService).  
  
     — or —  
  
- Remove the [System.Web.Services.WebMethodAttribute](https://learn.microsoft.com/search/?terms=System.Web.Services.WebMethodAttribute) attribute from the method.
