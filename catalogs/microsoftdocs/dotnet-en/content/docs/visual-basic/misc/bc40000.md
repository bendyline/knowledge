# '\<elementname>' is obsolete: '\<errormessage>'

A statement attempts to access a programming element which has been marked with the [System.ObsoleteAttribute](https://learn.microsoft.com/search/?terms=System.ObsoleteAttribute) attribute and the directive to treat it as a warning.

 You can mark any programming element as being no longer in use by applying [System.ObsoleteAttribute](https://learn.microsoft.com/search/?terms=System.ObsoleteAttribute) to it. If you do this, you can set the attribute's [System.ObsoleteAttribute.IsError](https://learn.microsoft.com/search/?terms=System.ObsoleteAttribute.IsError) property to either `True` or `False`. If you set it to `True`, the compiler treats an attempt to use the element as an error. If you set it to `False`, or let it default to `False`, the compiler issues a warning if there is an attempt to use the element.

 By default, this message is a warning, because the [System.ObsoleteAttribute.IsError](https://learn.microsoft.com/search/?terms=System.ObsoleteAttribute.IsError) property of [System.ObsoleteAttribute](https://learn.microsoft.com/search/?terms=System.ObsoleteAttribute) is `False`. For more information about hiding warnings or treating warnings as errors, see [Configuring Warnings in Visual Basic](https://learn.microsoft.com/visualstudio/ide/configuring-warnings-in-visual-basic).

 **Error ID:** BC40000

## To correct this error

1. Examine the quoted error message and take appropriate action.

2. Ensure that the source code reference is spelling the element name correctly.
