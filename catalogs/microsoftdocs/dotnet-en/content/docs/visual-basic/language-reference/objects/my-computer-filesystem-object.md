# My.Computer.FileSystem Object

Provides properties and methods for working with drives, files, and directories.  
  
## Remarks  

 For information about the methods and properties of the `My.Computer.FileSystem` object, see [Microsoft.VisualBasic.FileIO.FileSystem](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileIO.FileSystem).  
  
 For more information, see [File Access with Visual Basic](../../developing-apps/programming/drives-directories-files/file-access.md).  
  
> **Note:**
> You can also use classes in the [System.IO](https://learn.microsoft.com/search/?terms=System.IO) namespace to work with drives, files, and directories.  
  
## Requirements  

 **Namespace:** [Microsoft.VisualBasic.MyServices](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.MyServices)  
  
 **Class:** [Microsoft.VisualBasic.MyServices.FileSystemProxy](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.MyServices.FileSystemProxy) (provides access to [Microsoft.VisualBasic.FileIO.FileSystem](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileIO.FileSystem))  
  
 **Assembly:** Visual Basic Runtime Library (in Microsoft.VisualBasic.dll)
