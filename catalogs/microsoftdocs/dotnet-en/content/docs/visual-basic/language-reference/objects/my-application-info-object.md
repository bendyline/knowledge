# My.Application.Info Object

Provides properties for getting the information about the application, such as the version number, description, loaded assemblies, and so on.  
  
## Remarks  

 For information about the methods and properties of the `My.Application.Info` object, see [Microsoft.VisualBasic.ApplicationServices.AssemblyInfo](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.ApplicationServices.AssemblyInfo).  
  
> **Note:**
> You can use properties of the [System.Diagnostics.FileVersionInfo](https://learn.microsoft.com/search/?terms=System.Diagnostics.FileVersionInfo) class to obtain information about a file on disk.
