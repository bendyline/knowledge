# My.Request Object

Gets the [System.Web.HttpRequest](https://learn.microsoft.com/search/?terms=System.Web.HttpRequest) object for the requested page.  
  
## Remarks  

 The `My.Request` object contains information about the current HTTP request.  
  
 The `My.Request` object is available only for ASP.NET applications.
