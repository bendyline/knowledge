# My.Computer.Registry Object

Provides properties and methods for manipulating the registry.  
  
## Remarks  

 For information about the methods and properties of the `My.Computer.Registry` object, see [Microsoft.VisualBasic.MyServices.RegistryProxy](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.MyServices.RegistryProxy).  
  
 For more information, see [Reading from and Writing to the Registry](../../developing-apps/programming/computer-resources/reading-from-and-writing-to-the-registry.md).  
  
> **Note:**
> You can also manipulate the registry by using methods of the [Microsoft.Win32.Registry](https://learn.microsoft.com/search/?terms=Microsoft.Win32.Registry) class.  
  
## Requirements  

 **Namespace:** [Microsoft.VisualBasic.MyServices](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.MyServices)  
  
 **Class:** [Microsoft.VisualBasic.MyServices.RegistryProxy](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.MyServices.RegistryProxy) (provides access to [Microsoft.Win32.Registry](https://learn.microsoft.com/search/?terms=Microsoft.Win32.Registry))  
  
 **Assembly:** Visual Basic Runtime Library (in Microsoft.VisualBasic.dll)
