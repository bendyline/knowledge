# Errors Summary (Visual Basic)

Visual Basic language keywords and run-time library members are organized by purpose and use.

| Action | Language element |
| --- | --- |
| Generate run-time errors. | [Microsoft.VisualBasic.Collection.Clear*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Collection.Clear*), [Error](../statements/error-statement.md), [Microsoft.VisualBasic.ErrObject.Raise*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.ErrObject.Raise*) |
| Get exceptions. | [Microsoft.VisualBasic.ErrObject.GetException*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.ErrObject.GetException*) |
| Provide error information. | [Microsoft.VisualBasic.Information.Err*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Information.Err*) |
| Trap errors during run time. | [On Error](../statements/on-error-statement.md), [Resume](../statements/resume-statement.md), [Try...Catch...Finally](../statements/try-catch-finally-statement.md) |
| Provide line number of error. | [Microsoft.VisualBasic.ErrObject.Erl*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.ErrObject.Erl*) |
| Provide system error code. | [Microsoft.VisualBasic.ErrObject.LastDllError*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.ErrObject.LastDllError*) |
