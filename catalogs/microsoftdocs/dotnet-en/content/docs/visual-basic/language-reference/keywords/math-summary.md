# Math Summary (Visual Basic)

Visual Basic language keywords and run-time library members are organized by purpose and use.

| Action | Language element |
| --- | --- |
| Derive trigonometric functions. | [System.Math.Atan*](https://learn.microsoft.com/search/?terms=System.Math.Atan*), [System.Math.Cos*](https://learn.microsoft.com/search/?terms=System.Math.Cos*), [System.Math.Sin*](https://learn.microsoft.com/search/?terms=System.Math.Sin*), [System.Math.Tan*](https://learn.microsoft.com/search/?terms=System.Math.Tan*) |
| General calculations. | [System.Math.Exp*](https://learn.microsoft.com/search/?terms=System.Math.Exp*), [System.Math.Log*](https://learn.microsoft.com/search/?terms=System.Math.Log*), [System.Math.Sqrt*](https://learn.microsoft.com/search/?terms=System.Math.Sqrt*) |
| Generate random numbers. | [Microsoft.VisualBasic.VBMath.Randomize*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.VBMath.Randomize*), [Microsoft.VisualBasic.VBMath.Rnd*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.VBMath.Rnd*) |
| Get absolute value. | [System.Math.Abs*](https://learn.microsoft.com/search/?terms=System.Math.Abs*) |
| Get the sign of an expression. | [System.Math.Sign*](https://learn.microsoft.com/search/?terms=System.Math.Sign*) |
| Perform numeric conversions. | [Microsoft.VisualBasic.Conversion.Fix*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Conversion.Fix*), [Microsoft.VisualBasic.Conversion.Int*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Conversion.Int*) |
