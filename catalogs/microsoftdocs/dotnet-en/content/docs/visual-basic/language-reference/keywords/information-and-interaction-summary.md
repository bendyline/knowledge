# Information and Interaction Summary (Visual Basic)

Visual Basic language keywords and run-time library members are organized by purpose and use.

| Action | Language element |
| --- | --- |
| Run other programs. | [Microsoft.VisualBasic.Interaction.AppActivate*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.AppActivate*), [Microsoft.VisualBasic.Interaction.Shell*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.Shell*) |
| Call a method or property. | [Microsoft.VisualBasic.Interaction.CallByName*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.CallByName*) |
| Sound a beep from computer. | [Microsoft.VisualBasic.Interaction.Beep*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.Beep*) |
| Provide a command-line string. | [Microsoft.VisualBasic.Interaction.Command*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.Command*) |
| Manipulate COM objects. | [Microsoft.VisualBasic.Interaction.CreateObject*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.CreateObject*), [Microsoft.VisualBasic.Interaction.GetObject*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.GetObject*) |
| Retrieve color information. | [Microsoft.VisualBasic.Information.QBColor*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Information.QBColor*), [Microsoft.VisualBasic.Information.RGB*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Information.RGB*) |
| Control dialog boxes | [Microsoft.VisualBasic.Interaction.InputBox*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.InputBox*), [Microsoft.VisualBasic.Interaction.MsgBox*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.Interaction.MsgBox*) |
