# Directories and Files Summary (Visual Basic)

Visual Basic language keywords and run-time library members are organized by purpose and use.

 Using the `My` feature gives you greater productivity and performance in file I/O operations than using these members. For more information, see [Microsoft.VisualBasic.FileIO.FileSystem](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileIO.FileSystem).

| **Action** | **Language element** |
| --- | --- |
| Change a directory or folder. | [Microsoft.VisualBasic.FileSystem.ChDir*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.ChDir*) |
| Change the drive. | [Microsoft.VisualBasic.FileSystem.ChDrive*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.ChDrive*) |
| Copy a file. | [Microsoft.VisualBasic.FileSystem.FileCopy*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.FileCopy*) |
| Make a directory or folder. | [Microsoft.VisualBasic.FileSystem.MkDir*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.MkDir*) |
| Remove a directory or folder. | [Microsoft.VisualBasic.FileSystem.RmDir*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.RmDir*) |
| Rename a file, directory, or folder. | [Microsoft.VisualBasic.FileSystem.Rename*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.Rename*) |
| Return the current path. | [Microsoft.VisualBasic.FileSystem.CurDir*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.CurDir*) |
| Return a file's date/time stamp. | [Microsoft.VisualBasic.FileSystem.FileDateTime*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.FileDateTime*) |
| Return file, directory, or label attributes. | [Microsoft.VisualBasic.FileSystem.GetAttr*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.GetAttr*) |
| Return a file's length. | [Microsoft.VisualBasic.FileSystem.FileLen*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.FileLen*) |
| Return a file's name or volume label. | [Microsoft.VisualBasic.FileSystem.Dir*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.Dir*) |
| Set attribute information for a file. | [Microsoft.VisualBasic.FileSystem.SetAttr*](https://learn.microsoft.com/search/?terms=Microsoft.VisualBasic.FileSystem.SetAttr*) |
