### CoerceIsSelectionBoxHighlighted

#### Details

Certain sequences of actions involving a [System.Windows.Controls.ComboBox](https://learn.microsoft.com/search/?terms=System.Windows.Controls.ComboBox) and its data source can result in a [System.NullReferenceException](https://learn.microsoft.com/search/?terms=System.NullReferenceException).

#### Suggestion

If possible, upgrade to .NET Framework 4.6.2.

| Name | Value |
| :--- | :--- |
| Scope | Minor |
| Version | 4.6 |
| Type | Runtime |
