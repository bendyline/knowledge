### Fixed a issue when ListBox stops responding if it contains duplicate value-types

#### Details

Fixed a problem where a virtualizing [System.Windows.Controls.ItemsControl](https://learn.microsoft.com/search/?terms=System.Windows.Controls.ItemsControl) can stop responding during scrolling when its `Items` collection contains duplicate value-typed objects.

| Name | Value |
| :--- | :--- |
| Scope | Major |
| Version | 4.8 |
| Type | Runtime |

#### Affected APIs

Not detectable via API analysis.
