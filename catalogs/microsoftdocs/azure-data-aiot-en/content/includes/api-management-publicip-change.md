When changing from an internal to external virtual network or changing subnets in the network, you can configure a different [public IP address](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/api-management/api-management-using-with-vnet.md#prerequisites). If you don't provide one, an Azure-managed public IP address is automatically configured.
