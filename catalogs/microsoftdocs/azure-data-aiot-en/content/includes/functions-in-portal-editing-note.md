>**Note:**
>In-portal editing is only supported for JavaScript, PowerShell, and C# Script functions.
>Python in-portal editing is supported only when running in the Consumption plan.
>To create a C# Script app that supports in-portal editing, you must choose a runtime **Version** that supports the **in-process model**.  
>
>When possible, you should [develop your functions locally](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/azure-functions/functions-develop-local.md).   
>
>To learn more about the limitations on editing function code in the Azure portal, see [Development limitations in the Azure portal](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/azure-functions/functions-how-to-use-azure-function-app-settings.md#development-limitations-in-the-azure-portal).
