The legacy (old) VPN Gateway SKUs are:

* Standard
* High Performance

If you use legacy SKUs:

* You can configure site-to-site VPN Gateway connections in active-active mode only on the High Performance SKU.
* VPN Gateway doesn't use the Ultra Performance gateway SKU. For information about that SKU, see the [ExpressRoute](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/expressroute/expressroute-about-virtual-network-gateways.md) documentation.
