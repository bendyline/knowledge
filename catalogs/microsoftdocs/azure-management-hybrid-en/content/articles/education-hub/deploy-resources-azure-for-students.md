# Deploy resources with Azure for Students

Azure for Students gives you access to all the services on the Azure platform. This article links to documentation for some popular services, so you can learn about them and deploy resources.

## Prerequisites

You must have an Azure for Students account.

## Get documentation about Azure services

With your Azure for Students subscription, you can:

- Deploy an app by using [Azure App Service](https://learn.microsoft.com/azure/app-service/).
- Deploy a virtual machine by using [Azure Virtual Machines](https://learn.microsoft.com/azure/virtual-machines/).
- Deploy a SQL database by using [Azure SQL](https://learn.microsoft.com/azure/azure-sql/).
- Convert speech to text by using [Azure Speech in Foundry Tools](https://learn.microsoft.com/azure/ai-services/speech-service/index-speech-to-text).
- Customize image recognition by using [Azure AI Custom Vision](https://learn.microsoft.com/azure/ai-services/custom-vision-service/).
