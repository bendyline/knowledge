> **Important:**
> The Azure VPN gateway must be configured in [**active-active**](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/vpn-gateway/about-active-active-gateways.md) mode and have the ASN set to **65515**. It's not a requirement to have BGP enabled on the VPN gateway to communicate with the route server.
