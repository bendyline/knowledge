# Report history methods
  You can use these methods to create and manage item history snapshots.  
  
| Method | Action |
| --- | --- |
| [ReportService2010.ReportingService2010.CreateItemHistorySnapshot%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.CreateItemHistorySnapshot%252A) | Generates an item history snapshot of a specified catalog item. |
| [ReportService2010.ReportingService2010.DeleteItemHistorySnapshot%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.DeleteItemHistorySnapshot%252A) | Deletes an individual item history snapshot for a specified catalog item. |
| [ReportService2010.ReportingService2010.GetItemHistoryLimit%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetItemHistoryLimit%252A) | Returns the item history snapshot limit for a specified catalog item. |
| [ReportService2010.ReportingService2010.GetItemHistoryOptions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetItemHistoryOptions%252A) | Returns the item history snapshot option setting and properties generated for a catalog item. |
| [ReportService2010.ReportingService2010.ListItemHistory%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListItemHistory%252A) | Returns a list of item history snapshots and their properties for a specified catalog item. |
| [ReportService2010.ReportingService2010.SetItemHistoryLimit%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetItemHistoryLimit%252A) | Specifies how many snapshots of an item the report server retains. |
| [ReportService2010.ReportingService2010.SetItemHistoryOptions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetItemHistoryOptions%252A) | Sets item history options that specify when an item history snapshot is created for a specified catalog item. |
