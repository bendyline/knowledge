# Scheduling methods
  You can use these methods to create and manage shared schedules for report execution and delivery, and to cache refresh plans utilized by the report server.  
  
| Method | Action |
| --- | --- |
| [ReportService2010.ReportingService2010.CreateCacheRefreshPlan%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.CreateCacheRefreshPlan%252A) | Creates a cache refresh plan for an item. |
| [ReportService2010.ReportingService2010.CreateSchedule%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.CreateSchedule%252A) | Creates a new shared schedule. |
| [ReportService2010.ReportingService2010.DeleteCacheRefreshPlan%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.DeleteCacheRefreshPlan%252A) | Deletes a cache refresh plan. |
| [ReportService2010.ReportingService2010.DeleteSchedule%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.DeleteSchedule%252A) | Deletes a shared schedule based on a specific schedule ID. |
| [ReportService2010.ReportingService2010.GetCacheRefreshPlanProperties%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetCacheRefreshPlanProperties%252A) | Returns the properties of the specified cache refresh plan. |
| [ReportService2010.ReportingService2010.GetScheduleProperties%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetScheduleProperties%252A) | Returns the values of properties of a shared schedule. |
| [ReportService2010.ReportingService2010.ListCacheRefreshPlans%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListCacheRefreshPlans%252A) | Returns a list of the cache refresh plans associated with a catalog item. |
| [ReportService2010.ReportingService2010.ListScheduledItems%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListScheduledItems%252A) | Returns a list of items that are associated with a shared schedule. |
| [ReportService2010.ReportingService2010.ListSchedules%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListSchedules%252A) | Returns a list of all shared schedules at the report server or the SharePoint site. |
| [ReportService2010.ReportingService2010.ListScheduleStates%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListScheduleStates%252A) | Returns a list of supported schedule states. |
| [ReportService2010.ReportingService2010.PauseSchedule%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.PauseSchedule%252A) | Pauses the execution of a given schedule. |
| [ReportService2010.ReportingService2010.ResumeSchedule%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ResumeSchedule%252A) | Resumes a shared schedule that is paused. |
| [ReportService2010.ReportingService2010.SetCacheRefreshPlanProperties%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetCacheRefreshPlanProperties%252A) | Sets the properties of a cache refresh plan. |
| [ReportService2010.ReportingService2010.SetScheduleProperties%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetScheduleProperties%252A) | Sets the value of properties of a shared schedule. |
