# Rendering and execution methods
  You can use these methods to manage item execution and caching, and report rendering.  
  
| Method | Action |
| --- | --- |
| [ReportService2010.ReportingService2010.FlushCache%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.FlushCache%252A) | Invalidates the cache for an item. |
| [ReportService2010.ReportingService2010.GetCacheOptions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetCacheOptions%252A) | Returns the cache configuration for an item and the settings that describe when the cached copy of the item expires. |
| [ReportService2010.ReportingService2010.GetExecutionOptions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetExecutionOptions%252A) | Returns the execution option and associated settings for an individual item. |
| [ReportService2010.ReportingService2010.ListExecutionSettings%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListExecutionSettings%252A) | Returns a list of supported execution settings. |
| [ReportExecution2005.ReportExecutionService.Render%2A](https://learn.microsoft.com/search/?terms=ReportExecution2005.ReportExecutionService.Render%252A) | Processes the specified report and renders it in a specified format. |
| [ReportService2010.ReportingService2010.SetCacheOptions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetCacheOptions%252A) | Configures an item to be cached and provides settings that specify when the cached copy of the item expires. |
| [ReportService2010.ReportingService2010.SetExecutionOptions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetExecutionOptions%252A) | Sets execution options and associated execution properties for a specified item. |
| [ReportService2010.ReportingService2010.UpdateItemExecutionSnapshot%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.UpdateItemExecutionSnapshot%252A) | Generates an item execution snapshot for a specified item. |
