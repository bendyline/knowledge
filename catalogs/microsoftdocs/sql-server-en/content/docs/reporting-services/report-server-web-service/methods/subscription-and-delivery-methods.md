# Subscription and delivery methods
  You can use these methods to create and manage subscriptions and delivery of catalog items.  
  
| Method | Action |
| --- | --- |
| [ReportService2010.ReportingService2010.CreateDataDrivenSubscription%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.CreateDataDrivenSubscription%252A) | Creates a data-driven subscription for a specified item. |
| [ReportService2010.ReportingService2010.GetDataDrivenSubscriptionProperties%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetDataDrivenSubscriptionProperties%252A) | Returns the properties for a data-driven subscription. |
| [ReportService2010.ReportingService2010.CreateSubscription%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.CreateSubscription%252A) | Creates a subscription for the specified item in the report server database or SharePoint library. |
| [ReportService2010.ReportingService2010.DeleteSubscription%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.DeleteSubscription%252A) | Deletes a subscription from the report server database. |
| [ReportService2010.ReportingService2010.GetSubscriptionProperties%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetSubscriptionProperties%252A) | Returns the properties of a subscription. |
| [ReportService2010.ReportingService2010.ListMySubscriptions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListMySubscriptions%252A) | Retrieves a list of subscriptions that have been created by the current user of the report server or SharePoint site for the given catalog item. |
| [ReportService2010.ReportingService2010.ListSubscriptions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListSubscriptions%252A) | Retrieves a list of subscriptions for a given item. |
| [ReportService2010.ReportingService2010.PrepareQuery%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.PrepareQuery%252A) | Returns a data set containing the fields retrieved by the delivery query for a data-driven subscription. |
| [ReportService2010.ReportingService2010.SetDataDrivenSubscriptionProperties%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetDataDrivenSubscriptionProperties%252A) | Sets the values of properties of a data-driven subscription. |
| [ReportService2010.ReportingService2010.SetSubscriptionProperties%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetSubscriptionProperties%252A) | Sets the values of properties of a subscription. |
