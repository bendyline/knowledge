# Data sources and connection methods
  You can use these methods to set and manage data source connections and credentials.  
  
| Method | Action |
| --- | --- |
| [ReportService2010.ReportingService2010.CreateDataSource%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.CreateDataSource%252A) | Creates a new data source in the report server database or SharePoint library. |
| [ReportService2010.ReportingService2010.DisableDataSource%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.DisableDataSource%252A) | Disables a data source that is enabled. |
| [ReportService2010.ReportingService2010.EnableDataSource%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.EnableDataSource%252A) | Enables a data source that is disabled. |
| [ReportService2010.ReportingService2010.GetDataSourceContents%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetDataSourceContents%252A) | Returns the contents of a data source. |
| [ReportService2010.ReportingService2010.GetItemDataSourcePrompts%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetItemDataSourcePrompts%252A) | Gets the data source prompts for a specified item. |
| [ReportService2010.ReportingService2010.GetItemDataSources%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetItemDataSources%252A) | Returns the data sources for an item in the catalog. |
| [ReportService2010.ReportingService2010.ListDependentItems%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListDependentItems%252A) | Returns a list of catalog items that reference a specified catalog item. |
| [ReportService2010.ReportingService2010.ListSubscriptionsUsingDataSource%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListSubscriptionsUsingDataSource%252A) | Returns a list of subscriptions that are associated with a given data source. |
| [ReportService2010.ReportingService2010.SetDataSourceContents%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetDataSourceContents%252A) | Sets the connection properties that are associated with a data source. |
| [ReportService2010.ReportingService2010.SetItemDataSources%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetItemDataSources%252A) | Sets the data sources for an item in a report server database or SharePoint library. |
| [ReportService2010.ReportingService2010.TestConnectForDataSourceDefinition%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.TestConnectForDataSourceDefinition%252A) | Tests the connection for a data source. This method supports the direct testing of the data source. |
| [ReportService2010.ReportingService2010.TestConnectForItemDataSource%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.TestConnectForItemDataSource%252A) | Tests the connection for a data source. This method supports the testing of published data sources that are used by reports or models and shared data sources. |
