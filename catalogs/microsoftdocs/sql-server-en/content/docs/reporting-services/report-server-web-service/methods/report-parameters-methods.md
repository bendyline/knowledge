# Report parameters methods
  You can use these methods to set and retrieve parameters for reports.  
  
| Method | Action |
| --- | --- |
| [ReportService2010.ReportingService2010.GetItemParameters%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetItemParameters%252A) | Returns parameter properties for a specified item. This method can also be used to validate parameter values against parameters for a specified item. |
| [ReportService2010.ReportingService2010.ListParameterStates%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListParameterStates%252A) | Returns a list of supported parameter states. |
| [ReportService2010.ReportingService2010.ListParameterTypes%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListParameterTypes%252A) | Returns a list of supported parameter types. |
| [ReportService2010.ReportingService2010.SetItemParameters%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetItemParameters%252A) | Sets parameter properties for a specified item. |
