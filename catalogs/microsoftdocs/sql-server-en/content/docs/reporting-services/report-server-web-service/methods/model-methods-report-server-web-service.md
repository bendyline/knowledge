# Model methods - report server web service
  You can use these methods to manage models.  
  
| Method | Action |
| --- | --- |
| [ReportService2010.ReportingService2010.GenerateModel%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GenerateModel%252A) | Generates a default model on top of a shared data source. |
| [ReportService2010.ReportingService2010.GetModelItemPermissions%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetModelItemPermissions%252A) | Retrieves the user permissions that are associated with the model item. |
| [ReportService2010.ReportingService2010.GetModelItemPolicies%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetModelItemPolicies%252A) | Retrieves the policies that are associated with a model item. |
| [ReportService2010.ReportingService2010.GetUserModel%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.GetUserModel%252A) | Returns the semantic piece of a model for the current user. |
| [ReportService2010.ReportingService2010.InheritModelItemParentSecurity%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.InheritModelItemParentSecurity%252A) | Deletes the policies that are associated with a model item and causes the model item to inherit the policies from its parent. |
| [ReportService2010.ReportingService2010.ListModelDrillthroughReports%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListModelDrillthroughReports%252A) | Lists drillthrough reports that are associated with an entity in a model. |
| [ReportService2010.ReportingService2010.ListModelItemChildren%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListModelItemChildren%252A) | Returns an array of model item child elements. |
| [ReportService2010.ReportingService2010.ListModelItemTypes%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListModelItemTypes%252A) | Returns a list of supported model item types. |
| [ReportService2010.ReportingService2010.ListModelPerspectives%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.ListModelPerspectives%252A) | Lists models and perspectives that are available to the user. |
| [ReportService2010.ReportingService2010.RegenerateModel%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.RegenerateModel%252A) | Updates an existing model based on changes to the data source schema. |
| [ReportService2010.ReportingService2010.RemoveAllModelItemPolicies%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.RemoveAllModelItemPolicies%252A) | Deletes all policies that are associated with model items in the specified model. |
| [ReportService2010.ReportingService2010.SetModelDrillthroughReports%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetModelDrillthroughReports%252A) | Associates a set of drillthrough reports together with a model. |
| [ReportService2010.ReportingService2010.SetModelItemPolicies%2A](https://learn.microsoft.com/search/?terms=ReportService2010.ReportingService2010.SetModelItemPolicies%252A) | Sets security policies on a model item. |
