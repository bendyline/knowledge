# Analysis Server &lt;server&gt; (SQL Server Configuration Manager)


**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 on Windows


This is the service that supports Microsoft  Analysis Services 
. To view the properties of the service, right-click the service in the details pane, and then select **Properties**.

For information about  Analysis Services 
, see [What is Analysis Services?](https://learn.microsoft.com/analysis-services/analysis-services-overview)
