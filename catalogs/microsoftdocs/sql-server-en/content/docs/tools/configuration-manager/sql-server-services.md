# SQL Server Services


**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 on Windows


This section contains F1 Help topics for the  SQL Server 
 Services dialog boxes in  SQL Server 
 Configuration Manager.

If you open **SQL Server Configuration Manager** on a node of a cluster that doesn't host the resources, the services show as stopped.

If the nodes of the  SQL Server 
 Services don't populate with the  SQL Server 
 services available on the computer, you might not have sufficient permissions to access Windows Management Instrumentation (WMI).

To configure permissions on WMI, see [Configure WMI to show server status in SQL Server tools](https://learn.microsoft.com/ssms/configure-wmi-to-show-server-status-in-sql-server-tools).
