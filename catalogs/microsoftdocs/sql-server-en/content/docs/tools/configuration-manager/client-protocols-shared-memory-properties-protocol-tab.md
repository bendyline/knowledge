# Client Protocols - Shared Memory Properties (Protocol tab)


**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 on Windows


In  SQL Server 
 Configuration Manager use the **Protocol** tab on the **Shared Memory Properties** dialog box to view or modify shared memory. For more information about connection strings, see [Aliases (SQL Server Configuration Manager)](aliases-sql-server-configuration-manager.md).

## Options

#### Enabled

Possible values are **Yes** and **No**.
