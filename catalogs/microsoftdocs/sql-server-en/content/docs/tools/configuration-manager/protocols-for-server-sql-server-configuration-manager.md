# Protocols for &lt;server&gt; (SQL Server Configuration Manager)


**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 on Windows


To configure the protocols used by the  Database Engine 
, select **Protocols** for the desired server instance in the console pane, right-click the appropriate protocol in the details pane, and then select **Properties**.
