# Extract a script from a trace (SQL Server Profiler)


**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 





This article describes how to extract  Transact-SQL  events from a trace file or table and save them as a  Transact-SQL  script file by using  SQL Server Profiler 
.

## Extract a Transact-SQL script from a trace file or table

1. Open a trace file or table that contains  Transact-SQL  events that you want to save to a  Transact-SQL  script file. For more information, see [Open a trace file (SQL Server Profiler)](open-a-trace-file-sql-server-profiler.md) or [Open a trace table (SQL Server Profiler)](open-a-trace-table-sql-server-profiler.md).

1. On the **File** menu, point to **Export**, point to **Extract SQL Server Events**, and then select **Extract Transact-SQL Events**.

1. In the **Save As** dialog box, type a name for the  Transact-SQL  file, and select **Save**.
