# ServerSettingsGeneralFlag Class

**Applies to:**
 

](../../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  The [ServerSettingsGeneralFlag Class](#serversettingsgeneralflag-class) represents the general flag settings on an instance of  Microsoft 
  SQL Server 
.  
  
 This class can be used to do the following:  
  
-   View the flag name.  
  
-   View and modify the flag value.
