# ClientNetLibInfo Class

**Applies to:**
 

](../../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  The [ClientNetLibInfo Class](#clientnetlibinfo-class) represents information about the client network library.  
  
 The client network library file lets the client instance communicate over a network with an instance of  Microsoft 
  SQL Server 
 using a specific network protocol.
