# ClientSettingsGeneralFlag Class

**Applies to:**
 

](../../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  The [ClientSettingsGeneralFlag Class](#clientsettingsgeneralflag-class) represents the general flag settings on an instance of  Microsoft 
  SQL Server 
 client.  
  
 The [ClientSettingsGeneralFlag Class](#clientsettingsgeneralflag-class) can be used to do the following:  
  
-   View the flag name.  
  
-   View the flag index value.  
  
-   View and modify the flag value.
