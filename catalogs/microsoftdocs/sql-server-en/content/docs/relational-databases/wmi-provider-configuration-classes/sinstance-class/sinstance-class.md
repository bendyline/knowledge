# SInstance Class

**Applies to:**
 

](../../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  The [SInstance Class](#sinstance-class) represents an instance of  Microsoft 
  SQL Server 
.  
  
 The [SInstance Class](#sinstance-class) can be used to manage protocols and network libraries associated with the instance of  SQL Server 
. A security certificate can also be specified for the instance of  SQL Server 
.
