# GeneralFlags Property (SInstance Class)

**Applies to:**
 

](../../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  Gets the general flags associated with the an instance of  Microsoft 
  SQL Server 
.  
  
## Syntax  
  
```  
  
object.GeneralFlags [= value]  
```  
  
## Parts  
 *object*  
 An [SInstance Class](sinstance-class.md) object that represents a server instance.  
  
## Property Value/Return Value  
 An array of objects that represent the general flags supported by the instance of  SQL Server 
.
