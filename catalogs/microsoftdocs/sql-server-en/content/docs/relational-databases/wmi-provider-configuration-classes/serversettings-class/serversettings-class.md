# ServerSettings Class

**Applies to:**
 

](../../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  The [ServerSettings Class](#serversettings-class) represents server settings on an instance of  Microsoft 
  SQL Server 
.  
  
 The [ServerSettings Class](#serversettings-class) allows you to perform the following tasks:  
  
-   Access general flag settings for the instance of  SQL Server 
.  
  
-   Set default values for the instance of  SQL Server 
.  
  
-   Set the security certificate for the instance of  SQL Server 
.
