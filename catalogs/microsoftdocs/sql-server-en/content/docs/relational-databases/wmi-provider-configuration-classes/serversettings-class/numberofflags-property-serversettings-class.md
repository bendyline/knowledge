# NumberOfFlags Property (ServerSettings Class)

**Applies to:**
 

](../../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  Gets the number of general flags associated with the instance of  Microsoft 
  SQL Server 
.  
  
## Syntax  
  
```  
  
object.NumberOfFlags [= value]  
```  
  
## Parts  
 *object*  
 A [ServerSettings Class](serversettings-class.md) object that represents server settings on an instance of  SQL Server 
.  
  
## Property Value/Return Value  
 A **uint32** value that specifies the number of general flags associated with the instance of  SQL Server 
.
