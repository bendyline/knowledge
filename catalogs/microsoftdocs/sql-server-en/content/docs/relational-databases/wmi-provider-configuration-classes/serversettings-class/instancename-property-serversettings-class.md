# InstanceName property (ServerSettings Class)

**Applies to:**
 

](../../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  Gets the name of the instance of  Microsoft 
  SQL Server 
 to which the server settings apply.  
  
## Syntax  
  
```  
  
object.InstanceName [= value]  
```  
  
## Parts  
 *object*  
 A [ServerSettings Class](serversettings-class.md) object that represents the server settings on an instance of  SQL Server 
.  
  
## Property Value/Return Value  
 A string value that specifies the name of the instance of  SQL Server 
.
