# SQL Server data types in the .NET Framework


**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 

The `SqlTypes` library is part of the base class library of the  .NET Framework 
. It provides data types with the same semantics and precision as data types found in the  SQL Server 
 database. This article describes the new semantics to  .NET Framework 
 programmers, and introduces the types implemented in the `System.Data.SqlTypes` namespace that is included in the `System.Data` library.
