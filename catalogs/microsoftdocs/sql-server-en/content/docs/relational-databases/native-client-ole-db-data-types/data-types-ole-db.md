 Native Client OLE DB provider, you must know how the  SQL Server 
 Native Client OLE DB provider maps  SQL Server 
 data types to OLE DB data types when binding parameters or columns in a rowset, and when it uses the **ITableDefinition** interface to create a table in  SQL Server
