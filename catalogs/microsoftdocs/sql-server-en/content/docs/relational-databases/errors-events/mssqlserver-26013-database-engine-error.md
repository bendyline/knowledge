# MSSQLSERVER_26013
 
**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  
## Details  
  
| Attribute | Value |
| :--- | :--- |
| Product Name | SQL Server |
| Event ID | 26013 |
| Event Source | MSSQLSERVER |
| Component | SQLEngine |
| Symbolic Name | SNI_SSL_READY |
| Message Text | The certificate [Cert Hash(sha1) "%hs"] was successfully loaded for encryption. |
  
## Explanation  
This is an informational message. The named certificate was successfully loaded into  SQL Server 
 and can be used for encryption.  
  
## User Action  
No action is necessary.
