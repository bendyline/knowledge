## Details  
  
| Attribute | Value |
| :--- | :--- |
| Product Name | SQL Server |
| Event ID | 12305 |
| Event Source | MSSQLSERVER |
| Component | SQLEngine |
| Symbolic Name | HK_UNSUPPORTED_TABLE_VAR |
| Message Text | Inline table variables are not supported with '*construct*'. |
