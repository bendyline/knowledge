# SQLNumParams

**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)

 


 





  Improvements in the database engine beginning with  SQL Server 2012 (11.x) 
 allow SQLNumParams to obtain more accurate descriptions of the expected results. These more accurate results may differ from the values returned by SQLNumParams in previous versions of  SQL Server 
.  
  
 For more information, see [Metadata Discovery](../native-client/features/metadata-discovery.md).
