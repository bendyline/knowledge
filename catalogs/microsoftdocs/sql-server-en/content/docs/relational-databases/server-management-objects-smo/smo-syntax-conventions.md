   SQL Server 
 Management Objects (SMO) typographical conventions are based on those used in  Microsoft 
 Visual Studio .NET reference materials.  
  
| Convention | Used for |
| --- | --- |
| UPPERCASE | Transact-SQL  statements, macro names, and terms used at the operating system level; file names in text. |
| `monospace` | Sample command lines and program code. |
| *italic* | Variables in text, formulas in text, or terms defined in text. In syntax, italic letters indicate placeholders for information you supply. |
| **bold** | SMO objects, events, methods, or properties; programming terms in text. |
