   SQL Server 
 Management Objects (SMO) has various namespaces. The different namespaces represent different areas of functionality within SMO.  
  
 In  SQL Server 2022 (16.x) 
, the SMO assemblies are located in the C:\Program Files\Microsoft SQL Server\160\SDK\Assemblies folder.  
  
## Namespaces  
 The SMO namespaces are:  
  
| Class | Function |
| --- | --- |
| [Microsoft.SqlServer.Management.Smo](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Management.Smo) | Contains instance classes, utility classes, and enumerations that are used to programmatically manipulate  Microsoft |
  | SQL Server |
| . |
| [Microsoft.SqlServer.Management.Common](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Management.Common) | Contains the classes that are common to Replication Management Objects (RMO) and SMO, such as connection classes. |
| [Microsoft.SqlServer.Management.Smo.Agent](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Management.Smo.Agent) | Contains classes that represent the  SQL Server |
 | Agent. |
| [Microsoft.SqlServer.Management.Smo.Wmi](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Management.Smo.Wmi) | Contains classes that represent the WMI Provider. |
| [Microsoft.SqlServer.Management.Smo.RegisteredServers](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Management.Smo.RegisteredServers) | Contains classes that represent Registered Server. |
| [Microsoft.SqlServer.Management.Smo.Mail](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Management.Smo.Mail) | Contains classes that represent Database Mail. |
| [Microsoft.SqlServer.Management.Smo.Broker](https://learn.microsoft.com/search/?terms=Microsoft.SqlServer.Management.Smo.Broker) | Contains classes that represent the  Service Broker |
| . |
