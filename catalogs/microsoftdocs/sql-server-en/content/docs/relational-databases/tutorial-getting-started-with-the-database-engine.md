# Tutorial: Get started with the Database Engine


**Applies to:**
 

](../sql-server/sql-docs-navigation-guide.md#applies-to)
 

](../sql-server/sql-docs-navigation-guide.md#applies-to)




This tutorial is intended for users who are new to  SQL Server 
 and who have installed  SQL Server 
 or  SQL Server Express 
. This brief tutorial helps you get started using the  Database Engine 
.

## Prerequisites

- [Install SQL Server Management Studio](https://learn.microsoft.com/ssms/install/install)

## Tutorial outcomes

This tutorial shows you how to connect to the  Database Engine 
 using  SQL Server Management Studio 
 on both the local computer and from another computer.

This tutorial is divided into two lessons:

1. [Lesson 1: Connecting to the Database Engine](lesson-1-connecting-to-the-database-engine.md)

   In this lesson, you learn how to connect to the  Database Engine 
 and enable other people to connect.

1. [Lesson 2: Connect from another computer](lesson-2-connecting-from-another-computer.md)

   In this lesson, you learn how to connect to the  Database Engine 
 from a second computer, including enabling protocols, configuring ports, and configuring firewall settings.
