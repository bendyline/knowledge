# Breaking Changes in SQL Server Replication
 
**Applies to:**
 

](../../sql-server/sql-docs-navigation-guide.md#applies-to)
 
  This topic describes breaking changes in  SQL Server 
 Replication. These changes might break applications, scripts, or functionalities that are based on earlier versions of  SQL Server 
. You might encounter these issues when you upgrade.  
  
## Breaking Changes Made in  SQL Server 2016 (13.x) 
  
  SQL Server 2016 (13.x) 
 does not support replication to or from  SQL Server 2005 (9.x) 
 or  SQL Server Compact 
.
