# Using Scrollable Cursors
Using a scrollable cursor requires these three steps:  
  
1.  Determine the cursor capabilities.  
  
2.  Set up the cursor.  
  
3.  Scroll and fetch rows.

-   [Setting Up the Cursor](setting-up-the-cursor.md)  
  
-   [Cursor Characteristics and Cursor Type](cursor-characteristics-and-cursor-type.md)
