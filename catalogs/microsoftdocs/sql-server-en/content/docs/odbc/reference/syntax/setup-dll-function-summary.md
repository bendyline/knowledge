# Setup DLL Function Summary
The following table describes setup DLL functions. For more information about the syntax and semantics for each function, see [Setup DLL API Reference](setup-dll-api-reference.md).  
  
| Task | Function name | Purpose |
| --- | --- | --- |
| Setting up data sources and translators | [ConfigDriver](configdriver-function.md)<br /><br /> [ConfigDSN](configdsn-function.md)<br /><br /> [ConfigTranslator](configtranslator-function.md) | Installs or uninstalls a driver.<br /><br /> Adds, modifies, or deletes a data source.<br /><br /> Returns a default translation option. |
