# Additional Supported ODBC SQL Grammar
The ODBC drivers completely support the Minimum ODBC 2.5 grammar and the following clauses in the Core and Extended ODBC 2.5 grammar. Additional information can be displayed by jumping to the [ALTER TABLE Statement](alter-table-statement.md), [Correlation Names](correlation-names.md), and [Procedure Invocation](procedure-invocation.md) topics.  
  
-   Approximate numeric literal (Core)  
  
-   [ALTER TABLE Statement](alter-table-statement.md) (Core)  
  
-   Binary literals (Extended)  
  
-   [Correlation Names](correlation-names.md) (Core)  
  
-   [Procedure Invocation](procedure-invocation.md) (Extended)  
  
-   [BETWEEN Predicate](between-predicate.md) (Core)  
  
-   [CREATE INDEX Statement](create-index-statement.md)  
  
-   [Date Arithmetic](date-arithmetic.md)  
  
-   [Jet: Date, Time, and Timestamp Literals](jet-date-time-and-timestamp-literals.md)  
  
-   [DROP INDEX Statement](drop-index-statement.md)  
  
-   [Fixed-Width Text File](fixed-width-text-file.md)  
  
-   [GROUP BY expression-list](group-by-expression-list.md)  
  
-   [ORDER BY expression-list](order-by-expression-list.md)  
  
-   [ORDER BY with GROUP BY](order-by-with-group-by.md)  
  
-   EXISTS predicate (Core)  
  
-   IN (*valuelist*) (Core)  
  
-   [Jet: Outer Joins](jet-outer-joins.md) (Extended)  
  
-   SELECT statement (Extended) (including GROUP BY, HAVING, and UNION clauses)  
  
-   Subqueries (SUBSELECTs) (Core)  
  
-   [Scalar Functions](scalar-functions.md)  
  
-   [Table Names](table-names.md)
