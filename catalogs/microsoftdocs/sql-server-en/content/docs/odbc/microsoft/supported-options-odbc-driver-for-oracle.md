# Supported Options (ODBC Driver for Oracle)
> **Important:**  
>  This feature will be removed in a future version of Windows. Avoid using this feature in new development work, and plan to modify applications that currently use this feature. Instead, use the ODBC driver provided by Oracle.  
  
 The ODBC Driver for Oracle supports the following options for the SQLGetConnectOption( ) and SQLSetConnectOption( ) Level 1 functions:  
  
-   SQL_ACCESS_MODE ([SQLGetConnectOption](level-1-api-functions-odbc-driver-for-oracle.md)( ) only)  
  
-   [SQL_AUTOCOMMIT](connect-options.md)  
  
-   [SQL_ODBC_CURSORS](connect-options.md)  
  
-   [SQL_OPT_TRACEFILE](connect-options.md)  
  
-   [SQL_OPT_TRACE](connect-options.md)  
  
-   [SQL_TRANSLATE_DLL](connect-options.md)  
  
-   [SQL_TRANSLATE_OPTION](connect-options.md)  
  
-   [SQL_TXN_ISOLATION](connect-options.md)  
  
 The ODBC Driver for Oracle supports the following options for the SQLGetStmtOption( ) and SQLSetStmtOption( ) Level 1 functions:  
  
-   [SQL_BIND_TYPE](statement-options.md)  
  
-   [SQL_CONCURRENCY](statement-options.md)  
  
-   [SQL_CURSOR_TYPE](statement-options.md)  
  
-   [SQL_KEYSET_SIZE](statement-options.md)  
  
-   [SQL_MAX_ROWS](statement-options.md)  
  
-   [SQL_ROWSET_SIZE](statement-options.md)
