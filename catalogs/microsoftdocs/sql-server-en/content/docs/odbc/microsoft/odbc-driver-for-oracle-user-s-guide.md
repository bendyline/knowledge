# ODBC Driver for Oracle User's Guide
> **Important:**  
>  This feature will be removed in a future version of Windows. Avoid using this feature in new development work, and plan to modify applications that currently use this feature. Instead, use the ODBC driver provided by Oracle.  
  
 The ODBC Driver for Oracle User's Guide is intended to complement the setup help that can be accessed through the [ODBC Data Source Administrator](../admin/odbc-data-source-administrator.md).
