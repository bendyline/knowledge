# SQL Server data type mappings

 **Applies to**:  .NET Framework  .NET  .NET Standard 




SQL Server and the .NET Framework are based on different type systems. For example, the .NET Framework [System.Decimal](https://learn.microsoft.com/search/?terms=System.Decimal) structure has a maximum scale of 28, whereas the SQL Server decimal and numeric data types have a maximum scale of 38. To maintain data integrity when reading and writing data, the  [Microsoft.Data.SqlClient.SqlDataReader](https://learn.microsoft.com/search/?terms=Microsoft.Data.SqlClient.SqlDataReader) exposes SQL Server–specific typed accessor methods that return objects of [System.Data.SqlTypes](https://learn.microsoft.com/search/?terms=System.Data.SqlTypes) as well as accessor methods that return .NET Framework types. Both SQL Server types and .NET Framework types are also represented by enumerations in the [System.Data.DbType](https://learn.microsoft.com/search/?terms=System.Data.DbType) and [System.Data.SqlDbType](https://learn.microsoft.com/search/?terms=System.Data.SqlDbType) classes, which you can use when specifying [Microsoft.Data.SqlClient.SqlParameter](https://learn.microsoft.com/search/?terms=Microsoft.Data.SqlClient.SqlParameter) data types.
