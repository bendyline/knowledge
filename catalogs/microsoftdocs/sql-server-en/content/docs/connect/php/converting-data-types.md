# Converting Data Types



The Microsoft Drivers for PHP for SQL Server
 allows you to specify data types when you send data to or retrieve data from  SQL Server 
. Specifying data types is optional. If data types are not specified, default types are used. The topics in this section describe how to specify data types and provide details about default data types.
