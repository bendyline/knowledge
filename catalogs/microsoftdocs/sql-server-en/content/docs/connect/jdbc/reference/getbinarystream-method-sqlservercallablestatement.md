# getBinaryStream Method (SQLServerCallableStatement)


  Retrieves the value of the designated parameter as a binary stream of uninterrupted bytes.

| Name | Description |
| --- | --- |
| [getBinaryStream (int)](getbinarystream-int.md) | Retrieves the value of the designated parameter as a binary stream of uninterrupted bytes given the parameter index. |
| [getBinaryStream (java.lang.String)](getbinarystream-java-lang-string.md) | Retrieves the value of the designated parameter as a binary stream of uninterrupted bytes given the parameter name. |
