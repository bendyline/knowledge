# getBlob Method (SQLServerCallableStatement)


  Retrieves the value of the designated JDBC BLOB parameter as a Blob object in the Java programming language.  
  
## Overload List  
  
| Name | Description |
| --- | --- |
| [getBlob (int)](getblob-method-int.md) | Retrieves the value of the designated JDBC BLOB parameter as a Blob object in the Java programming language given the parameter index. |
| [getBlob (java.lang.String)](getblob-method-java-lang-string.md) | Retrieves the value of the designated JDBC BLOB parameter as a Blob object in the Java programming language given the parameter name. |
