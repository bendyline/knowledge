# setClob Method (SQLServerPreparedStatement)


  Sets the designated parameter to a java.sql.Clob object.  
  
## Overload List  
  
| Name | Description |
| --- | --- |
| [setClob Method (int, java.io.Reader)](setclob-method-int-java-io-reader.md) | Sets the designated parameter to a java.sql.Clob object. |
| [setClob Method (int, java.sql.Clob)](setclob-method-int-java-sql-clob.md) | Sets the designated parameter to the given java.sql.Clob object. |
| [setClob Method (int, java.io.Reader, long)](setclob-method-int-java-io-reader-long.md) | Sets the designated parameter to a java.sql.Clob object, which is the specified number of characters long. |
  
## Remarks  
 No server driver behavior. For details see JSE 6 API spec.
