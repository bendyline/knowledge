# setSavepoint Method (SQLServerConnection)


  Creates an unnamed savepoint in the current transaction and returns the new [SQLServerSavepoint](sqlserversavepoint-class.md) object that represents it.  
  
## Overload List  
  
| Name | Description |
| --- | --- |
| [setSavepoint ()](setsavepoint-method.md) | Creates an unnamed savepoint in the current transaction and returns the new [SQLServerSavepoint](sqlserversavepoint-class.md) object that represents it. |
| [setSavepoint (java.lang.String)](setsavepoint-method-java-lang-string.md) | Creates a savepoint with the given name in the current transaction and returns the new [SQLServerSavepoint](sqlserversavepoint-class.md) object that represents it. |
