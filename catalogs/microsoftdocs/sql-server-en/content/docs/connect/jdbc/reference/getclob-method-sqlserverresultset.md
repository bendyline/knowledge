# getClob Method (SQLServerResultSet)


  Retrieves the value of the designated column in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as a Clob object in the Java programming language.

| [getClob (java.lang.String)](getclob-method-java-lang-string-sqlserverresultset.md) | Retrieves the value of the designated column name in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as a Clob object in the Java programming language. |
