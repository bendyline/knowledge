# getInstanceName Method (SQLServerDataSource)


  Returns the  SQL Server 
 instance name.  
  
## Syntax  
  
```  
  
public java.lang.String getInstanceName()  
```  
  
## Return Value  
 A **String** that contains the instance name, or null if no value is set.
