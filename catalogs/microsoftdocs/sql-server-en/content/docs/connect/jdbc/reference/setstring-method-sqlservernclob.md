# setString Method (SQLServerNClob)


  Writes the specified **String** to the **NCLOB** starting at the specified position.  
  
## Overload List  
  
| Name | Description |
| --- | --- |
| [setString Method (long, java.lang.String) (SQLServerNClob)](setstring-method-long-java-lang-string-sqlservernclob.md) | Writes the specified **String** to the **NCLOB** starting at the specified position. |
| [setString Method (long, java.lang.String, int, int) (SQLServerNClob)](setstring-method-long-java-lang-string-int-int-sqlservernclob.md) | Writes the specified string to the NCLOB starting at the specified position, and based on the specified offset and length. |
