# clearWarnings Method (SQLServerResultSet)


  Clears all warnings reported on this [SQLServerResultSet](sqlserverresultset-class.md) object.  
  
> **Note:**  
>  This method is not currently implemented by the  Microsoft JDBC Driver for SQL Server 
. If called, it will always return null.  
  
## Syntax  
  
```  
  
public void clearWarnings()  
```  
  
## Exceptions  
 [SQLServerException](sqlserverexception-class.md)  
  
## Remarks  
 This clearWarnings method is specified by the clearWarnings method in the java.sql.ResultSet interface.
