# position Method (SQLServerClob)


  Returns the character position of the specified CLOB object or substring in the CLOB based on the given starting position.

| --- | --- |

| [position (java.lang.String, long)](position-method-java-lang-string-long.md) | Returns the character position of the specified substring in the CLOB based on the given starting position. |
