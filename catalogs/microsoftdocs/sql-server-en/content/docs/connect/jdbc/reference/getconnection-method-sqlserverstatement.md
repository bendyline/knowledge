# getConnection Method (SQLServerStatement)


  Retrieves the [SQLServerConnection](sqlserverconnection-class.md) object that produced this [SQLServerStatement](sqlserverstatement-class.md) object.  
  
## Syntax  
  
```  
  
public final java.sql.Connection getConnection()  
```  
  
## Exceptions  
 [SQLServerException](sqlserverexception-class.md)  
  
## Remarks  
 This getConnection method is specified by the getConnection method in the java.sql.Statement interface.
