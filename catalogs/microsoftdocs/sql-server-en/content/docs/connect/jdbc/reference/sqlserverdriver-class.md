# SQLServerDriver Class


  Represents the  Microsoft JDBC Driver for SQL Server 
. This class includes methods for connecting to a  SQL Server 
 database, and for obtaining information about the JDBC driver.  
  
 **Package:** com.microsoft.sqlserver.jdbc  
  
 **Extends:** java.lang.Object  
  
 **Implements:** java.sql.Driver  
  
## Syntax  
  
```  
  
public final class SQLServerDriver  
```
