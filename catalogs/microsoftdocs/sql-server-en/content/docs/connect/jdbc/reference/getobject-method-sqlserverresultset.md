# getObject Method (SQLServerResultSet)


  Gets the value of the designated column in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as an object in the Java programming language.  
  
## Overload List  
  
| Name | Description |
| --- | --- |
| [getObject (int)](getobject-method-int-sqlserverresultset.md) | Gets the value of the designated column index in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as an object in the Java programming language. |
| [getObject (int, java.util.Map)](getobject-method-int-java-util-map-sqlserverresultset.md) | Gets the value of the designated column index in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as an object in the Java programming language, using the given Map object. |
| [getObject (java.lang.String)](getobject-method-java-lang-string-sqlserverresultset.md) | Gets the value of the designated column name in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as an object in the Java programming language. |
| [getObject (java.lang.String, java.util.Map)](getobject-method-java-lang-string-java-util-map-sqlserverresultset.md) | Gets the value of the designated column name in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as an object in the Java programming language, using the given Map object. |
