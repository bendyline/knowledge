# getSchemas Method (SQLServerDatabaseMetaData)


  Retrieves the schema names that are available in the current database.  
  
## Overload List  
  
| Name | Description |
| --- | --- |
| [getSchemas Method ()](getschemas-method.md) | Retrieves the schema names that are available in the current database. |
| [getSchemas Method (String, String)](getschemas-method-string-string.md) | Retrieves the schema names that are available in the current database by using the specified catalog name and the schema name. |
