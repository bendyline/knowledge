# getArray Method (SQLServerResultSet)


  Retrieves the value of the designated column in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as an Array object.  
  
## Overload List  
  
| Name | Description |
| --- | --- |
| [getArray Method (int)](getarray-method-int-sqlserverresultset.md) | Retrieves the value of the designated column index in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as an Array object. |
| [getArray Method (java.lang.String)](getarray-method-java-lang-string-sqlserverresultset.md) | Retrieves the value of the designated column name in the current row of this [SQLServerResultSet](sqlserverresultset-class.md) object as an Array object. |
