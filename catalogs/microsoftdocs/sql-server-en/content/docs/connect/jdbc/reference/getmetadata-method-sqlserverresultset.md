# getMetaData Method (SQLServerResultSet)


  Retrieves the number, types, and properties of the columns for this [SQLServerResultSet](sqlserverresultset-class.md) object.  
  
## Syntax  
  
```  
  
public java.sql.ResultSetMetaData getMetaData()  
```  
  
## Return Value  
 A [SQLServerResultSetMetaData](sqlserverresultsetmetadata-class.md) object.  
  
## Exceptions  
 [SQLServerException](sqlserverexception-class.md)  
  
## Remarks  
 This getMetaData method is specified by the getMetaData method in the java.sql.ResultSet interface.
