# setCharacterStream Method (SQLServerCallableStatement)


  Sets the designated parameter to the specified  java.io.Reader object.

| [setCharacterStream Method (java.lang.String, java.io.Reader)](setcharacterstream-method-java-lang-string-java-io-reader.md) | Sets the designated parameter to the specified java.io.Reader object. |
| [setCharacterStream Method (java.lang.String, java.io.Reader, int)](setcharacterstream-method-java-lang-string-java-io-reader-int.md) | Sets the designated parameter to the specified java.io.Reader object, which is the specified number of characters long. |
