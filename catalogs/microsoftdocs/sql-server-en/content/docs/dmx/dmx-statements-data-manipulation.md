# DMX Statements - Data Manipulation

**Applies to:**
 

  Analysis Services 



  The following table lists the statements that are part of the data mining data manipulation language (DML) in Data Mining Extensions (DMX).  
  
| Topic | Description |
| --- | --- |
| [DELETE (DMX)](delete-dmx.md) | Clears the trained content from a mining model. |
| [INSERT INTO (DMX)](insert-into-dmx.md) | Trains a mining model. |
| [SELECT (DMX)](select-dmx.md) | Browses a mining model. |
| [\<source data query>](source-data-query.md) | Queries data sources for both **INSERT INTO** and **SELECT** statements. |
| [UPDATE (DMX)](update-dmx.md) | Changes the content in the mining model. |
