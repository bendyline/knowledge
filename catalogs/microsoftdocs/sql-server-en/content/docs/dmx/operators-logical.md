# Operators - Logical

**Applies to:**
 

  Analysis Services 



  You can use logical operators in Data Mining Extensions (DMX) expressions to evaluate values and to return a Boolean value in  Microsoft 
  SQL Server 
  Analysis Services 
.  
  
 The following table identifies the logical operators that DMX supports.  
  
| Operator | Description |
| --- | --- |
| [AND (DMX)](and-dmx.md) | Performs a logical conjunction on two numeric expressions. |
| [NOT (DMX)](not-dmx.md) | Performs a logical negation on a numeric expression. |
| [OR (DMX)](or-dmx.md) | Performs a logical disjunction on two numeric expressions. |
