## Create the custom container

If you haven't already done so, complete the previous quickstart article [Create a function that runs in custom container](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/azure-functions/functions-create-function-linux-custom-image.md) to create and publish a custom container with your first function app. 

This article creates a container image named `azurefunctionsimage` in either Azure Container Registry or Docker Hub. If you chose a different name for your image, you'll need to modify the examples in this article.
