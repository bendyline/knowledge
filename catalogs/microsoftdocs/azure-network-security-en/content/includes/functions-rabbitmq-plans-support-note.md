> **Note:**
> The RabbitMQ bindings are only fully supported on [Elastic Premium](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/azure-functions/functions-premium-plan.md) and [Dedicated (App Service)](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/azure-functions/dedicated-plan.md) plans. [Flex Consumption](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/azure-functions/flex-consumption-plan.md) and [Consumption](https://github.com/MicrosoftDocs/azure-docs/blob/4260367da6fe93d74e80662f882dd4e9f52b8924/articles/azure-functions/consumption-plan.md) plans aren't yet supported.
>
> RabbitMQ bindings aren't supported by the Azure Functions v1.x runtime.
