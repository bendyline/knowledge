**Application software** is [software](https://en.wikipedia.org/wiki/Software) that is intended for [end-user](https://en.wikipedia.org/wiki/End-user) use – not [operating](https://en.wikipedia.org/wiki/Computer_operator), [administering](https://en.wikipedia.org/wiki/System_administration) or [programming](https://en.wikipedia.org/wiki/Computer_programming) a [computer](https://en.wikipedia.org/wiki/Computer). It includes programs such as word processors, web browsers, media players, and mobile applications used in daily tasks. An **application** (**app**, **application program**, **software application**) is any [program](https://en.wikipedia.org/wiki/Computer_program) that can be categorized as application software.[^cite_note-\:3-1][^cite_note-rfc4949-2] Application is a subjective classification that is often used to differentiate from [system](https://en.wikipedia.org/wiki/System_software) and [utility](https://en.wikipedia.org/wiki/Utility_software) software.[^cite_note-3]

Application software represents the **user-facing layer of computing systems**, designed to translate complex system capabilities into task-oriented, goal-driven workflows. Unlike system software, which focuses on hardware orchestration and resource management, application software is centered on **problem abstraction, user interaction,** and **domain-specific functionality.**

The [abbreviation](https://en.wikipedia.org/wiki/Abbreviation) *app* became popular with the 2008 introduction of the [iOS App Store](https://en.wikipedia.org/wiki/App_Store_\(Apple\)), to refer to [applications for mobile devices](https://en.wikipedia.org/wiki/Mobile_app) such as [smartphones](https://en.wikipedia.org/wiki/Smartphone) and [tablets](https://en.wikipedia.org/wiki/Tablet_computer). Later, with the release of the [Mac App Store](https://en.wikipedia.org/wiki/Mac_App_Store) in 2010 and the [Windows Store](https://en.wikipedia.org/wiki/Windows_Store) in 2011, it began to be used to refer to end-user software in general, regardless of platform.[^cite_note-4]

Applications may be bundled with the [computer](https://en.wikipedia.org/wiki/Computer) and its system software or published separately. Applications may be [proprietary](https://en.wikipedia.org/wiki/Proprietary_software) or [open-source](https://en.wikipedia.org/wiki/Open-source_software).[^cite_note-\:1-5]

## Terminology

### Meaning program and software

When used as an adjective, *application* can have a broader meaning than that described in this article.[^cite_note-cutter-6] For example, concepts such as [application programming interface](https://en.wikipedia.org/wiki/Application_programming_interface) (API), [application server](https://en.wikipedia.org/wiki/Application_server), [application virtualization](https://en.wikipedia.org/wiki/Application_virtualization), [application lifecycle management](https://en.wikipedia.org/wiki/Application_lifecycle_management) and [portable application](https://en.wikipedia.org/wiki/Portable_application) refer to programs and software in general.

### Distinction between system and application software

The distinction between [system](https://en.wikipedia.org/wiki/System_software) and application software is subjective and has been the subject of controversy.[^cite_note-cutter-6] For example, one of the key questions in the *[United States v. Microsoft Corp.](https://en.wikipedia.org/wiki/United_States_v._Microsoft_Corp._\(2001\))* [antitrust](https://en.wikipedia.org/wiki/Antitrust) trial was whether Microsoft's [Internet Explorer](https://en.wikipedia.org/wiki/Internet_Explorer) [web browser](https://en.wikipedia.org/wiki/Web_browser) was part of its [Windows](18890.md) operating system or a separate piece of application software. As another example, the [GNU/Linux naming controversy](https://en.wikipedia.org/wiki/GNU/Linux_naming_controversy) is, in part, due to disagreement about the relationship between the [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel) and the operating systems built over this [kernel](https://en.wikipedia.org/wiki/Kernel_\(operating_system\)). In some types of [embedded systems](https://en.wikipedia.org/wiki/Embedded_system), the application software and the operating system software may be indistinguishable by the user, as in the case of software used to control a [VCR](https://en.wikipedia.org/wiki/Videocassette_recorder), [DVD](https://en.wikipedia.org/wiki/DVD) player, or [microwave oven](https://en.wikipedia.org/wiki/Microwave_oven). The above definitions may exclude some applications that may exist on some computers in large organizations. For an alternative definition of an app:&#x20;*&#x20;see [Application Portfolio Management](https://en.wikipedia.org/wiki/Application_portfolio_management#Definition_of_an_application).*

### Killer application

A [killer application](https://en.wikipedia.org/wiki/Killer_application) (killer app, coined in the late 1980s) is an application that is so popular that it causes demand for its host [platform](https://en.wikipedia.org/wiki/Computing_platform) to increase.[^cite_note-7][^cite_note-8] For example, [VisiCalc](https://en.wikipedia.org/wiki/VisiCalc) was the first modern [spreadsheet](https://en.wikipedia.org/wiki/Spreadsheet) software for the [Apple II](https://en.wikipedia.org/wiki/Apple_II) and helped sell the then-new [personal computers](https://en.wikipedia.org/wiki/Personal_computer) into offices. For the [BlackBerry](https://en.wikipedia.org/wiki/BlackBerry), it was its [email](9738.md) software.

### Software suite

A [software suite](https://en.wikipedia.org/wiki/Software_suite) consists of multiple applications bundled together. They usually have related functions, features, and user interfaces, and may be able to interact with each other, e.g. open each other's files. [Business applications](https://en.wikipedia.org/wiki/Business_software) often come in suites, e.g. [Microsoft Office](https://en.wikipedia.org/wiki/Microsoft_Office), [LibreOffice](https://en.wikipedia.org/wiki/LibreOffice) and [iWork](https://en.wikipedia.org/wiki/IWork), which bundle together a word processor, a spreadsheet, etc.; but suites exist for other purposes, e.g. graphics or music.

## Ways to classify



Application software on a mobile phone

As there so many applications and since their attributes vary so dramatically, there are many different ways to classify them.

### By legal aspects

Proprietary software is protected under an exclusive copyright, and a [software license](https://en.wikipedia.org/wiki/Software_license) grants limited usage rights. Such applications may allow [add-ons](https://en.wikipedia.org/wiki/Plug-in_\(computing\)) from third parties.

[Free and open-source software](https://en.wikipedia.org/wiki/Free_and_open-source_software) (FOSS) can be run, distributed, sold, and extended for any purpose. FOSS software released under a [free license](https://en.wikipedia.org/wiki/Free_license) may be [perpetual](https://en.wikipedia.org/wiki/List_of_countries'_copyright_lengths) and also [royalty-free](https://en.wikipedia.org/wiki/Royalty-free). Perhaps, the [owner](https://en.wikipedia.org/wiki/Ownership), the [holder](https://en.wikipedia.org/wiki/Holder_\(law\)) or third-party [enforcer](https://en.wikipedia.org/wiki/Law_enforcer) of any right ([copyright](https://en.wikipedia.org/wiki/Copyright), [trademark](https://en.wikipedia.org/wiki/Trademark), [patent](https://en.wikipedia.org/wiki/Patent), or *[ius in re aliena](https://en.wikipedia.org/wiki/Ius_in_re)*) are entitled to add exceptions, limitations, time decays or expiring dates to the license terms of use.

[Public-domain software](https://en.wikipedia.org/wiki/Public-domain_software) is a type of FOSS that is royalty-free and can be run, distributed, modified, reversed, republished, or created in derivative works without any [copyright attribution](https://en.wikipedia.org/wiki/Attribution_\(copyright\)) and therefore [revocation](https://en.wikipedia.org/wiki/Revocation). It can even be sold, but without transferring the public domain property to other single subjects. Public-domain software can be released under a (un)licensing legal statement, which enforces those terms and conditions for an indefinite duration (for a lifetime, or forever).

### By platform

An application can be categorized by the host [ platform](https://en.wikipedia.org/wiki/Computing_platform) on which it runs. Notable platforms include [operating system](https://en.wikipedia.org/wiki/Operating_system) (native), [web browser](https://en.wikipedia.org/wiki/Web_browser), [cloud computing](19541494.md) and [mobile](https://en.wikipedia.org/wiki/Mobile_app). For example a [web application](https://en.wikipedia.org/wiki/Web_application) runs in a web browser whereas a more traditional, native application runs in the environment of a computer's operating system.[^cite_note-9]

There has been a contentious debate regarding web applications replacing native applications for many purposes, especially on mobile devices such as [smartphones](https://en.wikipedia.org/wiki/Smartphone) and [tablets](https://en.wikipedia.org/wiki/Tablet_computer). Web apps have indeed greatly increased in popularity for some uses, but the advantages of applications make them unlikely to disappear soon, if ever. Furthermore, the two can be complementary, and even integrated.[^cite_note-10][^cite_note-\:0-11][^cite_note-12]

### Horizontal vs. vertical

Application software can be seen as either [horizontal](https://en.wikipedia.org/wiki/Horizontal_market_software) or [vertical](https://en.wikipedia.org/wiki/Vertical_market_software).[^cite_note-13][^cite_note-\:2-14] Horizontal applications are more popular and widespread, because they are general purpose, for example word processors or databases. Vertical applications are [niche products](https://en.wikipedia.org/wiki/Niche_product), designed for a particular type of industry or business, or department within an organization. Integrated suites of software will try to handle every specific aspect possible of, for example, manufacturing or banking worker, accounting, or customer service.

### By purpose

There are many types of application software:[^cite_note-15]

[Enterprise](https://en.wikipedia.org/wiki/Enterprise_software)

Addresses the needs of an entire organization's processes and data flows, across several departments, often in a large distributed environment. Examples include [enterprise resource planning](https://en.wikipedia.org/wiki/Enterprise_resource_planning) systems, [customer relationship management](https://en.wikipedia.org/wiki/Customer_relationship_management) (CRM) systems, [data replication](https://en.wikipedia.org/wiki/Replication_\(computing\)) engines, and [supply chain management software](https://en.wikipedia.org/wiki/Supply_chain_management_software). Departmental Software is a sub-type of enterprise software with a focus on smaller organizations or groups within a large organization. (Examples include travel [expense management](https://en.wikipedia.org/wiki/Expense_management) and IT Helpdesk.)

Enterprise infrastructure

Provides common capabilities needed to support enterprise [software systems](https://en.wikipedia.org/wiki/Software_system). (Examples include databases, email servers, and systems for managing networks and security.)

[Application platform as a service](https://en.wikipedia.org/wiki/Application_platform_as_a_service) (aPaaS)

A [cloud computing](19541494.md) service that offers development and deployment environments for application services.

[Knowledge worker](https://en.wikipedia.org/wiki/Knowledge_worker)

Lets users create and manage information, often for and individual media editors may aid in multiple information worker tasks.

Content access

Used primarily to access content without editing, but may include software that allows for content editing. Such software addresses the needs of individuals and groups to consume [digital entertainment](https://en.wikipedia.org/wiki/Digital_entertainment) and published digital content. (Examples include [media players](https://en.wikipedia.org/wiki/Media_player_\(application_software\)), [web browsers](https://en.wikipedia.org/wiki/Web_browser), and help browsers.)

[Educational](https://en.wikipedia.org/wiki/Educational_software)

Related to content access software, but has the content or features adapted for use by educators or students. For example, it may deliver evaluations (tests), track progress through material, or include collaborative capabilities.

[ Simulation](https://en.wikipedia.org/wiki/Simulation_software)

Simulates physical or abstract systems for either research, training, or entertainment purposes.

Media development

Generates print and electronic media for others to consume, most often in a commercial or educational setting. This includes [graphic-art software](https://en.wikipedia.org/wiki/Graphic_art_software), desktop publishing software, multimedia development software, HTML editors, digital-animation editors, digital audio and video composition, and many others.

[^cite_note-16]

Engineering

Used in developing hardware and software products. This includes [computer-aided design](https://en.wikipedia.org/wiki/Computer-aided_design) (CAD), [computer-aided engineering](https://en.wikipedia.org/wiki/Computer-aided_engineering) (CAE), computer language editing and compiling tools, [integrated development environments](https://en.wikipedia.org/wiki/Integrated_development_environment), and application programmer interfaces.

Entertainment

Refers to video games, screen savers, programs to display motion pictures or play recorded music, and other forms of entertainment which can be experienced through the use of a computing device.
