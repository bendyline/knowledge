# Public holidays in Morocco

## Movable holidays

The following holidays are public holidays but the date on which each occurs corresponds to the [Islamic calendar](https://en.wikipedia.org/wiki/Islamic_calendar), and thus has no set date.

| Date | English name | Local name | Description |
| --- | --- | --- | --- |
| [Muharram 1](https://en.wikipedia.org/wiki/Muharram) | [Islamic New Year](https://en.wikipedia.org/wiki/Islamic_New_Year) | *Fātiḥ muḥarram* | First day of the Islamic calendar |
| [Rabi' al-awwal 12](https://en.wikipedia.org/wiki/Rabi'_al-awwal) | [The Prophet's Birthday](1285650.md) | *ʿid lmawlid* |  |
| [Shawwal 1](https://en.wikipedia.org/wiki/Shawwal) | [Eid al-Fitr](154944.md) | *ʿid sġhīr* | Islamic holiday celebrated after the last day of [Ramadan](https://en.wikipedia.org/wiki/Ramadan) |
| [Dhu al-Hijjah 10](https://en.wikipedia.org/wiki/Dhu_al-Hijjah) | [Eid al-Adha](358226.md) | *ʿid kbīr* |  |
