# Data security

Not to be confused with [Data privacy](237536.md).

**Data security** or **data protection** is the process of securing digital information to protect it from online threats. Data security or protection means protecting [digital data](https://en.wikipedia.org/wiki/Digital_data), such as those in a [database](https://en.wikipedia.org/wiki/Database), from destructive forces and from the unwanted actions of unauthorized users,[^cite_note-1] such as a [cyberattack](37925700.md) or a [data breach](13307577.md).[^cite_note-2] Data security protects [computer hardware](https://en.wikipedia.org/wiki/Computer_hardware), [software](https://en.wikipedia.org/wiki/Software), storage devices, and the data of user devices. Data security also protects the data of organizations, companies and administrative controls.&#x20;

Proper data security practices reduce the risk of [data breaches](13307577.md), including unauthorized access, theft and loss of individual data such as [identity documents](https://en.wikipedia.org/wiki/Identity_document) and bank data. Data security is part of [information security](https://en.wikipedia.org/wiki/Information_security).

## Technologies

### Disk encryption

Main article: [Disk encryption](https://en.wikipedia.org/wiki/Disk_encryption)

[Disk encryption](https://en.wikipedia.org/wiki/Disk_encryption) refers to [encryption](https://en.wikipedia.org/wiki/Encryption) technology that encrypts data on a [hard disk drive](https://en.wikipedia.org/wiki/Hard_disk_drive). It takes data from a [storage device](https://en.wikipedia.org/wiki/Data_storage_device) and coverts it into an unreadable format. Disk encryption typically takes form in either [software](https://en.wikipedia.org/wiki/Software) (see [disk encryption software](https://en.wikipedia.org/wiki/Disk_encryption_software)) or [hardware](https://en.wikipedia.org/wiki/Electronic_hardware) (see [disk encryption hardware](https://en.wikipedia.org/wiki/Disk_encryption_hardware)) which can be used together. Disk encryption is often referred to as [on-the-fly encryption](https://en.wikipedia.org/wiki/On-the-fly_encryption) (OTFE) or transparent encryption. [Full disk encryption](https://en.wikipedia.org/wiki/Disk_encryption) encrypts each individual sector of a disk volume. Files and user data are encrypted to hinder unauthorized users from accessing without a [decryption key](https://en.wikipedia.org/wiki/Key_\(cryptography\)). A diversifier permits a plaintext of a specific disk sector to be encrypted into different ciphertexts, which does not require additional storage, such as an [initialization vector](https://en.wikipedia.org/wiki/Initialization_vector) (IV) or [message authentication code](https://en.wikipedia.org/wiki/Message_authentication_code) (MAC).[^cite_note-3]

### Software versus hardware-based mechanisms for protecting data

Software-based security solutions encrypt the data to protect it from theft. However, a [malicious program](https://en.wikipedia.org/wiki/Malware) or a [hacker](https://en.wikipedia.org/wiki/Hacker) could [corrupt the data](https://en.wikipedia.org/wiki/Data_corruption) to make it unrecoverable, making the system unusable. Hardware-based security solutions prevent read and write access to data, which provides very strong protection against tampering and unauthorized access.[^cite_note-4]

Hardware-based security or assisted [computer security](7398.md) offers an alternative to software-only computer security. [Security tokens](https://en.wikipedia.org/wiki/Security_token) such as those using [PKCS#11](https://en.wikipedia.org/wiki/PKCS#11) or a mobile phone may be more secure due to the physical access required in order to be compromised.[^cite_note-5] Access is enabled only when the token is connected and the correct [PIN](https://en.wikipedia.org/wiki/Personal_identification_number) is entered (see [two-factor authentication](https://en.wikipedia.org/wiki/Two-factor_authentication)). However, [dongles](https://en.wikipedia.org/wiki/Dongle) can be used by anyone who can gain physical access to it. Newer technologies in hardware-based security solve this problem by offering full proof of security for data.[^cite_note-6]

Working off hardware-based security: A hardware device allows a user to log in, log out and set different levels through manual actions. Many devices use [biometric technology](290622.md) to prevent malicious users from logging in, logging out, and changing privilege levels. The current state of a user of the device is read by controllers in [peripheral devices](https://en.wikipedia.org/wiki/Peripheral_devices) such as hard disks. Illegal access by a malicious user or a malicious program is interrupted based on the current state of a user by hard disk and DVD controllers making illegal access to data impossible.[^cite_note-7] Hardware-based access control is more secure than the protection provided by the operating systems as operating systems are vulnerable to malicious attacks by [viruses](https://en.wikipedia.org/wiki/Computer_virus) and hackers. The data on hard disks can be corrupted after malicious access is obtained. With hardware-based protection, the software cannot manipulate the user privilege levels. A [hacker](https://en.wikipedia.org/wiki/Hacker_\(computer_security\)) or a malicious program cannot gain access to secure data protected by hardware or perform unauthorized privileged operations. This assumption is broken only if the hardware itself is malicious or contains a backdoor.[^cite_note-8] The hardware protects the operating system image and file system privileges from being tampered with. Therefore, a completely secure system can be created using a combination of hardware-based security and secure system administration policies.

### Backups

Main article: [Backup](https://en.wikipedia.org/wiki/Backup)

[Backup](https://en.wikipedia.org/wiki/Backup) is the process of reproducing copies of essential data and storing in a separate, secured place. It is used to ensure data that is lost can be recovered from another source. Backups contains a minimum of one copy of the data that requires preservation.[^cite_note-9] It is considered essential to keep a backup of any data in most industries and the process is recommended for any files of importance to a user.[^cite_note-10]

There are 3 types of backups; full backups, incremental backups, and differential backups. Full backups secure all data from a production system, such as a server, database, or other connected data source. It is impossible to lose all data in a full backup if a breach or corruption were to occur. Full backups require a significantly large amount of time to back up and may be time-consuming taking hours to days to complete.[^cite_note-11] [Incremental backups](https://en.wikipedia.org/wiki/Incremental_backup) only secures changed data since last backup. While all backups are done in full backups, incremental backups only save data that is recently or frequently changed. Incremental backups require lower storage costs making it a prominent solution for growing datasets.[^cite_note-12]

### Data Privacy

Main article: [Data privacy](237536.md)

Data privacy (or [information privacy](237536.md)) is the right for individual's data to be secured to obstruct the use of unauthorized access. It gives individuals control over their data and how it can be shared to third parties. The U.S Privacy Protection Law (see [Privacy laws of the United States](https://en.wikipedia.org/wiki/Privacy_laws_of_the_United_States)) requires organizations to inform individuals of how their data is collected and when a data breach occurs.[^cite_note-13] By implementing an encryption, it ensures that private data is unreadable to [cybercriminals](https://en.wikipedia.org/wiki/List_of_cybercriminals).[^cite_note-14]

### Data masking

Main article: [Data masking](https://en.wikipedia.org/wiki/Data_masking)

[Data masking](https://en.wikipedia.org/wiki/Data_masking) of structured data is the process of obscuring (masking) specific data within a database table or cell to ensure that data security is maintained and sensitive information is not exposed to unauthorized personnel.[^cite_note-15] This may include masking the data from users (for example so banking customer representatives can only see the last four digits of a customer's national identity number), developers (who need real production data to test new software releases but should not be able to see sensitive financial data), [outsourcing](https://en.wikipedia.org/wiki/Outsourcing) vendors, etc.[^cite_note-16] Data masking is a form of encryption, as it obscures data by modifying particular letters and numbers to keep data concealed and protected from potential hackers. The individual that has access to the code that decrypts the replaced characters are the only ones that can uncover the data.[^cite_note-17]

### Data erasure

Main article: [Data erasure](https://en.wikipedia.org/wiki/Data_erasure)

[Data erasure](https://en.wikipedia.org/wiki/Data_erasure) (or data deletion, data destruction) is a method of software-based overwriting that permanently clears all electronic data residing on a hard drive or other digital media to ensure that no sensitive data is lost when an asset is retired or reused. [^cite_note-Wei2011-18] [Article 17: Right to be Forgotten](https://en.wikipedia.org/wiki/Right_to_be_forgotten) states that users have the right to permanently remove all of their private information from their old devices/services to give people more control over their data. Users are able to switch between devices efficiently.[^cite_note-19]

## Threats

### Malware

[Malware](https://en.wikipedia.org/wiki/Malware) (or malicious software) is designed to destroy, corrupt or gain unauthorized access to a computer for the purpose of stealing, or destroying data.[^cite_note-20] Hackers who use malware typically utilize many types of malware, which includes [computer virus](https://en.wikipedia.org/wiki/Computer_virus), [computer worms](https://en.wikipedia.org/wiki/Computer_worm), [ransomware](https://en.wikipedia.org/wiki/Ransomware), [spyware](28951.md) and [Trojan horse](https://en.wikipedia.org/wiki/Trojan_horse_\(computing\)) to create a vast system of disruption and cause easy data theft.[^cite_note-21] One of the victims of the vast system of disruption includes healthcare workers, who are targeted by compromised systems by infections and then having their data attacked.[^cite_note-22]

### Phishing

[Phishing](https://en.wikipedia.org/wiki/Phishing) is a type of [scam](96637.md) that allows hackers to hoax people using psychological and [social engineering](https://en.wikipedia.org/wiki/Social_engineering_\(security\)) (using human emotions such as their trust and fear) tactics into giving personal data through emails and messages, and install computer viruses if the individual were to click on a malicious link unknowingly. Attackers are able to create websites that are very similar to original websites, which makes it difficult to detect a fake website, causing individuals to fall for giving in information.[^cite_note-23] Phishing attackers use human emotion to exploit them, such as making them feel fear, urgency, sympathy with the message being sent by the sender.[^cite_note-24] Emails (Or [Email spoofing](https://en.wikipedia.org/wiki/Email_spoofing)) with impersonated companies and fake websites copying the original are ways to exploit people. Email spoofing show false names and emails of the original ones to copy several banks, companies and agencies, using warnings to manipulate people into feeling urgent about the email.[^cite_note-25]

## International laws and standards

### International laws

In the [UK](31717.md), the [Data Protection Act](https://en.wikipedia.org/wiki/Data_Protection_Act_1998) is used to ensure that personal data is accessible to those whom it concerns, and provides redress to individuals if there are inaccuracies.[^cite_note-26] This is particularly important to ensure individuals are treated fairly, for example for credit checking purposes. The Data Protection Act states that only individuals and companies with legitimate and lawful reasons can process personal information and cannot be shared. [Data Privacy Day](https://en.wikipedia.org/wiki/Data_Privacy_Day) is an international [holiday](https://en.wikipedia.org/wiki/Holiday) started by the [Council of Europe](https://en.wikipedia.org/wiki/Council_of_Europe) that occurs every January 28. [^cite_note-dataprivacyday-27]

Since the [General Data Protection Regulation](https://en.wikipedia.org/wiki/General_Data_Protection_Regulation) (GDPR) of the [European Union](9317.md) (EU) became law on May 25, 2018, organizations may face significant penalties of up to €20 million or 4% of their annual revenue if they do not comply with the regulation.[^cite_note-28] It is intended that GDPR will force organizations to understand their [data privacy](237536.md) risks and take the appropriate measures to reduce the risk of unauthorized disclosure of consumers’ private information. [^cite_note-29]

### International standards

The international standards [ISO/IEC 27001](https://en.wikipedia.org/wiki/ISO/IEC_27001)\:2013 and [ISO/IEC 27002](https://en.wikipedia.org/wiki/ISO/IEC_27002)\:2013 cover data security under the topic of [information security](https://en.wikipedia.org/wiki/Information_security), and one of its cardinal principles is that all stored information, i.e. data, should be owned so that it is clear whose responsibility it is to protect and control access to that data.[^cite_note-30][^cite_note-31] The following are examples of organizations that help strengthen and standardize computing security:

The [Trusted Computing Group](https://en.wikipedia.org/wiki/Trusted_Computing_Group) is an organization that helps standardize computing security technologies.

The [Payment Card Industry Data Security Standard](https://en.wikipedia.org/wiki/Payment_Card_Industry_Data_Security_Standard) (PCI DSS) is a proprietary international information security standard for organizations that handle cardholder information for the major [debit](https://en.wikipedia.org/wiki/Debit_card), [credit](https://en.wikipedia.org/wiki/Credit_card), prepaid, [e-purse](https://en.wikipedia.org/wiki/E-purse), [automated teller machines](https://en.wikipedia.org/wiki/Cash_machine), and point of sale cards.[^cite_note-32]

The [General Data Protection Regulation (GDPR)](https://en.wikipedia.org/wiki/General_Data_Protection_Regulation) proposed by the European Commission will strengthen and unify data protection for individuals within the EU, whilst addressing the export of personal data outside the EU.

## Safeguards

The four types of technical safeguards are [access controls](https://en.wikipedia.org/wiki/Access_control), [flow controls](https://en.wikipedia.org/wiki/Flow_control_\(data\)), inference controls, and [data encryption](https://en.wikipedia.org/wiki/Encryption). Access controls manage user entry and data manipulation, while flow controls regulate data dissemination. Inference controls prevent deduction of confidential information from statistical databases and data encryption prevents unauthorized access to confidential information.[^cite_note-33] [Health Insurance Portability and Accountability Act (HIPAA)](https://en.wikipedia.org/wiki/Health_Insurance_Portability_and_Accountability_Act) is a law that requires entities such as healthcare providers to keep patient confidentiality for three required safeguards: administrative, physical, and technical.[^cite_note-34]
