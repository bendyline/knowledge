**Windows** is a [proprietary](https://en.wikipedia.org/wiki/Proprietary_software) [operating system](https://en.wikipedia.org/wiki/Operating_system) developed by [Microsoft](19001.md). Windows is grouped into families that cater to particular sectors of the computing industry – Windows for [personal computers](https://en.wikipedia.org/wiki/Personal_computer), [Windows Server](https://en.wikipedia.org/wiki/Windows_Server) for [servers](https://en.wikipedia.org/wiki/Server_\(computing\)), and [Windows IoT](https://en.wikipedia.org/wiki/Windows_IoT) for [embedded systems](https://en.wikipedia.org/wiki/Embedded_system). Windows itself is further grouped into [editions](https://en.wikipedia.org/wiki/Windows_editions) that cater to different users – Home for home users, Professional for advanced users, Education for schools, and Enterprise for corporations. Windows is sold both as a [consumer retail](183515.md) product and to [computer manufacturers](https://en.wikipedia.org/wiki/Original_equipment_manufacturer), who [bundle and distribute it](https://en.wikipedia.org/wiki/Bundling_of_Microsoft_Windows) with their systems.

The first version of Windows, [Windows 1.0](https://en.wikipedia.org/wiki/Windows_1.0), was released on November 20, 1985 as a graphical [operating system shell](https://en.wikipedia.org/wiki/Operating_system_shell) for [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS) in response to growing interest in [graphical user interfaces](https://en.wikipedia.org/wiki/Graphical_user_interface) (GUIs).[^cite_note-15] The name *Windows* is a reference to the [windowing system](https://en.wikipedia.org/wiki/Windowing_system) in GUIs.[^cite_note-\:1-16] The 1990 release of [Windows 3.0](https://en.wikipedia.org/wiki/Windows_3.0) catapulted its market success and led to the launch of various other product families, including the (now-defunct) [Windows Mobile](https://en.wikipedia.org/wiki/Windows_Mobile), [Windows Phone](https://en.wikipedia.org/wiki/Windows_Phone), and [Windows CE/Embedded Compact](https://en.wikipedia.org/wiki/Windows_Embedded_Compact).

Windows is the [most popular](https://en.wikipedia.org/wiki/Usage_share_of_operating_systems) desktop operating system in the world, with a 76% [market share](https://en.wikipedia.org/wiki/Market_share) as of September 2026,[^cite_note-pc-17] and the second-most popular operating system overall, behind [Android](https://en.wikipedia.org/wiki/Android_\(operating_system\)).[^cite_note-18] As of September 2026, [Windows 11](https://en.wikipedia.org/wiki/Windows_11) is the most used desktop version of Windows, with a market share of 71%.[^cite_note-19]

## Product line

All members of the Windows product family are, as of 2026, based on [Windows NT](https://en.wikipedia.org/wiki/Windows_NT). The first version of Windows in that product line, [Windows NT 3.1](https://en.wikipedia.org/wiki/Windows_NT_3.1), was intended for [server computing](https://en.wikipedia.org/wiki/Server_\(computing\)) and corporate [workstations](https://en.wikipedia.org/wiki/Workstation). It now consists of four sub-families that tend to be released almost simultaneously and share the same kernel.

- Windows (unqualified): For a consumer or corporate [workstation](https://en.wikipedia.org/wiki/Workstation) or [tablet](https://en.wikipedia.org/wiki/Tablet_computer). The latest version is [Windows 11](https://en.wikipedia.org/wiki/Windows_11).

- [Windows Server](https://en.wikipedia.org/wiki/Windows_Server): For a server computer. The latest version is [Windows Server 2025](https://en.wikipedia.org/wiki/Windows_Server_2025). Unlike its client sibling, it has adopted a strong naming scheme. The main competitor of this family is [Linux](https://en.wikipedia.org/wiki/Linux). (cf. The latest version is [Windows 11 IoT Enterprise](https://en.wikipedia.org/wiki/Windows_IoT#Enterprise).

- [Windows PE](https://en.wikipedia.org/wiki/Windows_PE): A lightweight version of Windows designed to operate as a [live operating system](https://en.wikipedia.org/wiki/Live_OS), used for installing Windows on bare-metal computers (especially on many at once), recovery, or troubleshooting purposes. The latest version is Windows PE, version 10.0.

These top-level Windows families are no longer actively developed:

- [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS)-based versions of Windows, including [Windows 1.0](https://en.wikipedia.org/wiki/Windows_1.0), [Windows 2.0](https://en.wikipedia.org/wiki/Windows_2.0), [Windows 3.x](https://en.wikipedia.org/wiki/Windows_3.x), and [Windows 9x](https://en.wikipedia.org/wiki/Windows_9x): The original top-level family of Windows prior to Windows NT, aimed at consumers. These versions used a [monolithic kernel](https://en.wikipedia.org/wiki/Monolithic_kernel), with later versions in the family since [Windows 3.0](https://en.wikipedia.org/wiki/Windows_3.0) having their own kernel. The last version was [Windows Me](https://en.wikipedia.org/wiki/Windows_Me); the family was discontinued after the release of [Windows XP](https://en.wikipedia.org/wiki/Windows_XP), with all consumer-oriented versions of Windows afterwards being based on the Windows NT kernel.

- [Windows Mobile](https://en.wikipedia.org/wiki/Windows_Mobile): Windows Mobile was a mobile phone and [PDA](https://en.wikipedia.org/wiki/Personal_digital_assistant) operating system and the predecessor to Windows Phone. The first version was [Pocket PC 2000](https://en.wikipedia.org/wiki/Pocket_PC_2000); the third version, [Windows Mobile 2003](https://en.wikipedia.org/wiki/Windows_Mobile_2003), was the first version to adopt the Windows Mobile trademark. The last published version was [Windows Mobile 6.5](https://en.wikipedia.org/wiki/Windows_Mobile_6.5).

- [Windows Phone](https://en.wikipedia.org/wiki/Windows_Phone): Sold only to smartphone manufacturers. The first version was [Windows Phone 7](https://en.wikipedia.org/wiki/Windows_Phone_7), followed by [Windows Phone 8](https://en.wikipedia.org/wiki/Windows_Phone_8) and [Windows Phone 8.1](https://en.wikipedia.org/wiki/Windows_Phone_8.1). It was succeeded by [Windows 10 Mobile](https://en.wikipedia.org/wiki/Windows_10_Mobile), which is also defunct.

- [Windows Embedded Compact](https://en.wikipedia.org/wiki/Windows_Embedded_Compact): Most commonly known by its former name, Windows CE, it is a [hybrid kernel](https://en.wikipedia.org/wiki/Hybrid_kernel) operating system optimized for low power and memory systems, with [OEMs](https://en.wikipedia.org/wiki/OEM) able to modify the [UI](https://en.wikipedia.org/wiki/User_interface) to suit their needs. The final version was [Windows Embedded Compact 2013](https://en.wikipedia.org/wiki/Windows_Embedded_Compact_2013), and it is succeeded by [Windows IoT](https://en.wikipedia.org/wiki/Windows_IoT).

## History

Main article: [Microsoft Windows version history](https://en.wikipedia.org/wiki/Microsoft_Windows_version_history)

See also: [List of Microsoft Windows versions](https://en.wikipedia.org/wiki/List_of_Microsoft_Windows_versions)

The term *Windows* collectively describes any or all of several generations of [Microsoft](19001.md) [operating system](https://en.wikipedia.org/wiki/Operating_system) products. These products are generally categorized as follows:

### Early versions

Main articles: [Windows 1.0](https://en.wikipedia.org/wiki/Windows_1.0), [Windows 2.0](https://en.wikipedia.org/wiki/Windows_2.0), and [Windows 2.1](https://en.wikipedia.org/wiki/Windows_2.1)

The history of Windows dates back to 1981 when Microsoft started work on a program called "Interface Manager". The name "Windows" comes from the fact that the system was one of the first to use graphical boxes to represent programs; in the industry, at the time, these were called "windows" and the underlying software was called "windowing software".[^cite_note-\:1-16] It was announced in November 1983 (after the [Apple Lisa](https://en.wikipedia.org/wiki/Apple_Lisa), but before the [Macintosh](https://en.wikipedia.org/wiki/Macintosh_128K)) under the name "Windows", but [Windows 1.0](https://en.wikipedia.org/wiki/Windows_1.0) was not released until November 1985.[^cite_note-24] Windows 1.0 was to compete with [Apple](856.md)'s operating system, but achieved little popularity. Windows 1.0 is not a complete operating system; rather, it extends [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS). The shell of Windows 1.0 is a program known as the [MS-DOS Executive](https://en.wikipedia.org/wiki/MS-DOS_Executive). Components included [Calculator](https://en.wikipedia.org/wiki/Windows_Calculator), [Calendar](https://en.wikipedia.org/wiki/Calendar_\(Windows\)), [Cardfile](https://en.wikipedia.org/wiki/Cardfile), [Clipboard Viewer](https://en.wikipedia.org/wiki/ClipBook_Viewer), [Clock](https://en.wikipedia.org/wiki/Windows_Clock), [Control Panel](https://en.wikipedia.org/wiki/Control_Panel_\(Windows\)), [Notepad](https://en.wikipedia.org/wiki/Windows_Notepad), [Paint](https://en.wikipedia.org/wiki/Microsoft_Paint), [Reversi](https://en.wikipedia.org/wiki/Reversi), [Terminal](https://en.wikipedia.org/wiki/Terminal_emulator) and [Write](https://en.wikipedia.org/wiki/Microsoft_Write). Windows 1.0 does not allow overlapping windows. Instead, all windows are [tiled](https://en.wikipedia.org/wiki/Tiling_window_manager). Only modal dialog boxes may appear over other windows. Microsoft sold as included Windows Development libraries with the C development environment, which included numerous windows samples.[^cite_note-25]

[Windows 2.0](https://en.wikipedia.org/wiki/Windows_2.0) was released in December 1987, and was more popular than its predecessor. It features several improvements to the user interface and memory management.[^cite_note-26] Windows 2.03 changed the OS from tiled windows to overlapping windows. The result of this change led to [Apple Computer filing a suit against Microsoft](https://en.wikipedia.org/wiki/Apple_Computer,_Inc._v._Microsoft_Corp.) alleging infringement on Apple's copyrights (eventually settled in court in Microsoft's favor in 1993).[^cite_note-27][^cite_note-28] Windows 2.0 also introduced more sophisticated [keyboard shortcuts](https://en.wikipedia.org/wiki/Keyboard_shortcut) and could make use of [expanded memory](https://en.wikipedia.org/wiki/Expanded_memory).

[Windows 2.1](https://en.wikipedia.org/wiki/Windows_2.1) was released in two different versions: [Windows/286](https://en.wikipedia.org/wiki/Windows/286) and [Windows/386](https://en.wikipedia.org/wiki/Windows/386). Windows/386 uses the [virtual 8086 mode](https://en.wikipedia.org/wiki/Virtual_8086_mode) of the [Intel 80386](https://en.wikipedia.org/wiki/Intel_80386) to multitask several DOS programs and the [paged memory model](https://en.wikipedia.org/wiki/Paging) to emulate expanded memory using available [extended memory](https://en.wikipedia.org/wiki/Extended_memory). Windows/286, in spite of its name, runs on both [Intel 8086](https://en.wikipedia.org/wiki/Intel_8086) and [Intel 80286](https://en.wikipedia.org/wiki/Intel_80286) processors. It runs in [real mode](https://en.wikipedia.org/wiki/Real_mode) but can make use of the [high memory area](https://en.wikipedia.org/wiki/High_memory_area).[^cite_note-infoworld-19880704-29]

In addition to full Windows packages, there were runtime-only versions that shipped with early Windows software from third parties and made it possible to run their Windows software on MS-DOS and without the full Windows feature set.

The early versions of Windows are often thought of as graphical shells, mostly because they ran on top of MS-DOS and used it for [file system](https://en.wikipedia.org/wiki/File_system) services.[^cite_note-Evolution-30] However, even the earliest Windows versions already assumed many typical operating system functions; notably, having their own [executable file format](https://en.wikipedia.org/wiki/Executable_file_format) and providing their own [device drivers](https://en.wikipedia.org/wiki/Device_driver) (timer, graphics, printer, mouse, keyboard and sound). Unlike MS-DOS, Windows allowed users to execute multiple graphical applications at the same time, through [cooperative multitasking](https://en.wikipedia.org/wiki/Nonpreemptive_multitasking). Windows implemented an elaborate, segment-based, software virtual memory scheme, which allowed it to run applications larger than available memory: code segments and [resources](https://en.wikipedia.org/wiki/Resource_\(Windows\)) were swapped in and thrown away when memory became scarce; data segments moved in memory when a given application had relinquished processor control.

### Windows 3.x

Main articles: [Windows 3.0](https://en.wikipedia.org/wiki/Windows_3.0) and [Windows 3.1](https://en.wikipedia.org/wiki/Windows_3.1)



Windows 3.0, released in 1990

[Windows 3.0](https://en.wikipedia.org/wiki/Windows_3.0), released in 1990, improved the design, mostly because of [virtual memory](https://en.wikipedia.org/wiki/Virtual_memory) and loadable virtual device drivers ([VxDs](https://en.wikipedia.org/wiki/VxD)) that allow Windows to share arbitrary devices between multi-tasked DOS applications. Windows 3.0 applications can run in [protected mode](https://en.wikipedia.org/wiki/Protected_mode), which gives them access to several megabytes of memory without the obligation to participate in the software virtual memory scheme. They run inside the same address space, where the segmented memory provides a degree of protection. Windows 3.0 also featured improvements to the user interface. Microsoft rewrote critical operations from [C](https://en.wikipedia.org/wiki/C_\(programming_language\)) into [assembly](https://en.wikipedia.org/wiki/Assembly_language). Windows 3.0 was the first version of Windows to achieve broad commercial success, selling 2 million copies in the first six months.[^cite_note-31][^cite_note-32]



Versions before Windows 95 had to be installed from [floppy disks](https://en.wikipedia.org/wiki/Floppy_disk) by end users (or in professional environments with a network installation); here Windows for Workgroups with nine 3.5-inch-disks to be inserted sequentially.

Windows 3.1, made [generally available](https://en.wikipedia.org/wiki/General_availability_release) on March 1, 1992, featured a facelift. In October 1992, Windows for Workgroups, a special version with integrated [peer-to-peer networking](https://en.wikipedia.org/wiki/Peer-to-peer_networking) features, was released. It was sold along with Windows 3.1. Support for Windows 3.1 ended on December 31, 2001.[^cite_note-33]

Windows 3.2, released in 1994, is an updated version of the Chinese version of Windows 3.1.[^cite_note-34] The update was limited to this language version, as it fixed only issues related to the complex writing system of the Chinese language.[^cite_note-35] Windows 3.2 was generally sold by computer manufacturers with a ten-disk version of [MS-DOS](https://en.wikipedia.org/wiki/MS-DOS) that also had [Simplified Chinese characters](https://en.wikipedia.org/wiki/Simplified_Chinese_characters) in basic output and some translated utilities.

### Windows 9x

Main articles: [Windows 9x](https://en.wikipedia.org/wiki/Windows_9x), [Windows 95](https://en.wikipedia.org/wiki/Windows_95), [Windows 98](https://en.wikipedia.org/wiki/Windows_98), and [Windows Me](https://en.wikipedia.org/wiki/Windows_Me)

The next major consumer-oriented release of Windows, [Windows 95](https://en.wikipedia.org/wiki/Windows_95), was released on August 24, 1995. While still remaining MS-DOS-based, Windows 95 introduced support for native [32-bit applications](https://en.wikipedia.org/wiki/32-bit_application), [plug and play](https://en.wikipedia.org/wiki/Plug_and_play) hardware, [preemptive multitasking](https://en.wikipedia.org/wiki/Preemptive_multitasking), [long file names](https://en.wikipedia.org/wiki/Long_file_name) of up to 255 characters, and provided increased stability over its predecessors. Windows 95 also introduced a redesigned, [object oriented](https://en.wikipedia.org/wiki/Object-oriented_design) user interface, replacing the previous [Program Manager](https://en.wikipedia.org/wiki/Program_Manager) with the [Start menu](https://en.wikipedia.org/wiki/Start_menu), [taskbar](https://en.wikipedia.org/wiki/Taskbar), and [Windows Explorer](https://en.wikipedia.org/wiki/Windows_Explorer) [shell](https://en.wikipedia.org/wiki/Windows_shell). Windows 95 was a major commercial success for Microsoft; Ina Fried of [CNET](https://en.wikipedia.org/wiki/CNET) remarked that "by the time Windows 95 was finally ushered off the market in 2001, it had become a fixture on computer desktops around the world."[^cite_note-36] Microsoft published four OEM Service Releases (OSR) of Windows 95, each of which was roughly equivalent to a [service pack](https://en.wikipedia.org/wiki/Service_pack). The first OSR of Windows 95 was also the first version of Windows to be bundled with Microsoft's [web browser](https://en.wikipedia.org/wiki/Web_browser), [Internet Explorer](https://en.wikipedia.org/wiki/Internet_Explorer).[^cite_note-apr96ms-37] Mainstream support for Windows 95 ended on December 31, 2000, and extended support for Windows 95 ended on December 31, 2001.[^cite_note-Windows_95_Support_Lifecycle-38]

Windows 95 was followed up with the release of [Windows 98](https://en.wikipedia.org/wiki/Windows_98) on June 25, 1998, which introduced the [Windows Driver Model](https://en.wikipedia.org/wiki/Windows_Driver_Model), support for [USB composite devices](https://en.wikipedia.org/wiki/Universal_Serial_Bus#Overview), support for [ACPI](https://en.wikipedia.org/wiki/ACPI), [hibernation](https://en.wikipedia.org/wiki/Hibernation_\(computing\)), and support for [multi-monitor](https://en.wikipedia.org/wiki/Multi-monitor) configurations. Windows 98 also included integration with [Internet Explorer 4](https://en.wikipedia.org/wiki/Internet_Explorer_4) through [Active Desktop](https://en.wikipedia.org/wiki/Active_Desktop) and other aspects of the [Windows Desktop Update](https://en.wikipedia.org/wiki/Windows_Desktop_Update) (a series of enhancements to the Explorer shell which was also made available for Windows 95). In June 1999, Microsoft released [Windows 98 Second Edition](https://en.wikipedia.org/wiki/Windows_98_Second_Edition), an updated version of Windows 98. Windows 98 SE added [Internet Explorer 5.0](https://en.wikipedia.org/wiki/Internet_Explorer_5.0) and [Windows Media Player](https://en.wikipedia.org/wiki/Windows_Media_Player) 6.2 amongst other upgrades. Mainstream support for Windows 98 ended on June 30, 2002, and extended support for Windows 98 ended on July 11, 2006.[^cite_note-Windows_98_Standard_Edition_Support_Lifecycle-39]

On September 14, 2000, Microsoft released [Windows Me](https://en.wikipedia.org/wiki/Windows_Me) (Millennium Edition), the last DOS-based version of Windows. Windows Me incorporated visual interface enhancements from its Windows NT-based counterpart [Windows 2000](https://en.wikipedia.org/wiki/Windows_2000), had faster boot times than previous versions (which however, required the removal of the ability to access a [real mode](https://en.wikipedia.org/wiki/Real_mode) DOS environment, removing compatibility with some older programs),[^cite_note-FastBoot1-40] expanded [multimedia](https://en.wikipedia.org/wiki/Multimedia) functionality (including Windows Media Player 7, [Windows Movie Maker](https://en.wikipedia.org/wiki/Windows_Movie_Maker), and the [Windows Image Acquisition](https://en.wikipedia.org/wiki/Windows_Image_Acquisition) framework for retrieving images from scanners and digital cameras), additional system utilities such as [System File Protection](https://en.wikipedia.org/wiki/System_File_Protection) and [System Restore](https://en.wikipedia.org/wiki/System_Restore), and updated [home networking](https://en.wikipedia.org/wiki/Home_network) tools.[^cite_note-pcw-me-41] However, Windows Me was faced with criticism for its speed and instability, along with hardware compatibility issues and its removal of real mode DOS support. *[PC World](https://en.wikipedia.org/wiki/PC_World)* considered Windows Me to be one of the worst operating systems Microsoft had ever released, and the fourth worst tech product of all time.[^cite_note-WinMEbad-42]

Windows logo (1995–2001)

In November 1988, a new development team within Microsoft (which included former [Digital Equipment Corporation](https://en.wikipedia.org/wiki/Digital_Equipment_Corporation) developers [Dave Cutler](https://en.wikipedia.org/wiki/Dave_Cutler) and [Mark Lucovsky](https://en.wikipedia.org/wiki/Mark_Lucovsky)) began work on a revamped version of [IBM](https://en.wikipedia.org/wiki/IBM) and Microsoft's [OS/2](https://en.wikipedia.org/wiki/OS/2) operating system known as "NT OS/2". NT OS/2 was intended to be a secure, [multi-user](https://en.wikipedia.org/wiki/Multi-user) operating system with [POSIX](https://en.wikipedia.org/wiki/POSIX) compatibility and a modular, [portable](https://en.wikipedia.org/wiki/Software_portability) kernel with [preemptive multitasking](https://en.wikipedia.org/wiki/Preemptive_multitasking) and support for multiple processor architectures. However, following the successful release of [Windows 3.0](https://en.wikipedia.org/wiki/Windows_3.0), the NT development team decided to rework the project to use an extended [32-bit](https://en.wikipedia.org/wiki/32-bit_computing) port of the [Windows API](https://en.wikipedia.org/wiki/Windows_API) known as Win32 instead of those of OS/2. Win32 maintained a similar structure to the Windows [APIs](https://en.wikipedia.org/wiki/API) (allowing existing Windows applications to easily be [ported](https://en.wikipedia.org/wiki/Porting) to the platform), but also supported the capabilities of the existing NT [kernel](https://en.wikipedia.org/wiki/Kernel_\(operating_system\)). Following its approval by Microsoft's staff, development continued on what was now Windows NT, the first 32-bit version of Windows. However, IBM objected to the changes, and ultimately continued OS/2 development on its own.[^cite_note-insident-43][^cite_note-thurrott-nt-44]

Windows NT was the first Windows operating system based on a [hybrid kernel](https://en.wikipedia.org/wiki/Hybrid_kernel). The hybrid kernel was designed as a modified [microkernel](https://en.wikipedia.org/wiki/Microkernel), influenced by the [Mach microkernel](https://en.wikipedia.org/wiki/Mach_\(kernel\)) developed by [Richard Rashid](https://en.wikipedia.org/wiki/Richard_Rashid) at Carnegie Mellon University, but without meeting all of the criteria of a pure microkernel.

The first release of the resulting operating system, [Windows NT 3.1](https://en.wikipedia.org/wiki/Windows_NT_3.1) (named to associate it with [Windows 3.1](https://en.wikipedia.org/wiki/Windows_3.1)) was released in July 1993, with versions for desktop [workstations](https://en.wikipedia.org/wiki/Workstation) and [servers](https://en.wikipedia.org/wiki/Server_\(computing\)). [Windows NT 3.5](https://en.wikipedia.org/wiki/Windows_NT_3.5) was released in September 1994, focusing on performance improvements and support for [Novell](https://en.wikipedia.org/wiki/Novell)'s [NetWare](https://en.wikipedia.org/wiki/NetWare), and was followed up by [Windows NT 3.51](https://en.wikipedia.org/wiki/Windows_NT_3.51) in May 1995, which included additional improvements and support for the [PowerPC](https://en.wikipedia.org/wiki/PowerPC) architecture. [Windows NT 4.0](https://en.wikipedia.org/wiki/Windows_NT_4.0) was released in June 1996, introducing the redesigned interface of [Windows 95](https://en.wikipedia.org/wiki/Windows_95) to the NT series. On February 17, 2000, Microsoft released [Windows 2000](https://en.wikipedia.org/wiki/Windows_2000), a successor to NT 4.0. The Windows NT name was dropped at this point in order to put a greater focus on the Windows brand.[^cite_note-thurrott-nt-44]

##### Windows XP

Main article: [Windows XP](https://en.wikipedia.org/wiki/Windows_XP)



A variation of the 2001–06 Windows logo from 2003 using the [Segoe](https://en.wikipedia.org/wiki/Segoe) typeface instead of the [Franklin Gothic](https://en.wikipedia.org/wiki/Franklin_Gothic) typeface. This variation was mainly used for branding purposes.

The next major version of Windows NT, [Windows XP](https://en.wikipedia.org/wiki/Windows_XP), was released to manufacturing (RTM) on August 24, 2001, and to the general public on October 25, 2001. The introduction of Windows XP aimed to unify the consumer-oriented [Windows 9x](https://en.wikipedia.org/wiki/Windows_9x) series with the architecture introduced by Windows NT, a change which Microsoft promised would provide better performance over its DOS-based predecessors. Windows XP would also introduce a redesigned user interface (including an updated Start menu and a "task-oriented" [Windows Explorer](https://en.wikipedia.org/wiki/File_Explorer)), streamlined multimedia and networking features, [Internet Explorer 6](https://en.wikipedia.org/wiki/Internet_Explorer_6), integration with Microsoft's [.NET Passport](https://en.wikipedia.org/wiki/Microsoft_account) services, a "[compatibility mode](https://en.wikipedia.org/wiki/Windows_XP#Backwards_compatibility)" to help provide [backwards compatibility](https://en.wikipedia.org/wiki/Backwards_compatibility) with software designed for previous versions of Windows, and [Remote Assistance](https://en.wikipedia.org/wiki/Windows_Remote_Assistance) functionality.[^cite_note-cnet-xpreview-45][^cite_note-46]

At retail, Windows XP was marketed in two main [editions](https://en.wikipedia.org/wiki/Stock_keeping_unit): the "Home" edition was targeted towards consumers, while the "Professional" edition was targeted towards business environments and [power users](https://en.wikipedia.org/wiki/Power_user), and included additional security and networking features. Home and Professional were later accompanied by the "[Media Center](https://en.wikipedia.org/wiki/Windows_Media_Center)" edition (designed for [home theater PCs](https://en.wikipedia.org/wiki/Home_theater_PC), with an emphasis on support for [DVD](https://en.wikipedia.org/wiki/DVD) playback, [TV tuner cards](https://en.wikipedia.org/wiki/TV_tuner_card), [DVR](https://en.wikipedia.org/wiki/Digital_video_recorder) functionality, and remote controls), and the "Tablet PC" edition (designed for mobile devices meeting its [specifications](https://en.wikipedia.org/wiki/Microsoft_Tablet_PC) for a [tablet computer](https://en.wikipedia.org/wiki/Tablet_computer), with support for [stylus](https://en.wikipedia.org/wiki/Stylus) pen input and additional pen-enabled applications).[^cite_note-47][^cite_note-48][^cite_note-49] Mainstream support for Windows XP ended on April 14, 2009. Extended support ended on April 8, 2014.[^cite_note-50]

After Windows 2000, Microsoft also changed its release schedules for server operating systems; the server counterpart of Windows XP, [Windows Server 2003](https://en.wikipedia.org/wiki/Windows_Server_2003), was released in April 2003.[^cite_note-thurrott-nt-44] It was followed in March 2006, by Windows Server 2003 R2.[^cite_note-51]

##### Windows Vista

Main article: [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista)



Windows logo (2006–12)

After a lengthy [development process](https://en.wikipedia.org/wiki/Development_of_Windows_Vista), [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista) was released only for volume licensing on November 30, 2006, and finally, on January 30, 2007, it was officially released to everyone, including consumers. It contained a number of [new features](https://en.wikipedia.org/wiki/Features_new_to_Windows_Vista), from a redesigned shell and user interface to significant [technical changes](https://en.wikipedia.org/wiki/Technical_features_new_to_Windows_Vista), with a particular focus on [security features](https://en.wikipedia.org/wiki/Security_and_safety_features_new_to_Windows_Vista). It was available in a number of [different editions](https://en.wikipedia.org/wiki/Windows_Vista_editions), and has been subject to [some criticism](https://en.wikipedia.org/wiki/Criticism_of_Windows_Vista), such as drop of performance, longer boot time, criticism of new UAC, and stricter license agreement. Vista's server counterpart, [Windows Server 2008](https://en.wikipedia.org/wiki/Windows_Server_2008) was released in early 2008.

##### Windows 7

Main article: [Windows 7](https://en.wikipedia.org/wiki/Windows_7)



Windows logo (2009–12)

On July 22, 2009, [Windows 7](https://en.wikipedia.org/wiki/Windows_7) and [Windows Server 2008 R2](https://en.wikipedia.org/wiki/Windows_Server_2008_R2) were released to manufacturing (RTM) and were officially released, including for the public, months later on October 22, 2009. Unlike its predecessor, Windows Vista, which introduced a large number of new features, Windows 7 was intended to be a more focused, incremental upgrade to the Windows line, with the goal of being compatible with applications and hardware with which Windows Vista was already compatible.[^cite_note-52] Windows 7 has [multi-touch](https://en.wikipedia.org/wiki/Multi-touch) support, a redesigned [Windows shell](https://en.wikipedia.org/wiki/Windows_shell) with an updated [taskbar](https://en.wikipedia.org/wiki/Taskbar) with revealable [jump lists](https://en.wikipedia.org/wiki/Features_new_to_Windows_7#Jump_lists) that contain shortcuts to files frequently used with specific applications and shortcuts to tasks within the application,[^cite_note-53] a home networking system called [HomeGroup](https://en.wikipedia.org/wiki/Features_new_to_Windows_7#HomeGroup),[^cite_note-54] and performance improvements.

##### Windows 8 and 8.1

Main articles: [Windows 8](https://en.wikipedia.org/wiki/Windows_8) and [Windows 8.1](https://en.wikipedia.org/wiki/Windows_8.1)



Windows logo (2012–15)

[Windows 8](https://en.wikipedia.org/wiki/Windows_8), the successor to Windows 7, was released generally on October 26, 2012. A number of significant changes were made on Windows 8, including the introduction of a user interface based around Microsoft's [Metro design language](https://en.wikipedia.org/wiki/Metro_\(design_language\)) with optimizations for [touch-based](https://en.wikipedia.org/wiki/Multi-touch) devices such as [tablets](https://en.wikipedia.org/wiki/Tablet_computer) and all-in-one PCs. These changes include the [Start screen](https://en.wikipedia.org/wiki/Start_menu#Third_version), which uses large tiles that are more convenient for touch interactions and allow for the display of continually updated information, and a new class of [apps](454746.md) which are designed primarily for use on touch-based devices. The new Windows version required a minimum resolution of 1024×768 pixels,[^cite_note-zdnet-smallertab-55] effectively making it unfit for [netbooks](https://en.wikipedia.org/wiki/Netbook) with 800×600-pixel screens.

Other changes include increased integration with [cloud services](19541494.md) and other online platforms (such as [social networks](2041117.md) and Microsoft's own [OneDrive](https://en.wikipedia.org/wiki/OneDrive) (formerly [SkyDrive](https://en.wikipedia.org/wiki/SkyDrive.com)) and [Xbox Live](https://en.wikipedia.org/wiki/Xbox_Live) services), the [Windows Store](https://en.wikipedia.org/wiki/Windows_Store) service for software distribution, and a new variant known as [Windows RT](https://en.wikipedia.org/wiki/Windows_RT) for use on devices that utilize the [ARM architecture](https://en.wikipedia.org/wiki/ARM_architecture_family), and a new keyboard shortcut for [screenshots](https://en.wikipedia.org/wiki/Screenshot).[^cite_note-56][^cite_note-pcw-testdrivertm-57][^cite_note-bi-windows8-58][^cite_note-bw-win8editions-59][^cite_note-bw8-buildingarm-60][^cite_note-verge-talkswin8-61][^cite_note-pcw-building-62] An update to Windows 8, called [Windows 8.1](https://en.wikipedia.org/wiki/Windows_8.1),[^cite_note-63] was released on October 17, 2013, and includes features such as new live tile sizes, deeper OneDrive integration, and many other revisions. [Windows 8](https://en.wikipedia.org/wiki/Windows_8) and Windows 8.1 have been subject to some criticism, such as the removal of the [Start menu](https://en.wikipedia.org/wiki/Start_menu).

##### Windows 10

On September 30, 2014, Microsoft announced [Windows 10](43989914.md) as the successor to Windows 8.1. Windows 10 is said to be available to update from qualified [Windows 7](https://en.wikipedia.org/wiki/Windows_7) with SP1, [Windows 8.1](https://en.wikipedia.org/wiki/Windows_8.1) and [Windows Phone 8.1](https://en.wikipedia.org/wiki/Windows_Phone_8.1) devices from the Get Windows 10 Application (for Windows 7, Windows 8.1) or [Windows Update](https://en.wikipedia.org/wiki/Windows_Update) (Windows 7).[^cite_note-64]

In June 2021, shortly before Microsoft's announcement of Windows 11, Microsoft updated their lifecycle policy pages for Windows 10, revealing that support for their last release of Windows 10 will end on October 14, 2025.[^cite_note-Windows10HomeAndProLifecycle-66][^cite_note-Windows10EntAndEduLifecycle-67] On April 27, 2023, Microsoft announced that version 22H2 would be the last of Windows 10.[^cite_note-winroadmapupdate-68][^cite_note-69]

#### Multilingual support

See also: [Multilingual User Interface](https://en.wikipedia.org/wiki/Multilingual_User_Interface)

Multilingual support has been built into Windows since Windows 3.0. The language for both the keyboard and the interface can be changed through the Region and Language Control Panel. Components for all supported input languages, such as [Input Method Editors](https://en.wikipedia.org/wiki/Input_Method_Editor), are automatically installed during Windows installation (in Windows XP and earlier, files for East Asian languages, such as Chinese, and files for right-to-left scripts, such as Arabic, may need to be installed separately, also from the said Control Panel). Third-party IMEs may also be installed if a user feels that the provided one is insufficient for their needs. Since Windows 2000, English editions of Windows NT have East Asian IMEs (such as Microsoft Pinyin IME and Microsoft Japanese IME) bundled, but files for East Asian languages may be manually installed on Control Panel.

Interface languages for the operating system are free for download, but some languages are limited to certain editions of Windows. [Language Interface Packs](https://en.wikipedia.org/wiki/Language_Interface_Pack) (LIPs) are redistributable and may be downloaded from Microsoft's Download Center and installed for any edition of Windows (XP or later) – they translate most, but not all, of the Windows interface, and require a certain base language (the language which Windows originally shipped with). This is used for most languages in emerging markets. Full Language Packs, which translate the complete operating system, are only available for specific editions of Windows (Ultimate and Enterprise editions of Windows Vista and 7, and all editions of Windows 8, 8.1 and RT except Single Language). They do not require a specific base language and are commonly used for more popular languages such as French or Chinese. These languages cannot be downloaded through the Download Center, but are available as optional updates through the [Windows Update](https://en.wikipedia.org/wiki/Windows_Update) service (except Windows 8).

The interface language of installed applications is not affected by changes in the Windows interface language. The availability of languages depends on the application developers themselves.

[Windows 8](https://en.wikipedia.org/wiki/Windows_8) and [Windows Server 2012](https://en.wikipedia.org/wiki/Windows_Server_2012) introduce a new Language Control Panel where both the interface and input languages can be simultaneously changed, and language packs, regardless of type, can be downloaded from a central location. The PC Settings app in [Windows 8.1](https://en.wikipedia.org/wiki/Windows_8.1) and [Windows Server 2012 R2](https://en.wikipedia.org/wiki/Windows_Server_2012_R2) also includes a counterpart settings page for this. Changing the interface language also changes the language of preinstalled [Windows Store](https://en.wikipedia.org/wiki/Windows_Store) apps (such as Mail, Maps and News) and certain other Microsoft-developed apps (such as Remote Desktop). The above limitations for language packs are however still in effect, except that full language packs can be installed for any edition except Single Language, which caters to emerging markets.

#### Platform support

Windows NT included support for several platforms before the [x86](https://en.wikipedia.org/wiki/X86)-based [personal computer](https://en.wikipedia.org/wiki/Personal_computer) became dominant in the professional world. [Windows NT 4.0](https://en.wikipedia.org/wiki/Windows_NT_4.0) and its predecessors supported [PowerPC](https://en.wikipedia.org/wiki/PowerPC), [DEC Alpha](https://en.wikipedia.org/wiki/DEC_Alpha) and [MIPS](https://en.wikipedia.org/wiki/MIPS_architecture) R4000 (although some of the platforms implement [64-bit computing](https://en.wikipedia.org/wiki/64-bit_computing), the OS treated them as 32-bit). Windows 2000 dropped support for all platforms, except the third generation x86 (known as [IA-32](https://en.wikipedia.org/wiki/IA-32)) or newer in 32-bit mode. The client line of the Windows NT family still ran on IA-32 up to [Windows 10](43989914.md)[^cite_note-windows11specs-72] (the server line of the Windows NT family still ran on IA-32 up to [Windows Server 2008](https://en.wikipedia.org/wiki/Windows_Server_2008)).

With the introduction of the Intel Itanium architecture ([IA-64](https://en.wikipedia.org/wiki/IA-64)), Microsoft released new versions of Windows to support it. Itanium versions of [Windows XP](https://en.wikipedia.org/wiki/Windows_XP) and [Windows Server 2003](https://en.wikipedia.org/wiki/Windows_Server_2003) were released at the same time as their mainstream x86 counterparts. Windows XP 64-Bit Edition (Version 2003), released in 2003, is the last Windows client operating system to support Itanium. Windows Server line continues to support this platform until [Windows Server 2012](https://en.wikipedia.org/wiki/Windows_Server_2012); Windows Server 2008 R2 is the last Windows operating system to support Itanium architecture.

On April 25, 2005, Microsoft released [Windows XP Professional x64 Edition](https://en.wikipedia.org/wiki/Windows_XP_Professional_x64_Edition) and Windows Server 2003 x64 editions to support [x86-64](https://en.wikipedia.org/wiki/X86-64) (or simply x64), the 64-bit version of x86 architecture. [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista) was the first client version of Windows NT to be released simultaneously in IA-32 and x64 editions. As of 2024, x64 is still supported.

An edition of Windows 8 known as [Windows RT](https://en.wikipedia.org/wiki/Windows_RT) was specifically created for computers with [ARM architecture](https://en.wikipedia.org/wiki/ARM_architecture_family), and while ARM is still used for Windows smartphones with Windows 10, tablets with Windows RT will not be updated. Starting from [Windows 10 Fall Creators Update](https://en.wikipedia.org/wiki/Windows_10_Fall_Creators_Update) (version 1709) and later includes support for ARM-based PCs.[^cite_note-80]

### Windows CE

Main articles: [Windows CE](https://en.wikipedia.org/wiki/Windows_CE) and [Windows Phone](https://en.wikipedia.org/wiki/Windows_Phone)

Windows CE (officially known as *Windows Embedded Compact*), is an edition of Windows that runs on [minimalistic computers](https://en.wikipedia.org/wiki/Handheld_PC), like satellite navigation systems and some mobile phones. Windows Embedded Compact is based on its own dedicated kernel, dubbed Windows CE kernel. Microsoft licenses Windows CE to [OEMs](https://en.wikipedia.org/wiki/OEM) and device makers. The OEMs and device makers can modify and create their own user interfaces and experiences, while Windows CE provides the technical foundation to do so.

Windows CE was used in the [Dreamcast](https://en.wikipedia.org/wiki/Dreamcast) along with Sega's own proprietary OS for the console. Windows CE was the core from which [Windows Mobile](https://en.wikipedia.org/wiki/Windows_Mobile) was derived. Its successor, [Windows Phone 7](https://en.wikipedia.org/wiki/Windows_Phone_7), was based on components from both [Windows CE 6.0 R3](https://en.wikipedia.org/wiki/Windows_Embedded_CE_6.0) and [Windows CE 7.0](https://en.wikipedia.org/wiki/Windows_Embedded_Compact_7). [Windows Phone 8](https://en.wikipedia.org/wiki/Windows_Phone_8) however, is based on the same NT-kernel as Windows 8.

Windows Embedded Compact is not to be confused with [Windows XP Embedded](https://en.wikipedia.org/wiki/Windows_XP_Embedded) or [Windows NT 4.0 Embedded](https://en.wikipedia.org/wiki/Windows_NT_4.0_Embedded), modular editions of Windows based on Windows NT kernel.

### Xbox OS

Main article: [Xbox system software](https://en.wikipedia.org/wiki/Xbox_system_software)

Xbox OS is an unofficial name given to the version of Windows that runs on [Xbox](https://en.wikipedia.org/wiki/Xbox) consoles.[^cite_note-81] From [Xbox One](https://en.wikipedia.org/wiki/Xbox_One) onwards it is an implementation with an emphasis on virtualization (using [Hyper-V](https://en.wikipedia.org/wiki/Hyper-V)) as it is three operating systems running at once, consisting of the core [operating system](https://en.wikipedia.org/wiki/Operating_system), a second implemented for games and a more Windows-like environment for applications.[^cite_note-xboxonethreesystems-82] Microsoft updates Xbox One's OS every month, and these updates can be downloaded from the Xbox Live service to the Xbox and subsequently installed, or by using offline recovery images downloaded via a PC.[^cite_note-83] It was originally based on NT 6.2 (Windows 8) kernel, and the latest version runs on an NT 10.0 base. This system is sometimes referred to as "Windows 10 on Xbox One".[^cite_note-84][^cite_note-85] Xbox One and [Xbox Series](https://en.wikipedia.org/wiki/Xbox_Series_X_and_Series_S) operating systems also allow limited (due to licensing restrictions and testing resources) backward compatibility with previous generation hardware,[^cite_note-86] and the Xbox 360's system is backwards compatible with the original Xbox.[^cite_note-87]

## Version control system

Up to and including every version before [Windows 2000](https://en.wikipedia.org/wiki/Windows_2000), Microsoft used an in-house version control system named Source Library Manager (SLM). Shortly after Windows 2000 was released, Microsoft switched to a fork of Perforce named Source Depot.[^cite_note-88] This system was used up until 2017 when the system could not keep up with the size of Windows.[^cite_note-ArsWindowsGit2017-89] Microsoft had begun to integrate Git into [Team Foundation Server](https://en.wikipedia.org/wiki/Team_Foundation_Server) in 2013,[^cite_note-90] but Windows (and Office) continued to rely on Source Depot.[^cite_note-91] The Windows code in Source Depot was divided among 65 different repositories.[^cite_note-ArsWindowsGit2017-89]

In 2017 Microsoft announced that it would start using [Git](https://en.wikipedia.org/wiki/Git), an open source version control system created by [Linus Torvalds](https://en.wikipedia.org/wiki/Linus_Torvalds), and in May 2017 they reported that the migration into a new Git repository was complete.[^cite_note-PBright-65][^cite_note-92][^cite_note-\:0-93]

### VFSForGit

Each Git repository contains a complete history of all the files, which tends to be very large for Windows.[^cite_note-94] Microsoft has been working on a new project called the [Virtual File System for Git](https://en.wikipedia.org/wiki/Virtual_File_System_for_Git) (VFSForGit) to address these challenges.[^cite_note-\:0-93]

In 2021 the VFS for Git was superseded by **Scalar**.[^cite_note-95]

## Security

Early versions of Windows were designed at a time when [malware](https://en.wikipedia.org/wiki/Malware) and networking were less common, and had few built-in security features; they did not provide access privileges to allow a user to prevent other users from accessing their files, and they did not provide [memory protection](https://en.wikipedia.org/wiki/Memory_protection) to prevent one process from reading or writing another process's address space or to prevent a process from code or data used by privileged-mode code.

While the [Windows 9x](https://en.wikipedia.org/wiki/Windows_9x) series offered the option of having profiles for multiple users with separate profiles and home folders, it had no concept of [access privileges](https://en.wikipedia.org/wiki/Principle_of_least_privilege), allowing any user to edit others' files. In addition, while it ran separate 32-bit applications in separate address spaces, protecting an application's code and data from being read or written by another application, it did not protect the first megabyte of memory from [userland](https://en.wikipedia.org/wiki/Userland_\(computing\)) applications for compatibility reasons. This area of memory contains code critical to the functioning of the operating system, and by writing into this area of memory an application can [crash](https://en.wikipedia.org/wiki/Crash_\(computing\)) or [freeze](https://en.wikipedia.org/wiki/Hang_\(computing\)) the operating system. This was a source of instability as faulty applications could accidentally write into this region, potentially corrupting important operating system memory, which usually resulted in some form of system error and halt.[^cite_note-106]

[Windows NT](https://en.wikipedia.org/wiki/Windows_NT) was far more secure, implementing access privileges and full memory protection, and, while 32-bit programs meeting the DoD's C2 security rating.[^cite_note-107] Prior to [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista), the default user account created during the setup process was an [administrator](https://en.wikipedia.org/wiki/Windows_administrator) account; the user, and any program the user launched, had full access to the machine. Though [Windows XP](https://en.wikipedia.org/wiki/Windows_XP) did offer an option of turning administrator accounts into limited accounts, the majority of home users did not do so, partially due to the number of programs which required administrator rights to function properly. As a result, most home users still ran as administrator all the time. These architectural flaws, combined with Windows's very high popularity, made Windows a frequent target of [computer worm](https://en.wikipedia.org/wiki/Computer_worm) and [virus](https://en.wikipedia.org/wiki/Computer_virus) writers.[^cite_note-108][^cite_note-Patrizio2-109][^cite_note-110]

Furthermore, although Windows NT and its successors are designed for security (including on a network) and multi-user PCs, they were not initially designed with Internet security in mind as much, since, when it was first developed in the early 1990s, Internet use was less prevalent.[^cite_note-111]

In a 2002 strategy memo entitled "Trustworthy computing" sent to every Microsoft employee, Bill Gates declared that security should become Microsoft's highest priority.[^cite_note-112][^cite_note-113]

[Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista) introduced a privilege elevation system called [User Account Control](https://en.wikipedia.org/wiki/User_Account_Control).[^cite_note-114] When logging in as a standard user, a logon session is created and a [token](https://en.wikipedia.org/wiki/Token_\(Windows_NT_architecture\)) containing only the most basic privileges is assigned. In this way, the new logon session is incapable of making changes that would affect the entire system. When logging in as a user in the Administrators group, two separate tokens are assigned. The first token contains all privileges typically awarded to an administrator, and the second is a restricted token similar to what a standard user would receive. User applications, including the [Windows shell](https://en.wikipedia.org/wiki/Windows_shell), are then started with the restricted token, resulting in a reduced privilege environment even under an Administrator account. When an application requests higher privileges or "Run as administrator" is clicked, UAC will prompt for confirmation and, if consent is given (including administrator credentials if the account requesting the elevation is not a member of the administrators group), start the process using the unrestricted token.[^cite_note-kennykerr2-115]

Leaked documents from 2013 to 2016 codenamed [Vault 7](https://en.wikipedia.org/wiki/Vault_7) detail the capabilities of the [CIA](5183633.md) to perform electronic surveillance and cyber warfare,[^cite_note-116] such as the ability to compromise operating systems such as Windows.[^cite_note-117]

In August 2019, computer experts reported that the [BlueKeep](https://en.wikipedia.org/wiki/BlueKeep) security vulnerability, [CVE](https://en.wikipedia.org/wiki/CVE_\(identifier\))-[2019-0708](https://nvd.nist.gov/vuln/detail/CVE-2019-0708), that potentially affects older unpatched Windows versions via the program's [Remote Desktop Protocol](https://en.wikipedia.org/wiki/Remote_Desktop_Protocol), allowing for the possibility of [remote code execution](https://en.wikipedia.org/wiki/Remote_code_execution), may include related flaws, collectively named *[DejaBlue](https://en.wikipedia.org/wiki/DejaBlue)*, affecting newer Windows versions (i.e., [Windows 7](https://en.wikipedia.org/wiki/Windows_7) and all recent versions) as well.[^cite_note-WRD-201908132-118] In addition, experts reported a Microsoft [security vulnerability](https://en.wikipedia.org/wiki/Security_vulnerability), [CVE](https://en.wikipedia.org/wiki/CVE_\(identifier\))-[2019-1162](https://nvd.nist.gov/vuln/detail/CVE-2019-1162), based on [legacy code](https://en.wikipedia.org/wiki/Legacy_code) involving [Microsoft CTF and ctfmon (ctfmon.exe)](https://en.wikipedia.org/wiki/Text_Services_Framework#ctfmon), that affects all [Windows](https://en.wikipedia.org/wiki/Windows) versions from [Windows XP](https://en.wikipedia.org/wiki/Windows_XP) to the then most recent [Windows 10](43989914.md) versions; a patch to correct the flaw is available.[^cite_note-TP-201908142-119]

Microsoft releases security patches through its [Windows Update](https://en.wikipedia.org/wiki/Windows_Update) service approximately once a month (usually the [second Tuesday](https://en.wikipedia.org/wiki/Patch_Tuesday) of the month), although critical updates are made available at shorter intervals when necessary.[^cite_note-120] Versions subsequent to Windows 2000 SP3 and Windows XP implemented automatic download and installation of updates, substantially increasing the number of users installing security updates.[^cite_note-121]

Windows integrates the Windows Defender antivirus, which is seen as one of the best available.[^cite_note-122] Windows also implements [Secure Boot](https://en.wikipedia.org/wiki/Secure_Boot), [Control Flow Guard](https://en.wikipedia.org/wiki/Control-flow_integrity), ransomware protection, [BitLocker](https://en.wikipedia.org/wiki/BitLocker) disk encryption, a firewall, and Windows SmartScreen.

In July 2024, Microsoft signalled an intention to limit kernel access and improve overall security, following a highly publicised [CrowdStrike update](https://en.wikipedia.org/wiki/2024_CrowdStrike-related_IT_outages) that caused 8.5 million Windows PCs to crash.[^cite_note-CrowdStrike9to5-123] Part of that initiative is to rewrite parts of Windows in [Rust](https://en.wikipedia.org/wiki/Rust_\(programming_language\)), a [memory-safe](https://en.wikipedia.org/wiki/Memory-safe) language.[^cite_note-124] In 2025 Microsoft stopped offering support to Window 10 users, including providing security updates. Microsoft encouraged people to upgrade to Windows 11 or if this wasn't possible, to sign-up for extended security updates.[^cite_note-125]

### File permissions

All Windows versions from Windows NT 3 have been based on a file system permission system referred to as [AGDLP](https://en.wikipedia.org/wiki/AGDLP) (Accounts, Global, Domain Local, Permissions) in which file permissions are applied to the file/folder in the form of a 'local group' which then has other 'global groups' as members. These global groups then hold other groups or users depending on different Windows versions used. This system varies from other vendor products such as [Linux](https://en.wikipedia.org/wiki/Linux) and [NetWare](https://en.wikipedia.org/wiki/NetWare) due to the 'static' allocation of permission being applied directly to the file or folder. However using this process of AGLP/AGDLP/AGUDLP allows a small number of static permissions to be applied and allows for easy changes to the account groups without reapplying the file permissions on the files and folders.[^cite_note-126]

## Alternative implementations

Owing to the operating system's popularity, a number of applications have been released that aim to provide compatibility with Windows applications, either as a [compatibility layer](https://en.wikipedia.org/wiki/Compatibility_layer) for another operating system, or as a standalone system that can run software written for Windows out of the box. These include:

- [Wine](https://en.wikipedia.org/wiki/Wine_\(software\)) – a [free and open-source](https://en.wikipedia.org/wiki/Free_and_open-source) implementation of the [Windows API](https://en.wikipedia.org/wiki/Windows_API), allowing one to run many Windows applications on x86-based platforms, including [UNIX](https://en.wikipedia.org/wiki/UNIX), [Linux](https://en.wikipedia.org/wiki/Linux) and [macOS](https://en.wikipedia.org/wiki/MacOS). Wine developers refer to it as a "compatibility layer"

  [^cite_note-127]

  &#x20;and use Windows-style APIs to emulate a Windows environment.&#x20;

  - [CrossOver](https://en.wikipedia.org/wiki/CrossOver_\(software\)) – a Wine package with licensed fonts. Its developers are regular contributors to Wine.

  - [Proton](https://en.wikipedia.org/wiki/Proton_\(software\)) – A fork of Wine by Valve to run Windows games on Linux and other Unix-based operating systems.

- [ReactOS](https://en.wikipedia.org/wiki/ReactOS) – an open-source OS intended to run the same software as Windows, originally designed to simulate Windows NT 4.0, later aiming at Windows 7 compatibility. It has been in the [development stage](https://en.wikipedia.org/wiki/Development_stage) since 1996.

- Freedows OS – an open-source attempt at creating a Windows clone for x86 platforms, intended to be released under the [GNU General Public License](https://en.wikipedia.org/wiki/GNU_General_Public_License). Started in 1996 by Reece K. Sellin, the project was never completed, getting only to the stage of design discussions which featured a number of novel concepts until it was suspended in 2002.
