**Semiconductor memory** is a [digital electronic](https://en.wikipedia.org/wiki/Digital_electronics) [semiconductor device](https://en.wikipedia.org/wiki/Semiconductor_device) used for [digital data storage](https://en.wikipedia.org/wiki/Digital_data_storage), such as [computer memory](https://en.wikipedia.org/wiki/Computer_memory). It typically refers to devices in which data is stored within [metal–oxide–semiconductor](https://en.wikipedia.org/wiki/Metal%E2%80%93oxide%E2%80%93semiconductor) (MOS) [memory cells](https://en.wikipedia.org/wiki/Memory_cell_\(computing\)) on a [silicon](https://en.wikipedia.org/wiki/Silicon) [integrated circuit](https://en.wikipedia.org/wiki/Integrated_circuit) **memory chip**.[^cite_note-1][^cite_note-2][^cite_note-FOOTNOTEVeendrick2017314–315-3] There are multiple types using different semiconductor technologies. The two main types of [random-access memory](https://en.wikipedia.org/wiki/Random-access_memory) (RAM) are [static RAM](https://en.wikipedia.org/wiki/Static_RAM) (SRAM), which uses several [transistors](https://en.wikipedia.org/wiki/Transistor) per memory cell, and [dynamic RAM](https://en.wikipedia.org/wiki/Dynamic_RAM) (DRAM), which uses a transistor and a [MOS capacitor](https://en.wikipedia.org/wiki/MOS_capacitor) per cell. [Non-volatile memory](https://en.wikipedia.org/wiki/Non-volatile_memory) (such as [EPROM](https://en.wikipedia.org/wiki/EPROM), [EEPROM](https://en.wikipedia.org/wiki/EEPROM) and [flash memory](https://en.wikipedia.org/wiki/Flash_memory)) uses [floating-gate](https://en.wikipedia.org/wiki/Floating-gate) memory cells, which consist of a single [floating-gate transistor](https://en.wikipedia.org/wiki/Floating-gate_MOSFET) per cell.

Most types of semiconductor memory have the property of [random access](https://en.wikipedia.org/wiki/Random_access),[^cite_note-FIFO-4] which means that it takes the same amount of time to access any memory location, so data can be efficiently accessed in any random order.[^cite_note-Dawoud-5] This contrasts with [data storage](https://en.wikipedia.org/wiki/Data_storage) media such as [CDs](https://en.wikipedia.org/wiki/Compact_disc) which read and write data consecutively and therefore the data can only be accessed in the same sequence it was written. Semiconductor memory also has much faster [access times](https://en.wikipedia.org/wiki/Access_time) than other types of data storage; a [byte](https://en.wikipedia.org/wiki/Byte) of data can be written to or read from semiconductor memory within a few [nanoseconds](https://en.wikipedia.org/wiki/Nanosecond), while access time for rotating storage such as hard disks is in the range of milliseconds. For these reasons it is used for [primary storage](https://en.wikipedia.org/wiki/Primary_storage), to hold the program and data the computer is currently working on, among other uses.

As of 2017, sales of semiconductor memory chips are \$124 billion annually, accounting for 30% of the [semiconductor industry](612813.md).[^cite_note-6] [Shift registers](https://en.wikipedia.org/wiki/Shift_register), [processor registers](https://en.wikipedia.org/wiki/Processor_register), [data buffers](https://en.wikipedia.org/wiki/Data_buffer) and other small digital registers that have no [memory address decoding mechanism](https://en.wikipedia.org/wiki/Address_decoder) are typically not referred to as *memory* although they also store digital data.

## Description

See also: [Computer memory](https://en.wikipedia.org/wiki/Computer_memory)

In a semiconductor memory chip, each [bit](https://en.wikipedia.org/wiki/Binary_digit) of binary data is stored in a tiny circuit called a *[memory cell](https://en.wikipedia.org/wiki/Memory_cell_\(computing\))* consisting of one to several [transistors](https://en.wikipedia.org/wiki/Transistor). The memory cells are laid out in rectangular arrays on the surface of the chip. The 1-bit memory cells are grouped in small units called *"words,"* which are accessed together as a single memory address. Memory is manufactured in [word length](https://en.wikipedia.org/wiki/Word_length) that is usually a power of two, typically *N*=1, 2, 4 or 8 bits.

Data is accessed by means of a binary number called a [memory address](https://en.wikipedia.org/wiki/Memory_address) applied to the chip's address pins, which specifies which word in the chip is to be accessed. If the memory address consists of *M* bits, the number of addresses on the chip is 2<sup>*M*</sup>, each containing an *N* bit word. Consequently, the amount of data stored in each chip is *N*2<sup>*M*</sup> bits.[^cite_note-Dawoud-5] The memory storage capacity for *M* number of [address lines](https://en.wikipedia.org/wiki/Address_line) is given by 2<sup>*M*</sup>, which is usually in power of two: 2, 4, 8, 16, 32, 64, 128, 256 and 512 and measured in [kilobits](https://en.wikipedia.org/wiki/Kilobit), [megabits](https://en.wikipedia.org/wiki/Megabit), [gigabits](https://en.wikipedia.org/wiki/Gigabit) or [terabits](https://en.wikipedia.org/wiki/Terabit), etc. As of 2014 the largest semiconductor memory chips hold a few gigabits of data, but higher capacity memory is constantly being developed. By combining several integrated circuits, memory can be arranged into a larger word length and/or address space than what is offered by each chip, often but not necessarily a [power of two](https://en.wikipedia.org/wiki/Power_of_two).[^cite_note-Dawoud-5]

The two basic operations performed by a memory chip are "*read*", in which the data contents of a memory word is read out (nondestructively), and "*write*" in which data is stored in a memory word, replacing any data that was previously stored there. To increase data rate, in some of the latest types of memory chips such as [DDR SDRAM](https://en.wikipedia.org/wiki/DDR_SDRAM) multiple words are accessed with each read or write operation.

In addition to standalone memory chips, blocks of semiconductor memory are integral parts of many computer and data processing integrated circuits. For example, the [microprocessor](https://en.wikipedia.org/wiki/Microprocessor) chips that run computers contain [cache memory](https://en.wikipedia.org/wiki/Cache_memory) to store instructions awaiting execution.

## Types

### Volatile memory



[RAM](https://en.wikipedia.org/wiki/Random-access_memory) chips for computers usually come on removable [memory modules](https://en.wikipedia.org/wiki/Memory_module) like these. Additional memory can be added to the computer by plugging in additional modules.&#x20;

[Volatile memory](https://en.wikipedia.org/wiki/Volatile_memory) loses its stored data when the power to the memory chip is turned off. However it can be faster and less expensive than non-volatile memory. This type is used for the main memory in most computers, since data is stored on the [hard disk](https://en.wikipedia.org/wiki/Hard_disk) while the computer is off. Major types are:[^cite_note-Godse-7][^cite_note-Arora-8]

**RAM** (*[Random-access memory](https://en.wikipedia.org/wiki/Random-access_memory)*) – This has become a generic term for any semiconductor memory that can be written to, as well as read from, in contrast to ROM *(below)*, which can only be read. All semiconductor memory, not just RAM, has the property of [random access](https://en.wikipedia.org/wiki/Random_access).

- **DRAM** (*[Dynamic random-access memory](https://en.wikipedia.org/wiki/Dynamic_random-access_memory)*) – This uses [memory cells](https://en.wikipedia.org/wiki/Memory_cell_\(computing\)) consisting of one [MOSFET](https://en.wikipedia.org/wiki/MOSFET) (MOS field-effect transistor) and one [MOS capacitor](https://en.wikipedia.org/wiki/MOS_capacitor) to store each bit. This type of RAM is the cheapest and highest in density, so it is used for the main memory in computers. However, the [electric charge](https://en.wikipedia.org/wiki/Electric_charge) that stores the data in the memory cells slowly leaks out, so the memory cells must be periodically [refreshed](https://en.wikipedia.org/wiki/Memory_refresh) (rewritten) which requires additional circuitry. The refresh process is handled internally by the computer and is transparent to its user.&#x20;

  - **FPM DRAM** (*[Fast page mode DRAM](https://en.wikipedia.org/wiki/FPM_DRAM)*) – An older type of asynchronous DRAM that improved on previous types by allowing repeated accesses to a single "page" of memory to occur at a faster rate. Used in the mid-1990s.

  - **EDO DRAM** (*[Extended data out DRAM](https://en.wikipedia.org/wiki/Extended_data_out_DRAM)*) – An older type of asynchronous DRAM which had faster access time than earlier types by being able to initiate a new memory access while data from the previous access was still being transferred. Used in the later part of the 1990s.

  - **VRAM** (*[Video random access memory](https://en.wikipedia.org/wiki/Video_RAM)*) – An older type of [dual-ported](https://en.wikipedia.org/wiki/Dual-ported_RAM) memory once used for the [frame buffers](https://en.wikipedia.org/wiki/Frame_buffer) of [video adapters](https://en.wikipedia.org/wiki/Video_adapters) (video cards).

  - **SDRAM** (*[Synchronous dynamic random-access memory](https://en.wikipedia.org/wiki/Synchronous_dynamic_random-access_memory)*) – This added circuitry to the DRAM chip which synchronizes all operations with a clock signal added to the computer's [memory bus](https://en.wikipedia.org/wiki/Memory_bus). This allowed the chip to process multiple memory requests simultaneously using *[pipelining](https://en.wikipedia.org/wiki/Pipeline_\(computing\))*, to increase the speed. The data on the chip is also divided into *banks* which can each work on a memory operation simultaneously. This became the dominant type of computer memory by about the year 2000.&#x20;

    - **[DDR SDRAM](https://en.wikipedia.org/wiki/DDR_SDRAM)** (*Double data rate SDRAM*) – This could transfer twice the data (two consecutive words) on each clock cycle by [double pumping](https://en.wikipedia.org/wiki/Double_pumping) (transferring data on both the rising and falling edges of the clock pulse). Extensions of this idea are the current (2012) technique being used to increase memory access rate and throughput. Since it is proving difficult to further increase the internal clock speed of memory chips, these chips increase the transfer rate by transferring more data words on each clock cycle&#x20;

      - **[DDR2 SDRAM](https://en.wikipedia.org/wiki/DDR2_SDRAM)** – Transfers 4 consecutive words per internal clock cycle

      - **[DDR3 SDRAM](https://en.wikipedia.org/wiki/DDR3_SDRAM)** – Transfers 8 consecutive words per internal clock cycle.

      - **[DDR4 SDRAM](https://en.wikipedia.org/wiki/DDR4_SDRAM)** – Transfers 16 consecutive words per internal clock cycle.

      - **[DDR5 SDRAM](https://en.wikipedia.org/wiki/DDR5_SDRAM)**

    - **RDRAM** (*[Rambus DRAM](https://en.wikipedia.org/wiki/Rambus_DRAM)*) – An alternate double data rate memory standard that was used on some Intel systems but ultimately lost out to DDR SDRAM.&#x20;

      - **[XDR DRAM](https://en.wikipedia.org/wiki/XDR_DRAM)** (*Extreme data rate DRAM*)

    - **SGRAM** (*[Synchronous graphics RAM](https://en.wikipedia.org/wiki/Synchronous_graphics_RAM)*) – A specialized type of SDRAM made for [graphics adaptors](https://en.wikipedia.org/wiki/Graphics_adaptor) (video cards). It can perform graphics-related operations such as [bit masking](https://en.wikipedia.org/wiki/Bit_masking) and block write, and can open two pages of memory at once.&#x20;

      - **[GDDR SDRAM](https://en.wikipedia.org/wiki/GDDR_SDRAM)** (*Graphics DDR SDRAM*)&#x20;

        - **[GDDR2](https://en.wikipedia.org/wiki/GDDR2)**

        - **[GDDR3 SDRAM](https://en.wikipedia.org/wiki/GDDR3_SDRAM)**

        - **[GDDR4 SDRAM](https://en.wikipedia.org/wiki/GDDR4_SDRAM)**

        - **[GDDR5 SDRAM](https://en.wikipedia.org/wiki/GDDR5_SDRAM)**

        - **[GDDR6 SDRAM](https://en.wikipedia.org/wiki/GDDR6_SDRAM)**

    - **HBM** (*[High Bandwidth Memory](https://en.wikipedia.org/wiki/High_Bandwidth_Memory)*) – A development of SDRAM used in graphics cards that can transfer data at a faster rate. It consists of multiple memory chips stacked on top of one another, with a wider data bus.

  - **PSRAM** (*[Pseudostatic RAM](https://en.wikipedia.org/wiki/Pseudostatic_RAM)*) – This is DRAM which has circuitry to perform [memory refresh](https://en.wikipedia.org/wiki/Memory_refresh) on the chip, so that it acts like SRAM, allowing the external memory controller to be shut down to save energy. It is used in a few [game consoles](https://en.wikipedia.org/wiki/Game_console) such as the [Wii](https://en.wikipedia.org/wiki/Wii).

- **SRAM** (*[Static random-access memory](https://en.wikipedia.org/wiki/Static_random-access_memory)*) – This stores each [bit](https://en.wikipedia.org/wiki/Bit) of data in a circuit called a [flip-flop](https://en.wikipedia.org/wiki/Flip-flop_\(electronics\)), made of 4 to 6 transistors. SRAM is less dense and more expensive per bit than DRAM, but faster and does not require [memory refresh](https://en.wikipedia.org/wiki/Memory_refresh). It is used for smaller [cache memories](https://en.wikipedia.org/wiki/Cache_memory) in computers.

- **CAM** (*[Content-addressable memory](https://en.wikipedia.org/wiki/Content-addressable_memory)*) – This is a specialized type in which, instead of accessing data using an address, a data word is applied and the memory returns the location if the word is stored in the memory. It is mostly incorporated in other chips such as [microprocessors](https://en.wikipedia.org/wiki/Microprocessor) where it is used for [cache memory](https://en.wikipedia.org/wiki/Cache_memory).

### Non-volatile memory

[Non-volatile memory](https://en.wikipedia.org/wiki/Non-volatile_memory) (NVM) preserves the data stored in it during periods when the power to the chip is turned off. Therefore, it is used for the memory in portable devices, which don't have disks, and for removable [memory cards](https://en.wikipedia.org/wiki/Memory_cards) among other uses. Major types are:[^cite_note-Godse-7][^cite_note-Arora-8]

- **ROM** (*[Read-only memory](https://en.wikipedia.org/wiki/Read-only_memory)*) – This is designed to hold permanent data, and in normal operation is only read from, not written to. Although many types can be written to, the writing process is slow and usually all the data in the chip must be rewritten at once. It is usually used to store [system software](https://en.wikipedia.org/wiki/System_software) which must be immediately accessible to the computer, such as the [BIOS](https://en.wikipedia.org/wiki/BIOS) program which starts the computer, and the software ([microcode](https://en.wikipedia.org/wiki/Microcode)) for portable devices and embedded computers such as [microcontrollers](https://en.wikipedia.org/wiki/Microcontroller).&#x20;

  - **MROM** ([*Mask programmed ROM* or *Mask ROM*](https://en.wikipedia.org/wiki/Mask_ROM)) – In this type the data is programmed into the chip when the chip is manufactured, so it is only used for large production runs. It cannot be rewritten with new data.

  - **PROM** (*[Programmable read-only memory](https://en.wikipedia.org/wiki/Programmable_read-only_memory)*) – In this type the data is written into an existing PROM chip before it is installed in the circuit, but it can only be written once. The data is written by plugging the chip into a device called a PROM programmer.

  - **EPROM** (*[Erasable programmable read-only memory](https://en.wikipedia.org/wiki/Erasable_programmable_read-only_memory)* or UVEPROM) – In this type the data in it can be rewritten by removing the chip from the circuit board, exposing it to an [ultraviolet light](https://en.wikipedia.org/wiki/Ultraviolet_light) to erase the existing data, and plugging it into a PROM programmer. The IC package has a small transparent "window" in the top to admit the UV light. It is often used for prototypes and small production run devices, where the program in it may have to be changed at the factory.&#x20;

    

    4M EPROM, showing transparent window used to erase the chip

  - **EEPROM** (*[Electrically erasable programmable read-only memory](https://en.wikipedia.org/wiki/Electrically_erasable_programmable_read-only_memory)*) – In this type the data can be rewritten electrically, while the chip is on the circuit board, but the writing process is slow. This type is used to hold [firmware](https://en.wikipedia.org/wiki/Firmware), the low level microcode which runs hardware devices, such as the [BIOS](https://en.wikipedia.org/wiki/BIOS) program in most computers, so that it can be updated.

- **NVRAM** (*[Non-volatile random-access memory](https://en.wikipedia.org/wiki/Non-volatile_random-access_memory)*)&#x20;

  - **FRAM** (*[Ferroelectric RAM](https://en.wikipedia.org/wiki/Ferroelectric_RAM)*) – One type of nonvolatile RAM.

- **[Flash memory](https://en.wikipedia.org/wiki/Flash_memory)** – In this type the writing process is intermediate in speed between EEPROMS and RAM memory; it can be written to, but not fast enough to serve as main memory. It is often used as a semiconductor version of a [hard disk](https://en.wikipedia.org/wiki/Hard_disk), to store files. It is used in portable devices such as PDAs, [USB flash drives](https://en.wikipedia.org/wiki/USB_flash_drives), and removable [memory cards](https://en.wikipedia.org/wiki/Memory_card) used in [digital cameras](https://en.wikipedia.org/wiki/Digital_camera) and [cellphones](https://en.wikipedia.org/wiki/Cellphone).

## History

See also: [Computer memory](https://en.wikipedia.org/wiki/Computer_memory) and [Memory cell (computing)](https://en.wikipedia.org/wiki/Memory_cell_\(computing\))

Early [computer memory](https://en.wikipedia.org/wiki/Computer_memory) consisted of [magnetic-core memory](https://en.wikipedia.org/wiki/Magnetic-core_memory), as early [solid-state electronic](https://en.wikipedia.org/wiki/Solid-state_electronic) [semiconductors](https://en.wikipedia.org/wiki/Semiconductors), including [transistors](https://en.wikipedia.org/wiki/Transistors) such as the [bipolar junction transistor](https://en.wikipedia.org/wiki/Bipolar_junction_transistor) (BJT), were impractical for use as digital storage elements ([memory cells](https://en.wikipedia.org/wiki/Memory_cell_\(computing\))). The earliest semiconductor memory dates back to the early 1960s, with bipolar memory, which used bipolar transistors.[^cite_note-computerhistory1966-9] **Bipolar semiconductor memory&#x20;**&#x6D;ade from [discrete devices](https://en.wikipedia.org/wiki/Discrete_device) was first shipped by [Texas Instruments](https://en.wikipedia.org/wiki/Texas_Instruments) to the [United States Air Force](32090.md) in 1961. The same year, the concept of [solid-state](https://en.wikipedia.org/wiki/Solid-state_electronics) memory on an [integrated circuit](https://en.wikipedia.org/wiki/Integrated_circuit) (IC) chip was proposed by [applications engineer](https://en.wikipedia.org/wiki/Applications_engineers) Bob Norman at [Fairchild Semiconductor](https://en.wikipedia.org/wiki/Fairchild_Semiconductor).[^cite_note-computerhistory-timeline-10] The **first single-chip** memory IC was the BJT 16-bit IBM SP95 fabricated in December 1965, engineered by Paul Castrucci.[^cite_note-computerhistory1966-9][^cite_note-computerhistory-timeline-10] While bipolar memory offered improved performance over magnetic-core memory, it could not compete with the lower price of magnetic-core memory, which remained dominant up until the late 1960s.[^cite_note-computerhistory1966-9] Bipolar memory failed to replace magnetic-core memory because bipolar [flip-flop](https://en.wikipedia.org/wiki/Flip-flop_\(electronics\)) circuits were too large and expensive.[^cite_note-11]

### MOS memory

See also: [MOSFET](https://en.wikipedia.org/wiki/MOSFET)

The advent of the [metal–oxide–semiconductor field-effect transistor](https://en.wikipedia.org/wiki/Metal%E2%80%93oxide%E2%80%93semiconductor_field-effect_transistor) (MOSFET), invented by [Mohamed M. Atalla](https://en.wikipedia.org/wiki/Mohamed_M._Atalla) and [Dawon Kahng](https://en.wikipedia.org/wiki/Dawon_Kahng) at [Bell Labs](https://en.wikipedia.org/wiki/Bell_Labs) in 1959,[^cite_note-computerhistory-12] enabled the practical use of [metal–oxide–semiconductor](https://en.wikipedia.org/wiki/Metal%E2%80%93oxide%E2%80%93semiconductor) (MOS) transistors as [memory cell](https://en.wikipedia.org/wiki/Memory_cell_\(computing\)) storage elements, a function previously served by [magnetic cores](https://en.wikipedia.org/wiki/Magnetic-core_memory) in [computer memory](https://en.wikipedia.org/wiki/Computer_memory). MOS memory was developed by John Schmidt at [Fairchild Semiconductor](https://en.wikipedia.org/wiki/Fairchild_Semiconductor) in 1964.[^cite_note-computerhistory1970-13][^cite_note-14] In addition to higher performance, MOS memory was cheaper and consumed less power than magnetic-core memory.[^cite_note-computerhistory1970-13] This led to MOSFETs eventually replacing magnetic cores as the standard storage elements in computer memory.

In 1965, J. Wood and R. Ball of the [Royal Radar Establishment](https://en.wikipedia.org/wiki/Royal_Radar_Establishment) proposed digital storage systems that use [CMOS](https://en.wikipedia.org/wiki/CMOS) (complementary MOS) memory cells, in addition to MOSFET [power devices](https://en.wikipedia.org/wiki/Power_devices) for the [power supply](https://en.wikipedia.org/wiki/Power_supply), switched cross-coupling, [switches](https://en.wikipedia.org/wiki/Switches) and [delay-line storage](https://en.wikipedia.org/wiki/Delay-line_memory).[^cite_note-15] The development of [silicon-gate](https://en.wikipedia.org/wiki/Silicon-gate) [MOS integrated circuit](https://en.wikipedia.org/wiki/MOS_integrated_circuit) (MOS IC) technology by [Federico Faggin](https://en.wikipedia.org/wiki/Federico_Faggin) at Fairchild in 1968 enabled the production of MOS [memory chips](1313007.md).[^cite_note-16] [NMOS](https://en.wikipedia.org/wiki/NMOS_logic) memory was commercialized by [IBM](https://en.wikipedia.org/wiki/IBM) in the early 1970s.[^cite_note-17] MOS memory overtook magnetic core memory as the dominant memory technology in the early 1970s.[^cite_note-computerhistory1970-13]

The term "memory" when used with reference to computers most often refers to volatile [random-access memory](https://en.wikipedia.org/wiki/Random-access_memory) (RAM). The two main types of volatile RAM are [static random-access memory](https://en.wikipedia.org/wiki/Static_random-access_memory) (SRAM) and [dynamic random-access memory](https://en.wikipedia.org/wiki/Dynamic_random-access_memory) (DRAM). Bipolar SRAM was invented by Robert Norman at Fairchild Semiconductor in 1963,[^cite_note-computerhistory1966-9] followed by the development of MOS SRAM by John Schmidt at Fairchild in 1964.[^cite_note-computerhistory1970-13] SRAM became an alternative to magnetic-core memory, but required six MOS transistors for each [bit](https://en.wikipedia.org/wiki/Bit) of data.[^cite_note-ibm100-18] Commercial use of SRAM began in 1965, when IBM introduced their SP95 SRAM chip for the [System/360 Model 95](https://en.wikipedia.org/wiki/IBM_System/360).[^cite_note-computerhistory1966-9]

[Toshiba](https://en.wikipedia.org/wiki/Toshiba) introduced bipolar DRAM [memory cells](https://en.wikipedia.org/wiki/Memory_cell_\(computing\)) for its Toscal BC-1411 [electronic calculator](https://en.wikipedia.org/wiki/Electronic_calculator) in 1965.[^cite_note-bc-spec-19][^cite_note-bc-20] While it offered improved performance over magnetic-core memory, bipolar DRAM could not compete with the lower price of the then dominant magnetic-core memory.[^cite_note-21] MOS technology is the basis for modern DRAM. In 1966, Dr. [Robert H. Dennard](https://en.wikipedia.org/wiki/Robert_H._Dennard) at the [IBM Thomas J. Watson Research Center](https://en.wikipedia.org/wiki/IBM_Thomas_J._Watson_Research_Center) was working on MOS memory. While examining the characteristics of MOS technology, he found it was capable of building [capacitors](https://en.wikipedia.org/wiki/Capacitors), and that storing a charge or no charge on the MOS capacitor could represent the 1 and 0 of a bit, while the MOS transistor could control writing the charge to the capacitor. This led to his development of a single-transistor DRAM memory cell.[^cite_note-ibm100-18] In 1967, Dennard filed a patent under IBM for a single-transistor DRAM memory cell, based on MOS technology.[^cite_note-22] This led to the first commercial DRAM IC chip, the [Intel 1103](https://en.wikipedia.org/wiki/Intel_1103), in October 1970.[^cite_note-Intel2003-23][^cite_note-HC-24][^cite_note-Lojek-1103-25] [Synchronous dynamic random-access memory](https://en.wikipedia.org/wiki/Synchronous_dynamic_random-access_memory) (SDRAM) later debuted with the [Samsung](46445426.md) KM48SL2000 chip in 1992.[^cite_note-26][^cite_note-electronic-design-27]

The term "memory" is also often used to refer to [non-volatile memory](https://en.wikipedia.org/wiki/Non-volatile_memory), specifically [flash memory](https://en.wikipedia.org/wiki/Flash_memory). It has origins in [read-only memory](https://en.wikipedia.org/wiki/Read-only_memory) (ROM). [Programmable read-only memory](https://en.wikipedia.org/wiki/Programmable_read-only_memory) (PROM) was invented by [Wen Tsing Chow](https://en.wikipedia.org/wiki/Wen_Tsing_Chow) in 1956, while working for the Arma Division of the American Bosch Arma Corporation.[^cite_note-Huang2008-28][^cite_note-FOOTNOTESaeckerMarkl2013136-29] In 1967, Dawon Kahng and [Simon Sze](https://en.wikipedia.org/wiki/Simon_Sze) of Bell Labs proposed that the [floating gate](https://en.wikipedia.org/wiki/Floating_gate_MOSFET) of a MOS [semiconductor device](https://en.wikipedia.org/wiki/Semiconductor_device) could be used for the cell of a reprogrammable [read-only memory](https://en.wikipedia.org/wiki/Read-only_memory) (ROM), which led to [Dov Frohman](https://en.wikipedia.org/wiki/Dov_Frohman) of [Intel](https://en.wikipedia.org/wiki/Intel) inventing [EPROM](https://en.wikipedia.org/wiki/EPROM) (erasable PROM) in 1971.[^cite_note-computerhistory1971-30] [EEPROM](https://en.wikipedia.org/wiki/EEPROM) (electrically erasable PROM) was developed by Yasuo Tarui, Yutaka Hayashi and Kiyoko Naga at Japan's [Ministry of International Trade and Industry](https://en.wikipedia.org/wiki/Ministry_of_International_Trade_and_Industry) (MITI) [Electrotechnical Laboratory](https://en.wikipedia.org/wiki/Electrotechnical_Laboratory) in 1972.[^cite_note-31] Flash memory was invented by [Fujio Masuoka](https://en.wikipedia.org/wiki/Fujio_Masuoka) at [Toshiba](https://en.wikipedia.org/wiki/Toshiba) in the early 1980s.[^cite_note-32][^cite_note-33] Masuoka and colleagues presented the invention of [NOR flash](https://en.wikipedia.org/wiki/NOR_flash) in 1984,[^cite_note-34] and then [NAND flash](https://en.wikipedia.org/wiki/NAND_flash) in 1987.[^cite_note-35] Toshiba commercialized NAND flash memory in 1987.[^cite_note-\:0-36][^cite_note-37]
