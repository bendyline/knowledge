**Amazon Web Services, Inc.** (**AWS**) is a subsidiary of [Amazon](90451.md) that provides [on-demand](https://en.wikipedia.org/wiki/Software_as_a_service) [cloud computing](19541494.md) [platforms](https://en.wikipedia.org/wiki/Computing_platform) and [APIs](https://en.wikipedia.org/wiki/API) to individuals, companies, and governments, on a metered, pay-as-you-go basis.

Clients often use this in combination with [autoscaling](https://en.wikipedia.org/wiki/Elasticity_\(system_resource\)) (a process that allows a client to use more computing in times of high application usage, and then scale down to reduce costs when there is less traffic). These cloud computing [web services](https://en.wikipedia.org/wiki/Web_service) provide various services related to networking, compute, storage, [middleware](https://en.wikipedia.org/wiki/Middleware), [IoT](https://en.wikipedia.org/wiki/Internet_of_things) and other processing capacity, as well as [software tools](https://en.wikipedia.org/wiki/Software_tools) via AWS [server farms](https://en.wikipedia.org/wiki/Server_farm). This frees clients from managing, scaling, and patching hardware and operating systems.

One of the foundational services is [Amazon Elastic Compute Cloud](https://en.wikipedia.org/wiki/Amazon_Elastic_Compute_Cloud) (EC2), which allows users to have at their disposal a [virtual](https://en.wikipedia.org/wiki/Virtualization) [cluster of computers](https://en.wikipedia.org/wiki/Computer_cluster), with extremely high availability, which can be interacted with over the Internet via [REST](https://en.wikipedia.org/wiki/REST) APIs, a [CLI](https://en.wikipedia.org/wiki/Command-line_interface) or the AWS console. AWS's virtual computers emulate most of the attributes of a real computer, including hardware [central processing units](https://en.wikipedia.org/wiki/Central_processing_unit) (CPUs) and [graphics processing units](390214.md) (GPUs) for processing; local/[RAM](https://en.wikipedia.org/wiki/Random-access_memory) memory; [hard-disk](https://en.wikipedia.org/wiki/Hard_disk_drive) (HDD)/[SSD storage](https://en.wikipedia.org/wiki/Solid-state_drive); a choice of [operating systems](https://en.wikipedia.org/wiki/Operating_system); networking; and pre-loaded application software such as [web servers](https://en.wikipedia.org/wiki/Web_server), [databases](https://en.wikipedia.org/wiki/Database), and [customer relationship management](https://en.wikipedia.org/wiki/Customer_relationship_management) (CRM).

AWS services are delivered to customers via a network of AWS server farms located throughout the world. Fees are based on a combination of usage (known as a "Pay-as-you-go" model), hardware, operating system, software, and networking features chosen by the subscriber requiring various degrees of [availability](https://en.wikipedia.org/wiki/Availability_\(system\)), [redundancy](https://en.wikipedia.org/wiki/Redundancy_\(engineering\)), [security](7398.md), and service options. Subscribers can pay for a single virtual AWS computer, a dedicated physical computer, or clusters of either.[^cite_note-AWSagreement-10] Amazon provides select portions of security for subscribers (e.g. physical security of the data centers) while other aspects of security are the responsibility of the subscriber (e.g. account management, vulnerability scanning, patching). AWS operates from many global geographical regions, including nine in North America.[^cite_note-GlobalInfrastructure-11]

Amazon markets AWS to subscribers as a way of obtaining large-scale computing capacity more quickly and cheaply than building an actual physical server farm.[^cite_note-12] All services are billed based on usage, but each service measures usage in varying ways. As of 2023 Q1, AWS has 31% market share for cloud infrastructure while the next two competitors [Microsoft Azure](https://en.wikipedia.org/wiki/Microsoft_Azure) and [Google Cloud](https://en.wikipedia.org/wiki/Google_Cloud_Platform) have 25%, and 11% respectively, according to Synergy Research Group.[^cite_note-13][^cite_note-14] AWS was the first cloud provider to build infrastructure specifically for U.S. government with respect to security and compliance requirements (2011; launched AWS GovCloud), accredited to support classified workloads (2014; launched AWS Top Secret), and achieve accreditation across all U.S. government data classifications (2017; launched AWS Secret).[^cite_note-auto3-15][^cite_note-16]

## Services

Main articles: [Amazon Elastic Compute Cloud](https://en.wikipedia.org/wiki/Amazon_Elastic_Compute_Cloud) and [Amazon S3](https://en.wikipedia.org/wiki/Amazon_S3)

As of 2025 AWS comprises over 200[^cite_note-techradar-17] products and services including [computing](https://en.wikipedia.org/wiki/Computation), [storage](https://en.wikipedia.org/wiki/Amazon_Elastic_File_System), [networking](https://en.wikipedia.org/wiki/Computer_network), [database](https://en.wikipedia.org/wiki/Database), [analytics](https://en.wikipedia.org/wiki/Analytics), [application services](https://en.wikipedia.org/wiki/Application_service_provider), [deployment](https://en.wikipedia.org/wiki/Software_deployment), [management](https://en.wikipedia.org/wiki/Systems_management), [machine learning](https://en.wikipedia.org/wiki/Machine_learning),[^cite_note-18] [mobile](https://en.wikipedia.org/wiki/Mobile_application_development), [developer tools](https://en.wikipedia.org/wiki/Programming_tool), RobOps and tools for the [Internet of Things](https://en.wikipedia.org/wiki/Internet_of_Things). The most popular include [Amazon Elastic Compute Cloud](https://en.wikipedia.org/wiki/Amazon_Elastic_Compute_Cloud) (EC2), [Amazon Simple Storage Service](https://en.wikipedia.org/wiki/Amazon_Simple_Storage_Service) (Amazon S3), Amazon Connect, and [AWS Lambda](https://en.wikipedia.org/wiki/AWS_Lambda) (a [serverless function](https://en.wikipedia.org/wiki/Serverless_computing) that can perform arbitrary code written in any [language](https://en.wikipedia.org/wiki/Programming_language) that can be configured to be triggered by hundreds of [events](https://en.wikipedia.org/wiki/Event_\(computing\)), including [HTTP](https://en.wikipedia.org/wiki/HTTP) calls).[^cite_note-mostpopularservices-19]

Services expose functionality through APIs for clients to use in their applications. These APIs are accessed over HTTP, using the [REST](https://en.wikipedia.org/wiki/REST) architectural style and [SOAP](https://en.wikipedia.org/wiki/SOAP) protocol for older APIs and exclusively [JSON](https://en.wikipedia.org/wiki/JSON) for newer ones. Clients can interact with these APIs in various ways, including from the AWS console (a website), by using [SDKs](https://en.wikipedia.org/wiki/Software_development_kit) written in various languages (such as [Python](https://en.wikipedia.org/wiki/Python_\(programming_language\)), [Java](https://en.wikipedia.org/wiki/Java_\(programming_language\)), and [JavaScript](https://en.wikipedia.org/wiki/JavaScript)), or by making direct REST calls.

## History

Further information: [Timeline of Amazon Web Services](https://en.wikipedia.org/wiki/Timeline_of_Amazon_Web_Services)

### Founding (2000–2005)



Early AWS "building blocks" logo

The genesis of AWS came in the early 2000s. After building *Merchant.com*, Amazon's e-commerce-as-a-service platform that offers third-party retailers a way to build their own web-stores, Amazon pursued [service-oriented architecture](https://en.wikipedia.org/wiki/Service-oriented_architecture) as a means to scale its engineering operations,[^cite_note-horsemouth-20][^cite_note-foraws-21][^cite_note-tcaws-22][^cite_note-crnaws-23][^cite_note-hilabs-24][^cite_note-vdynamo-25][^cite_note-vogels-26] led by then [CTO](https://en.wikipedia.org/wiki/Chief_technology_officer) Allan Vermeulen.[^cite_note-brad-27]

Around the same time frame, Amazon was frustrated with the speed of its software engineering, and sought to implement various recommendations put forth by Matt Round, an engineering leader at the time, including maximization of autonomy for engineering teams, adoption of [REST](https://en.wikipedia.org/wiki/Representational_state_transfer), standardization of infrastructure, removal of gate-keeping decision-makers (bureaucracy), and [continuous deployment](https://en.wikipedia.org/wiki/Continuous_deployment). He also called for increasing the percentage of the time engineers spent building the software rather than doing other tasks.[^cite_note-velocity-28] Amazon created "a shared [IT](https://en.wikipedia.org/wiki/Information_Technology) platform" so its engineering organizations, which were spending 70% of their time on "undifferentiated heavy-lifting" such as IT and infrastructure problems, could focus on customer-facing innovation instead.[^cite_note-29][^cite_note-aselip-30] Besides, in dealing with unusual peak traffic patterns, especially during [the holiday season](https://en.wikipedia.org/wiki/Economics_of_Christmas), by migrating services to commodity Linux hardware and relying on [open source software](https://en.wikipedia.org/wiki/Open_source_software), Amazon's Infrastructure team, led by Tom Killalea,[^cite_note-tompeak-31] Amazon's first [CISO](https://en.wikipedia.org/wiki/CISO),[^cite_note-32] had already run its data centers and associated services in a "fast, reliable, cheap" way.[^cite_note-tompeak-31]

In July 2002 Amazon.com Web Services, managed by Colin Bryar,[^cite_note-33] launched its first [web services](https://en.wikipedia.org/wiki/Web_service), opening up the Amazon.com platform to all developers.[^cite_note-34] Over one hundred applications were built on top of it by 2004.[^cite_note-tomlinux-35] This unexpected developer interest took Amazon by surprise and convinced them that developers were "hungry for more".[^cite_note-aselip-30]

By the summer of 2003, [Andy Jassy](https://en.wikipedia.org/wiki/Andy_Jassy) had taken over Bryar's portfolio[^cite_note-working-36] at [Rick Dalzell](https://en.wikipedia.org/wiki/Rick_Dalzell)'s behest, after Vermeulen, who was Bezos' first pick, declined the offer.[^cite_note-brad-27] Jassy subsequently mapped out the vision for an "Internet [OS](https://en.wikipedia.org/wiki/Operating_System)"[^cite_note-horsemouth-20][^cite_note-tcaws-22][^cite_note-hilabs-24][^cite_note-telaws-37] made up of foundational infrastructure primitives that alleviated key impediments to shipping software applications faster.[^cite_note-horsemouth-20][^cite_note-foraws-21][^cite_note-tcaws-22][^cite_note-hilabs-24][^cite_note-vogels-26] By fall 2003,[^cite_note-horsemouth-20][^cite_note-tcaws-22] [databases](https://en.wikipedia.org/wiki/Databases), [storage](https://en.wikipedia.org/wiki/Cloud_storage), and [compute](https://en.wikipedia.org/wiki/Compute) were identified as the first set of infrastructure pieces that Amazon should launch.[^cite_note-horsemouth-20][^cite_note-tcaws-22][^cite_note-aselip-30]

Jeff Barr, an early AWS employee, credits himself, Vermeulen, Jassy, Bezos, and a few others for coming up with the idea that would evolve into [EC2](https://en.wikipedia.org/wiki/Amazon_EC2), [S3](https://en.wikipedia.org/wiki/Amazon_S3), and [RDS](https://en.wikipedia.org/wiki/Amazon_RDS);[^cite_note-38] Jassy recalls the idea was the result of brainstorming for about a week with "ten of the best [technology](https://en.wikipedia.org/wiki/Software_engineering) minds and ten of the best [product management](https://en.wikipedia.org/wiki/Product_management) minds" on about ten different Internet applications and the most primitive building blocks required to build them.[^cite_note-hilabs-24] [Werner Vogels](https://en.wikipedia.org/wiki/Werner_Vogels) cites Amazon's desire to make the process of "invent, launch, reinvent, relaunch, start over, rinse, repeat" as fast as it could was leading them to break down [organizational structures](https://en.wikipedia.org/wiki/Big_company) with "two-pizza teams"[^cite_note-40] and [application structures](https://en.wikipedia.org/wiki/Software_architecture) with [distributed systems](https://en.wikipedia.org/wiki/Distributed_computing);[^cite_note-41] and that these changes ultimately paved way for the formation of AWS[^cite_note-vogels-26] and its mission "to expose all of the atomic-level pieces of the Amazon.com platform".[^cite_note-42] According to [Brewster Kahle](https://en.wikipedia.org/wiki/Brewster_Kahle), co-founder of [Alexa Internet](https://en.wikipedia.org/wiki/Alexa_Internet), which was acquired by Amazon in 1999, his start-up's compute infrastructure helped Amazon solve its [big data](https://en.wikipedia.org/wiki/Big_data) problems and later informed the innovations that underpinned AWS.[^cite_note-43]

Jassy assembled a founding team of 57 employees from a mix of engineering and business backgrounds to kick-start these initiatives,[^cite_note-hilabs-24][^cite_note-crnaws-23] with a majority of the hires coming from outside the company.[^cite_note-hilabs-24] They included Jeff Lawson, the [Twilio](https://en.wikipedia.org/wiki/Twilio) CEO;[^cite_note-44] Adam Selipsky, the [Tableau](https://en.wikipedia.org/wiki/Tableau_Inc) CEO;[^cite_note-45][^cite_note-46] and Mikhail Seregine,[^cite_note-47] a co-founder at [Outschool](https://en.wikipedia.org/wiki/Outschool).

In late 2003, the concept for compute,[^cite_note-49] which would later launch as [EC2](https://en.wikipedia.org/wiki/Amazon_EC2), was reformulated when Chris Pinkham and Benjamin Black presented a paper internally describing a vision for Amazon's retail computing infrastructure that was completely standardized, completely automated, and would rely extensively on web services for services such as storage and would draw on internal work already underway. Near the end of their paper, they mentioned the possibility of selling access to virtual servers as a service, proposing the company could generate revenue from the new infrastructure investment.[^cite_note-PinkhamBlack2003Paper-50] Thereafter Pinkham, [Willem van Biljon](https://en.wikipedia.org/wiki/Willem_van_Biljon), and lead developer Christopher Brown developed the Amazon EC2 service, with a team in [Cape Town](6653.md), South Africa.[^cite_note-51]

In October 2004, Amazon released Alexa Web Information Service (AWIS) as beta.[^cite_note-52] In November 2004, AWS launched its first [infrastructure service](https://en.wikipedia.org/wiki/IaaS), as beta: [Simple Queue Service](https://en.wikipedia.org/wiki/Amazon_Simple_Queue_Service) (SQS).[^cite_note-53][^cite_note-54][^cite_note-55], and officially launched in July 2006.[^cite_note-56][^cite_note-auto2-57]

### Growth (2010–2015)



AWS Summit 2013 event in NYC

In November 2010, it was reported that all of Amazon.com's retail sites had migrated to AWS.[^cite_note-71] Prior to 2012, AWS was considered a part of Amazon.com and so its revenue was not delineated in Amazon financial statements. In that year industry watchers for the first time estimated AWS revenue to be over \$1.5 billion.[^cite_note-72]

On November 27, 2012, AWS hosted its first major annual conference, *re\:Invent* with a focus on AWS's partners and ecosystem,[^cite_note-73] with over 150 sessions.[^cite_note-freinventblog-74] The three-day event was held in Las Vegas because of its relatively cheaper connectivity with locations across the United States and the rest of the world.[^cite_note-75] Andy Jassy and Werner Vogels presented keynotes, with [Jeff Bezos](https://en.wikipedia.org/wiki/Jeff_Bezos) joining Vogels for a fireside chat.[^cite_note-net1-76] AWS opened early registrations at [US\$](https://en.wikipedia.org/wiki/USD)1,099 per head for their customers[^cite_note-freinventblog-74] from over 190 countries.[^cite_note-77] On stage with Andy Jassy at the event which saw around 6000 attendees, [Reed Hastings](https://en.wikipedia.org/wiki/Reed_Hastings), CEO at [Netflix](https://en.wikipedia.org/wiki/Netflix), announced plans to migrate 100% of Netflix's infrastructure to AWS.[^cite_note-net1-76]

To support industry-wide training and skills standardization, AWS began offering a certification program for computer engineers, on April 30, 2013, to highlight expertise in cloud computing.[^cite_note-78] Later that year, in October, AWS launched *Activate*, a program for start-ups worldwide to leverage AWS credits, third-party integrations, and free access to AWS experts to help build their business.[^cite_note-79]

In 2014, AWS launched its partner network, AWS Partner Network (APN), which is focused on helping AWS-based companies grow and scale the success of their business with close collaboration and best practices.[^cite_note-80][^cite_note-81]

In October 2014, [Amazon Aurora](https://en.wikipedia.org/wiki/Amazon_Aurora) was launched.[^cite_note-82]

In January 2015, Amazon Web Services acquired [Annapurna Labs](https://en.wikipedia.org/wiki/Annapurna_Labs), an Israel-based microelectronics company for a reported US\$350–370M.[^cite_note-reut_Amaz-83][^cite_note-extr_Amaz-84]

In April 2015, Amazon.com reported AWS was profitable, with sales of \$1.57 billion in the first quarter of the year and \$265 million of operating income. Founder [Jeff Bezos](https://en.wikipedia.org/wiki/Jeff_Bezos) described it as a fast-growing \$5 billion business; analysts described it as "surprisingly more profitable than forecast".[^cite_note-85] In October, Amazon.com said in its Q3 earnings report that AWS's operating income was \$521 million, with operating margins at 25 percent. AWS's 2015 Q3 revenue was \$2.1 billion, a 78% increase from 2014's Q3 revenue of \$1.17 billion.[^cite_note-86] 2015 Q4 revenue for the AWS segment increased 69.5% y/y to \$2.4 billion with a 28.5% operating margin, giving AWS a \$9.6 billion run rate. In 2015, [Gartner](https://en.wikipedia.org/wiki/Gartner) estimated that AWS customers are deploying 10x more infrastructure on AWS than the combined adoption of the next 14 providers.[^cite_note-87]

### Since 2016

In 2016 Q1, revenue was \$2.57 billion with net income of \$604 million, a 64% increase over 2015 Q1 that resulted in AWS being more profitable than Amazon's North American retail business for the first time.[^cite_note-88] Jassy was thereafter promoted to CEO of the division.[^cite_note-CEO_Andy_Jassy-89] Around the same time, Amazon experienced a 42% rise in stock value as a result of increased earnings, of which AWS contributed 56% to corporate profits.[^cite_note-90]

AWS had \$17.46 billion in annual revenue in 2017.[^cite_note-auto1-91] By the end of 2020, the number had grown to [\$](https://en.wikipedia.org/wiki/USD)46 billion.[^cite_note-2020sales-92] Reflecting the success of AWS, Jassy's annual compensation in 2017 hit nearly \$36 million.[^cite_note-auto-93]

In January 2018, Amazon launched a unified [autoscaling](https://en.wikipedia.org/wiki/Autoscaling) service on AWS.[^cite_note-94][^cite_note-95] This new service unifies and builds on AWS existing, service-specific, scaling features like EC2 Auto Scaling groups, that was launched in August 2006.[^cite_note-96]

In November 2018, AWS announced customized ARM cores for use in its servers.[^cite_note-97] Also in November 2018, AWS announced [AWS Ground Stations](https://en.wikipedia.org/wiki/AWS_Ground_Station) to communicate with customers' satellites.[^cite_note-98]

In 2019, AWS reported 37% yearly growth and accounted for 12% of Amazon's revenue (up from 11% in 2018).[^cite_note-99]

In April 2021, AWS reported 32% yearly growth and accounted for 32% of \$41.8 billion cloud market in Q1 2021.[^cite_note-100]

In January 2022, AWS joined the MACH Alliance, a non-profit enterprise technology advocacy group.[^cite_note-101]

In June 2022, it was reported that in 2019 Capital One had not secured their AWS resources properly, and was subject to a data breach by a former AWS employee. The employee was convicted of hacking into the company's cloud servers to steal customer data and use computer power to mine cryptocurrency. The ex-employee was able to download the personal information of more than 100 million Capital One customers.[^cite_note-102]

In June 2022, AWS announced they had launched the AWS Snowcone, a small computing device, to the [International Space Station](15043.md) on the [Axiom Mission 1](https://en.wikipedia.org/wiki/Axiom_Mission_1).[^cite_note-103]

In September 2023, AWS announced it would become AI startup [Anthropic](6206236.md)'s primary cloud provider. Amazon has committed to investing up to \$4 billion in Anthropic and will have a minority ownership position in the company.[^cite_note-104] AWS also announced the GA of [Amazon Bedrock](https://en.wikipedia.org/wiki/Amazon_Bedrock), a fully managed service that makes foundation models (FMs) from leading AI companies available through a single application programming interface (API)[^cite_note-105]

In April 2024, AWS announced a new service called Deadline Cloud, which lets customers set up, deploy and scale up graphics and visual effects rendering pipelines on AWS cloud infrastructure.[^cite_note-106]

In July 2024, AWS won a \$1.3 billion (A\$2 billion) contract with Australia's government to build a top-secret cloud service. The service included a partnership with the [Australian Signals Directorate](https://en.wikipedia.org/wiki/Australian_Signals_Directorate) (ASD). The ASD director general Rachel Noble said the service would "provide a state-of-the-art collaborative space for our intelligence and defense community to store and access top-secret data”.[^cite_note-107]

In December 2024, AWS announced Amazon Nova, its own family of [foundation models](https://en.wikipedia.org/wiki/Foundation_model). These models, offered through Amazon Bedrock, are designed for various tasks including content generation, video understanding, and building agentic applications. They are available in six different sizes.[^cite_note-108] At the end of 2024, AWS announced Project Rainier, a massive one-of-a-kind machine "designed to usher in the next generation of AI."[^cite_note-109]

In February 2026, India's [National Informatics Centre](https://en.wikipedia.org/wiki/National_Informatics_Centre) (NIC), a department under the [Ministry of Electronics and Information Technology](https://en.wikipedia.org/wiki/Ministry_of_Electronics_and_Information_Technology), announced deployment of [AWS Outposts](https://en.wikipedia.org/wiki/AWS_Outposts?action=edit\&redlink=1) within its data centers as part of the government's Meghraj 2.0 hybrid cloud initiative, working with Indian data center provider Yotta Data Services. The deployment enables sensitive government workloads to remain within NIC's physical infrastructure while accessing AWS cloud services including Amazon EKS, Amazon RDS, and Amazon S3.[^cite_note-110]

In March and April of 2026, during the [2026 Iran War](https://en.wikipedia.org/wiki/2026_Iran_War), Iranian drone and missile strikes damaged AWS data centers in the United Arab Emirates (me-central-1) and Bahrain (me-south-1) regions, in the first deliberate military targeting of a commercial data center. Iran claimed the data centers hosted US military workloads. AWS advised customers to migrate to other regions.[^cite_note-111][^cite_note-\:3-112]

On 30 June 2026, AWS Secret Cloud for Industry (ASCI) was made generally available. It holds a Provisional Authorization at Impact Level 6 from the Defense Information Systems Agency and uses the same Defense Counterintelligence and Security Agency (DCSA) compliance framework that cleared defense contractors already use for on-premises classified systems. Northrop Grumman was the first defense contractor to deploy classified workloads on ASCI. To speed up the migration and to attract customers AWS launched ASCI Accelerator Initiative.[^cite_note-auto3-15] The U.S. Intelligence Community (IC) launched IC Accelerated Modernization Framework (ICAMF) which subsidizes transfer to AWS from on-site systems. ASCI provides physically and logically isolated environment purpose-built to meet the most demanding security and compliance requirements.[^cite_note-113] They also created AWS [Forward Deployed Engineering](https://en.wikipedia.org/wiki/Forward_deployed_engineer) (FDE) organization. It embeds *AWS frontier teams*[^cite_note-114]—working with purpose-built agents—directly inside customer teams (business, engineering, and security teams) to build and deploy production AI systems with their data, governance, and processes.[^cite_note-115]

### Customer base

In October 2013, AWS was awarded a \$600M contract with the [CIA](https://en.wikipedia.org/wiki/CIA).[^cite_note-116]

By 2019, it was reported that more than 80% of [Germany](11867.md)'s listed [DAX](https://en.wikipedia.org/wiki/DAX) companies used AWS.[^cite_note-117] In August 2019, the [U.S. Navy](20518076.md) said it moved 72,000 users from six commands to an AWS cloud system as a first step toward pushing all of its data and analytics onto the cloud.[^cite_note-118]

## Availability and topology

As of October 2025, AWS has distinct operations in 38 geographical "regions":[^cite_note-GlobalInfrastructure-11] nine in [North America](21139.md), two in [South America](26769.md), nine in [Europe](9239.md), four in the [Middle East](19323.md), one in Africa, thirteen in the [Asia–Pacific](https://en.wikipedia.org/wiki/Asia%E2%80%93Pacific), and three in Australia and New Zealand.

Most AWS regions are enabled by default for AWS accounts. Regions introduced after 20 March 2019 are considered to be *opt-in* regions, requiring a user to explicitly enable them in order for the region to be usable in the account. For opt-in regions, Identity and Access Management (IAM) resources such as users and roles are only propagated to the regions that are enabled.[^cite_note-144]

Each region is wholly contained within a single country and all of its data and services stay within the designated region.[^cite_note-AWSagreement-10] Each region has multiple "Availability Zones",[^cite_note-GlobalInfrastructure-11] which consist of one or more discrete [data centers](579730.md), each with [redundant power](2736308.md), networking, and connectivity, housed in separate facilities. Availability Zones do not automatically provide additional scalability or redundancy within a region, since they are intentionally isolated from each other to prevent [outages](https://en.wikipedia.org/wiki/Network_outage) from spreading between zones. Several services can operate across Availability Zones (e.g., S3, [DynamoDB](https://en.wikipedia.org/wiki/Amazon_DynamoDB)) while others can be configured to replicate across zones to spread demand and avoid [downtime](https://en.wikipedia.org/wiki/Downtime) from failures.

As of December 2014, Amazon Web Services operated an estimated 1.4 million servers across 11 regions and 28 availability zones.[^cite_note-145] The global network of AWS Edge locations consists of over 700 points of presence worldwide, including locations in North America, Europe, Asia, Australia and New Zealand, Africa, and South America.The AWS Cloud spans 120 Availability Zones within 38 Geographic Regions, with announced plans for 10 more Availability Zones and 3 more AWS Regions in the Kingdom of Saudi Arabia, Chile, and the AWS European Sovereign Cloud.[^cite_note-GlobalInfrastructure-11]

As of March 2024, AWS had announced the planned launch of six additional regions in Malaysia, Mexico, New Zealand, Thailand, Saudi Arabia, and the European Union.[^cite_note-GlobalInfrastructure-11] In mid March 2023, Amazon Web Services signed a cooperation agreement with the New Zealand Government to build large data centers in New Zealand.[^cite_note-146]

## Reception

### Environmental footprint

In 2014, AWS claimed its aim was to achieve [100% renewable energy](https://en.wikipedia.org/wiki/100%25_renewable_energy) usage in the future.[^cite_note-159] In the United States, AWS's partnerships with renewable energy providers include Community Energy of Virginia, to support the US East region;[^cite_note-burt2015-160] Pattern Development, in January 2015, to construct and operate Amazon [Wind Farm Fowler Ridge](https://en.wikipedia.org/wiki/Fowler_Ridge_Wind_Farm);[^cite_note-161] [Iberdrola Renewables](https://en.wikipedia.org/wiki/Avangrid), LLC, in July 2015, to construct and operate Amazon Wind Farm US East; [EDP Renewables North America](https://en.wikipedia.org/wiki/EDP_Renewables_North_America), in November 2015, to construct and operate Amazon Wind Farm US Central;[^cite_note-162] and [Tesla Motors](https://en.wikipedia.org/wiki/Tesla_Motors), to apply battery storage technology to address power needs in the US West (Northern California) region.[^cite_note-burt2015-160]

In 2016, [Greenpeace](12233.md) assessed major tech companies—including cloud services providers like AWS, [Microsoft](19001.md), [Oracle](22591.md), [Google](1092923.md), [IBM](https://en.wikipedia.org/wiki/IBM), [Salesforce](https://en.wikipedia.org/wiki/Salesforce) and [Rackspace](https://en.wikipedia.org/wiki/Rackspace)—based on their level of "clean energy" usage. Greenpeace evaluated companies on their mix of renewable-energy sources; transparency; renewable-energy commitment and policies; energy efficiency and greenhouse-gas mitigation; renewable-energy procurement; and advocacy. The group gave AWS an overall "C" grade. Greenpeace credited AWS for its advances toward greener computing in recent years and its plans to launch multiple wind and solar farms across the United States. The organization stated that Amazon is opaque about its [carbon footprint](https://en.wikipedia.org/wiki/Carbon_footprint).[^cite_note-163]

In January 2021, AWS joined an industry pledge to achieve [climate neutrality](https://en.wikipedia.org/wiki/Carbon_neutrality) of data centers by 2030, the [Climate Neutral Data Centre Pact](https://en.wikipedia.org/wiki/Climate_Neutral_Data_Centre_Pact).[^cite_note-164] As of 2023, Amazon as a whole is the largest corporate purchaser of renewable energy in the world, a position it has held since 2020, and has a global portfolio of over 20 GW of renewable energy capacity.[^cite_note-165] In 2022, 90% of all Amazon operations, including data centers, were powered by renewables.[^cite_note-166] In 2024, AWS paid \$650 million for a data center[^cite_note-167] at the 2.5 GW [Susquehanna nuclear power plant](https://en.wikipedia.org/wiki/Susquehanna_Steam_Electric_Station), connected at 300 MW. In 2025, AWS signed an \$18 billion [power purchase agreement](https://en.wikipedia.org/wiki/Power_purchase_agreement) with the station for 840—1,200 MW in 2029 and 1,680—1,920 MW in 2032, continuing to 2042. The power increase depends on Amazon's expansion of the data center.[^cite_note-pat-168]

### Denaturalization protest

US [Department of Homeland Security](58236.md) has employed the software ATLAS, which runs on Amazon Cloud. It scanned more than 16.5 million records of naturalized Americans and flagged approximately 124,000 of them for manual analysis and review by [USCIS](https://en.wikipedia.org/wiki/USCIS) officers regarding [denaturalization](https://en.wikipedia.org/wiki/Denaturalization).[^cite_note-169][^cite_note-170] Some of the scanned data came from the [Terrorist Screening Database](https://en.wikipedia.org/wiki/Terrorist_Screening_Database) and the [National Crime Information Center](https://en.wikipedia.org/wiki/National_Crime_Information_Center). The algorithm and the criteria for the algorithm were secret. Amazon faced protests from its own employees and activists for the anti-migrant collaboration with authorities.[^cite_note-171]

## Security incidents

### Amazon Q Developer Extension supply-chain vulnerability (2025)

In July 2025, a security researcher disclosed a supply-chain vulnerability in the Amazon Q Developer Extension (version 1.84) for Visual Studio Code.[^cite_note-\:1-179] The issue involved a malicious pull request to the project's GitHub repository, which introduced a prompt instructing the AI assistant to delete local files and AWS resources.[^cite_note-\:2-180][^cite_note-\:1-179] AWS acknowledged the issue in Security Bulletin AWS‑2025‑015 and released version 1.85 to remove the injected prompt. The company stated that no customer systems or data were affected.[^cite_note-181] However, critics including Corey Quinn, writing in Last Week in AWS, questioned the transparency of the response, noting the absence of a changelog entry, a CVE assignment, or a public statement beyond the bulletin.[^cite_note-\:2-180]

### Log4Shell Hot Patch vulnerability

In response to the [Log4Shell vulnerability](https://en.wikipedia.org/wiki/Log4Shell), AWS released hot patch solutions to mitigate risks in Java applications across various environments, including standalone servers, Kubernetes clusters, and Elastic Container Service (ECS). These patches were designed for both AWS and non-AWS environments. However, researchers from Unit 42 at [Palo Alto Networks](https://en.wikipedia.org/wiki/Palo_Alto_Networks) identified critical security flaws in these patches that could be exploited for container escape and privilege escalation, potentially granting attackers unauthorized root-level access to the host system. AWS addressed these vulnerabilities by releasing updated patches on April 19, 2022. Users who deployed the initial patches were advised to upgrade to the latest versions to mitigate security risks.[^cite_note-182]

### Application Load Balancer security issue

In April 2024, security researchers from Miggo security identified a configuration vulnerability in AWS Application Load Balancer (ALB) that could allow attackers to bypass access controls and compromise web applications. The issue stemmed from how some users configured ALB's authentication handoff to third-party services, potentially enabling unauthorized access to application data. On July 11, 2024, AWS confirmed the issue affecting its customers, and on July 19, 2024, AWS updated its documentation accordingly to recommend more secure implementation practices.[^cite_note-183][^cite_note-184]

In 2026, Amazon Web Services (AWS) data center infrastructure in the United Arab Emirates and Bahrain experienced service disruptions following reported drone strikes in the region. According to Datacenter Dynamics and Reuters, some facilities were affected, resulting in partial damage to physical infrastructure and temporary reductions in service availability for enterprise customers. reports indicated that full recovery of services in the affected regions could take several months, with some services being moved to other cloud regions.[^cite_note-185][^cite_note-186][^cite_note-187]

## Pricing

### Data transfer charges

AWS applies charges for data transferred both between Availability Zones within the same region (inter-AZ) and across different geographic regions (inter-region). The pricing structure is influenced by several factors, including the source and destination of the data, the specific AWS services in use, and the underlying networking architecture.[^cite_note-191][^cite_note-\:0-192] Various services implement different data transfer models, and the choice of communication method—such as VPC Peering,[^cite_note-193] Transit Gateway,[^cite_note-194] or AWS PrivateLink[^cite_note-195]—can also affect the overall cost.[^cite_note-\:0-192]
