# Security

Report suspected credential exposure or code execution issues privately to
support@bendyline.com. Do not include live tokens or private source content in a
public issue. Use normal issues for incorrect public content and attribution.

Imported Markdown, YAML, HTML, and office files are untrusted data. The pipeline
does not execute their scripts. Fork pull requests run without publishing tokens.
Publishing operates on reviewed commits and verifies archive digests after upload.

Keep dependency updates and converter fixes current. Source license checks and
public-source restrictions are release policy, not a guarantee that every upstream
file has correct attribution; new sources still require human assessment.
